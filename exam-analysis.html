如何读这些变化 / Reading the changes

  • U1：A线历年47—60分，首场51→2026年6月60；E线历年27—40分。2026年1月到6月，A线53→60（+7分），E线36→40（+4分）。 Raw thresholds vary by series; the full unit tables show all grades.
  • U2：A线历年42—60分，首场55→2026年6月60；E线历年21—36分。2026年1月到6月，A线56→60（+4分），E线36→36（+0分）。 Raw thresholds vary by series; the full unit tables show all grades.
  • U3：A线历年46—67分，首场50→2026年6月67；E线历年24—38分。2026年1月到6月，A线59→67（+8分），E线38→37（-1分）。 Raw thresholds vary by series; the full unit tables show all grades.
  • U4：A线历年47—66分，首场51→2026年6月66；E线历年21—38分。2026年1月到6月，A线63→66（+3分），E线38→37（-1分）。 Raw thresholds vary by series; the full unit tables show all grades.

U表示低于E线，原始分区间为0至E−1。不同试卷经官方UMS换算维持成绩可比性；阈值上升不单独证明试卷更容易或考生更强。 U is a band, and raw-boundary differences do not isolate the cause of performance changes.

四、如何用于备考 / Using the analysis

  • 用历年占比安排复习频次；完整覆盖考纲，不能删去低频小节。Use historical emphasis to plan repetition while retaining the full specification.
  • 同一知识点交叉练习计算、作图和解释，按评分标准复盘步骤。Vary response demands and review credited steps.
  • 不把分数线当固定百分比，不把知识占比当得分率，也不据两份试卷预测未来命题。Separate boundaries, topic emphasis and performance.
  • 每个小问只归一个主考点；综合题的辅助标签不重复计分。All shares use one primary allocation per subpart.
  • U2 2025年6月有1分统一给分，已单列；各卷总分仍为80。The administrative credit is kept separate from assessed topic marks.
