U3/07 常用物理模型

U3PM13 水平桌面绳牵引 / Horizontal string

所属知识 / Knowledge： 3.6.1 Circular motion / 圆周运动 · 模型目录 / Model index

关键词 → 模型 / Keywords → model

horizontal table / smooth / taut string → 水平桌面绳牵引 / Horizontal string

关键词只是识别线索；必须同时核对受力方向、几何和约束。 Keywords are cues, not sufficient conditions; check the actual forces and constraints.

建模、方程与适用条件 / Model, equations and conditions

受力与方程 / Forces and equation

模型假设物体在光滑水平面内运动，绳水平并指向圆心；竖直方向 \(N=mg\)，径向只有张力 \(T_s=mv^2/r\)。若无桌面或其他竖直支持力，不能把有重力的悬挂物直接套为此模型。

On a smooth horizontal table, weight and normal reaction balance vertically and a horizontal string supplies the radial force. Without vertical support, a freely suspended mass needs a different model.

若绳最大允许张力 \(T_{\max}\)，则 \(v_{\max}=\sqrt{T_{\max}r/m}\)。绳断开后速度初始沿切线；随后轨迹取决于桌面支持、重力等剩余作用，不说“沿半径飞出”。

Maximum tension limits the speed. On release the initial velocity is tangential; subsequent motion depends on the remaining forces.

条件检查 / Constraint check

把张力与额外的“向心力”同时画在受力图上属于重复计力。对于图中圆周任一点，向心方向随位置变化。

Do not draw an extra centripetal force in addition to tension. The inward direction changes around the circle.
