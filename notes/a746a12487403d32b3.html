1. 测量质量与结果比较 / Measurement quality and comparisons

1.1 关键概念与定义 / Key concepts and definitions

Measurement error / 测量误差

Definition / 定义

EN: A measurement error is the difference between a measured value and the true value of the quantity.

中: 测量误差是测量值与该物理量真值之差。

Accuracy / 准确度

Definition / 定义

EN: Accuracy describes how close a measured value is to the true value of the quantity.

中: 准确度描述测量值接近该量真值的程度。

表达要点 / Wording: close to the true value

准确度与精密度 / Accuracy and precision

读图 / Reading： 靶心代表真值；散布越小越精密，整组结果越接近靶心越准确。结果集中但偏离靶心，仍可能存在系统误差。

The centre represents the true value. Small spread means precision; closeness to the centre means accuracy. A tight displaced group can have systematic bias.

Precision / 精密度

Definition / 定义

EN: Precision describes how closely repeated measurements agree with one another.

中: 精密度描述重复测量值彼此接近的程度。

表达要点 / Wording: close agreement; small spread

1.2 内容解析与细节 / Explanation and details

测量质量对照 / Measurement-quality comparison

中文 English 含义 / Meaning
准确度 accuracy 测量值接近真值或公认值的程度 / closeness to a true or accepted value
精密度 precision 重复读数彼此接近、分散小的程度 / small spread of repeated readings
重复性 repeatability 同一人、同一方法和设备重复得到一致结果 / agreement under the same conditions
可复现性 reproducibility 更换人员、设备或方法仍得到一致结果 / agreement when conditions change
分辨率 resolution 仪器可区分的最小变化 / smallest discernible change

2. 重复性与可复现性 / Repeatability and reproducibility

2.1 关键概念与定义 / Key concepts and definitions

Repeatability / 重复性

Definition / 定义

EN: Measurements are repeatable when the same person uses the same method and equipment and obtains consistent results.

中: 同一人使用相同方法和仪器重复测量，得到一致结果时，测量具有重复性。

表达要点 / Wording: same person; same method and equipment; consistent results

Reproducibility / 可复现性

Definition / 定义

EN: A measurement is reproducible when another person, or a different method, produces the same result.

中: 换另一人或另一方法测量，仍得到相同结果时，测量具有可复现性。

表达要点 / Wording: another person or method; same result

依据 / Evidence: PH01 202201 Q04.3 · MS p8（定义/陈述评分点）；OxfordAQA 9630 Practical handbook · PDF p42

3. 分辨率与仪器读数 / Resolution and instrument readings

3.1 关键概念与定义 / Key concepts and definitions

Resolution / 分辨率

Definition / 定义

EN: Resolution is the smallest change in the measured quantity that produces a discernible change in an instrument reading.

中: 分辨率是能使仪器读数产生可辨变化的被测量最小变化。

表达要点 / Wording: smallest discernible change

千分尺读数 / Micrometer reading

读图 / Reading： 先核对零点，再把主尺与微分筒读数相加；多位置、多方向测量线径，避免把线径变化当成随机读数误差。

Check zero error, add sleeve and thimble readings, and measure diameter at several positions and orientations.

4. 随机误差与减小方法 / Random error and its reduction

4.1 关键概念与定义 / Key concepts and definitions

Random error / 随机误差

Definition / 定义

EN: A random error causes repeated measured values to vary unpredictably.

中: 随机误差使重复测量值发生不可预测的变化。

表达要点 / Wording: unpredictable variation

4.2 内容解析与细节 / Explanation and details

重要考点 · 减小随机误差的影响 / Minimise the effect of random errors

随机误差使重复读数发生不可预测的变化，例如反应时间变化或读数判断不同。改进实验时，应说明具体操作以及它如何减小随机误差对最终结果的影响。

Random errors cause unpredictable variation between readings, for example through variations in reaction time or reading a scale. State the practical change and explain how it reduces the effect on the final result.

方法 / Method 原因与答题表述 / Reason and exam wording
重复测量并取平均值 / Repeat measurements and calculate a mean 在相同条件下多次独立测量并取平均，正、负随机偏差可部分抵消，减小随机误差对平均值的影响。 / Repeat independent measurements under the same conditions and calculate a mean. Positive and negative random deviations partly cancel, reducing their effect on the mean.
采用自动计时 / Use automatic timing 例如用光电门和数据记录器记录时间，减小人工反应时间变化对测量的影响。 / Use light gates and a data logger to reduce variations caused by human reaction time.
稳定装置与测量条件 / Stabilise the apparatus and measurement conditions 固定仪器、减少不必要的振动或气流，并在读数稳定后记录，减小相应的读数波动。 / Secure the apparatus, reduce unwanted vibration or draughts, and take readings once they are stable to reduce the resulting fluctuations.
答题表述 / Exam wording

Repeat the measurements and calculate a mean to minimise the effect of random errors.
重复测量并计算平均值，以减小随机误差对结果的影响。

取平均减小的是随机误差对平均值的影响，原始读数的分散程度仍应如实记录。
Averaging reduces the effect of random errors on the mean. The spread of the original readings should still be recorded.

真题依据 / Mark-scheme example · PH01 · 2025年6月 · Q08.4 将重复测量与减小随机误差的影响联系起来，同时要求解释在不同位置测量是为了考虑地面的不均匀性。 / Repeating measurements reduces the effect of random errors. Measuring at different locations also accounts for uneven ground.

5. 系统误差、零点误差与修正 / Systematic error, zero error and correction

5.1 关键概念与定义 / Key concepts and definitions

Systematic error / 系统误差

Definition / 定义

EN: A systematic error causes measured values to differ from the true value in a consistent direction.

中: 系统误差使测量值相对于真值产生方向一致的偏差。

表达要点 / Wording: consistent bias

依据 / Evidence: OxfordAQA 9630 Practical handbook · PDF p41；PH01 202001 Q01 · MS p4（相关计算或应用）

Zero error / 零点误差

Definition / 定义

EN: A zero error occurs when an instrument gives a non-zero reading when the measured quantity is zero.

中: 被测量为零而仪器读数不为零时，存在零点误差。

表达要点 / Wording: non-zero reading at zero

依据 / Evidence: OxfordAQA 9630 Practical handbook · PDF p42；PH01 202301 Q10.4 · MS p20（相关计算或应用）

5.2 内容解析与细节 / Explanation and details

重要考点 · 减小系统误差 / Reduce systematic errors

系统误差使测量结果相对于真值产生方向一致的偏差，例如零点偏移、校准错误或持续采用错误的测量方法。

Systematic errors cause a consistent bias relative to the true value, for example through a zero offset, incorrect calibration or a consistently incorrect method.

误差来源 / Source 改进及原因 / Improvement and reason
零点误差 / Zero error 测量前检查零点并调零，或根据测得的零点偏移修正所有读数。 / Check and adjust the zero before measuring, or correct all readings using the measured zero offset.
校准错误 / Incorrect calibration 用已知标准值校准仪器，并在实际使用的测量范围内检查读数。 / Calibrate the instrument against known standards and check its readings over the range used.
视差 / Parallax 视线垂直于刻度，眼睛与指针或液面处于适当的同一高度。 / View the scale perpendicularly, with the eye correctly aligned with the pointer or liquid level.
装置或方法造成的一致偏差 / Consistent bias in the apparatus or method 指出具体偏差并针对性改进，例如测量摆长时量至摆球中心，测量伸长时用最终长度减去初始长度。 / Identify and correct the specific bias, for example by measuring pendulum length to the bob’s centre or finding extension from the final length minus the original length.
答题表述 / Exam wording

Check for zero error and correct the readings. Calibrate the instrument using a known standard.
检查零点误差并修正读数，使用已知标准校准仪器。

重复测量、取平均仍保留共同的系统偏差，因此还需识别并修正误差来源。
Repeated readings and their mean retain a common systematic bias, so its source must be identified and corrected.

真题依据 / Mark-scheme example · PH01 · 2023年1月 · Q10.4–10.5 考查零点误差及其影响。恒定的纵轴零点偏移影响每个读数，但直线斜率保持不变。 / A constant zero offset in the vertical-axis readings affects every reading while leaving the gradient unchanged.

6. 不确定度的减小 / Reducing uncertainty

6.1 内容解析与细节 / Explanation and details

重要考点 · 减小不确定度 / Minimise the uncertainty

根据误差来源，选择更小读数不确定度的仪器、测量更大的累计量、重复取平均，或优先改进对结果不确定度贡献最大的测量。绝对不确定度和百分比不确定度的改进方法见 减小不确定度的方法 / Methods to minimise the uncertainty。

Choose a method that addresses the source of uncertainty. Use an instrument with a smaller reading uncertainty, measure a larger accumulated quantity, repeat and average, or improve the measurement that contributes most to the final uncertainty.

高精密度并不保证高准确度。分辨率高也不自动说明仪器已经校准正确。High precision or resolution alone does not guarantee accuracy.

M04 方法 1 · 误差类型、精密度与可复现性 / Error types and reproducibility

  • 固定零点或校准偏移属于系统误差；重复平均不能消除。视差若观察方向变化可造成随机散布，固定错误观察位置也可能形成系统偏差，应按题境解释。 / Classify the mechanism, not just the instrument name.
  • 精密度比较要引用不确定度，结果量级不同时优先比百分不确定度；可复现性涉及不同人、设备或方法获得一致结果，可用区间是否重叠讨论。 / Support quality claims quantitatively.
  • 分辨率通常有单位，准确度、重复性等不是另一个带单位的读数。重复同位置减小随机影响，换位置用于检验样品或表面均匀性。 / State the purpose of each repeat.
  • 提出改进写“具体做法 → 所针对的误差 → 减小何种不确定度”；不把所有改进都写成换更精密仪器。 / Link the change to an identified problem.
