线材拉伸与杨氏模量模型 / Young modulus

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
wire / cable 细线 / 缆绳 受拉的试样 / A sample under tension.
Young modulus / same material 杨氏模量 / 相同材料 相同线性材料的E不随试样尺寸改变 / E is a material property in the linear range.
diameter / original length 直径 / 原长 面积含直径平方，应变用原长 / Area uses diameter squared; strain uses original length.
tensile stress / strain 拉应力 / 拉应变 区分F/A与伸长/原长 / Distinguish force per area from fractional extension.
joined / in series 连接 / 串接 按连接点受力判断各段拉力 / Check forces at the join.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

线性弹性范围中，材料的杨氏模量连接载荷、试样几何与伸长。 / Young modulus links force, geometry and extension in the linear elastic range.

Formula / 公式

\[A_0=\frac{\pi d^2}{4},\qquad \sigma=\frac{F}{A_0},\qquad \epsilon=\frac{x}{L_0},\]
\[E=\frac{\sigma}{\epsilon}=\frac{FL_0}{A_0x},\qquad x=\frac{FL_0}{EA_0},\qquad k=\frac{EA_0}{L_0}.\]

解题流程 / Method

  1. 用原长、原始截面积及实际拉力；伸长量不是末长度。 / Use original geometry and actual tension.
  2. 同材料、同载荷和同原长时，直径加倍使伸长变为四分之一。 / Extension scales inversely with diameter squared under those fixed conditions.
  3. 求E时，F–x梯度 \(k\) 还须乘 \(L_0/A_0\)；\(\sigma\)–\(\epsilon\)线性梯度直接给E。 / Interpret the graph before extracting the modulus.
  4. 串接轻线、中间无额外外力时各段拉力相同；截面积不同则应力、应变、伸长一般不同。 / Equal tension does not imply equal stress or strain.

易错判断 / Checks

相同材料意味着E相同，未必k相同。 应变没有单位；E和应力单位为Pa。 / Stiffness depends on geometry; strain is dimensionless.

读图 / Reading: 杨氏模量取起始线性弹性段的斜率。图横轴为应变百分数，计算前须除以100转成无量纲应变。 / Use the initial linear gradient; convert percent strain to dimensionless strain before calculating E.
