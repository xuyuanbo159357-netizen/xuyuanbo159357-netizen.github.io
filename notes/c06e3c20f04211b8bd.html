本单元备考重点 / Unit-specific preparation

模型选择 / Model choice

先分辨矢量、运动学、受力、动量和能量，再写约束；不要因出现碰撞就无条件同时守恒动能。 Identify the model and constraints before selecting conservation laws.

图像与测量 / Graphs and measurement

速度时间面积、瞬时切线、误差棒、异常值与有效数字要分开训练。 Practise signed areas, tangents, error bars and measurement processing.

粒子与材料表述 / Particles and materials

粒子名称、电荷与核子数标记完整；弹性、塑性、脆性和刚度定义要准确。 Use exact particle notation and distinguish material properties.

按题型落实 / Applying the command

类型 / Type 答题动作 / What to do
计算 / Calculation 明确模型与适用条件→列方程→SI代入→中间量→结果及单位；需要判断时补结论。 State the model, equation, substitution, result and conclusion.
画图 / Drawing 看清draw或sketch；坐标、量名、单位、起点、峰值、渐近线和方向按题意标明，直线用尺。 Label the requested features and use a ruler for straight lines.
陈述 / Statement 按state/name/define区分名称、事实和严格定义，避免只写符号替代名称。 Match the requested level of recall.
解释 / Explanation 条件或原因→物理关系→变化方向→题境结论；不能只给公式或只复述现象。 Develop the causal link.
实验 / Practical 装置、变量、读数、控制、重复、处理、误差改进形成完整路径；改进应针对已识别偏差。 Tie the procedure and improvements to the experiment.
证明与推断 / Show or deduce 从原理出发展示链条；数值show that显示足够位数以验证给定近似值；deduce需推导或结论依据。 Show the reasoning rather than repeat the supplied result.

考官报告回看 / Examiner-report review

本地有6/17场官方报告；缺失场次未编造考生表现数据。 Reports are available for 6 of 17 papers in the collection.

2024年1月 / January

  • 证明题需交代因子与中间步骤；可用时间、速度等小标题组织推导。 Show the origin of factors and intermediate steps in derivations. 报告第3页 / Report p3

  • 处理重复测量时先识别异常值，再按题目要求求平均值和不确定度。 Identify anomalous readings before processing repeated measurements. 报告第5页 / Report p5

2024年6月 / June

  • 速度—时间图先核对毫秒与秒，距离取面积，合力计算须包含全部力。 Check milliseconds before taking areas and include every force in the resultant. 报告第3页 / Report p3

  • 杨氏模量陌生情境题需把图像、几何与材料关系串联；证明题展示代数和数量级。 Connect the graph and geometry to the Young modulus relation. 报告第4页 / Report p4

2025年1月 / January

  • 散射结论要比较原子核与原子大小，不能只说核很小。 Compare nuclear size with atomic size in scattering conclusions. 报告第2页 / Report p2

  • 飞机受力解释需区分加速和离地，并说明阻力随速率改变。 Distinguish acceleration from take-off and link drag to speed. 报告第3页 / Report p3

2025年6月 / June

  • name 要写粒子名称；自由中子衰变要区分中微子与反中微子。 Use particle names for “name” and distinguish neutrinos from antineutrinos. 报告第3页 / Report p3

  • 反应时间题要讨论反应时间的变化；不同地点重复与同处重复的目的不同。 Discuss variation in reaction time and the purpose of each type of repeat. 报告第5页 / Report p5

2026年1月 / January

  • 多步抛体计算避免逐步过早取整，速度解释应合成水平、竖直分量。 Avoid early rounding and combine horizontal and vertical velocity components. 报告第3页 / Report p3

  • determine 并要求使用图像时，需留下标注、读数或计算证据。 Provide graph annotations or calculations when determining a value from a figure. 报告第4页 / Report p4

2026年6月 / June

  • 材料行为定义应明确所谈的是应力、应变、力还是伸长。 Name the relevant quantity precisely in material-behaviour definitions. 报告第2页 / Report p2

  • 匀加速度方程需统一方向符号；能量解释需指明动能等具体能量。 Use consistent signs in kinematics and identify the type of energy. 报告第3页 / Report p3

自测与时间分配 / Practice and timing

每套120分钟、80分，平均1.5分钟/分可作为训练预算；这不是官方逐题用时要求。先完成可得分步骤，标记未完成题，最后核对单位、图线与结论。 A 1.5-minute-per-mark budget is a teaching aid, not an official timing rule.
