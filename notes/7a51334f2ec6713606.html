U1/07 常用物理模型

竖直抛落与自由落体模型 / Free fall

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.3 直线运动 - Motion along a straight line

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
dropped / released from rest 放下 / 从静止释放 释放时 u=0 / Initial velocity is zero.
thrown vertically upwards 竖直向上抛出 初速度向上，加速度向下 / Initial velocity is upward; acceleration is downward.
falls freely / negligible air resistance 自由下落 / 空气阻力可忽略 仅重力主导的阶段 / Identify the gravity-only interval.
highest point 最高点 竖直速度为零，加速度仍向下 / Vertical velocity is zero but gravity remains.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

近地面、重力场近似均匀且阻力可忽略时，飞行阶段有恒定加速度。自由落体可有非零初速度。 / Free fall is motion under gravity alone and need not start from rest.

Formula / 公式

向上为正： / Upward positive:

\[a=-g,\qquad v=u-gt,\qquad y=ut-\frac12gt^2,\qquad v^2=u^2-2gy.\]

从静止释放、向下为正时，落距 \(h=\frac12gt^2\)。 / The familiar drop-distance formula requires zero initial velocity.

解题流程 / Method

  1. 标明释放点、最高点和所问位置，写出所问阶段。 / Identify the positions and interval.
  2. 最高点 \(v_y=0\)，求上升时间或高度；回到相同高度时可利用对称性（无阻力）。 / Use zero vertical velocity at the top and equal-height symmetry when valid.
  3. 绳拉紧、弹簧伸长或接触地面后重新受力分析。 / Reanalyse forces when a rope, spring or contact force starts acting.

易错判断 / Checks

最高点 \(v=0\) 不等于 \(a=0\)。 蹦极只在绳尚未拉紧的阶段可用自由落体模型。 / Zero speed at the top does not remove gravity; a taut elastic rope changes the force model.

原课件图像辅助 / Source-slide figures

读图 / Reading: 向上为正：上升和下降阶段的速度–时间斜率都为−g，最高点只有速度为零。 / With upward positive, the slope is −g on both ascent and descent; only velocity is zero at the top.
