Rutherford散射与核式结构模型 / Rutherford scattering

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.3.1 原子的组成 - Constituents of the atom

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
Rutherford / scattering 卢瑟福 / 散射 用实验现象推断原子结构 / Infer structure from observations.
most pass through 多数穿过 原子大部分空间为空 / Most of the atom is empty space.
large angle / backwards 大角度 / 向后 少数粒子接近小而密集的原子核 / A small fraction approaches the compact nucleus.
alpha particles / thin foil α粒子 / 薄金属箔 识别入射粒子、靶和探测装置 / Identify beam, target and detector.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型 / Model

正电荷和大部分质量集中在尺寸很小的原子核中，电子分布在核外。正α粒子靠近正核时受到排斥，轨迹偏转。 / A compact positive nucleus deflects positive alpha particles.

读图 / Reading: 薄箔、准直α束与探测屏共同测散射方向。 / A collimated alpha beam, thin foil and screen reveal scattering directions.

观察到结论 / Observation to inference

观察 / Observation 推断 / Inference
多数α粒子几乎直线通过 / most pass almost undeflected 原子大部分空间为空 / the atom is mostly empty space
少数发生大角度偏转 / a small fraction undergo large deflections 正电荷集中在很小区域 / positive charge is concentrated
极少数接近反向 / a very small fraction scatter backwards 核小且集中了大部分质量 / a compact massive nucleus

解题流程 / Method

  1. 画出α源、准直束、薄箔及探测器。 / Label the source, collimated beam, thin foil and detector.
  2. 先写观察，再写它支持的结构结论。 / Pair each observation with its inference.
  3. 用正电排斥解释偏转，避免把所有散射都描述为接触撞击。 / Use repulsion rather than a literal hard-sphere impact description.

易错判断 / Checks

“大部分空间为空”与“核集中了大部分质量”来自不同观察。此模型侧重证据链和定性受力。 / Keep the observation–inference pairs distinct.
