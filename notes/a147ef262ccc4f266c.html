碰撞模型 / Collide

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
collide / collision 碰撞 / 碰撞过程 先建立相互作用的物体系统 / Identify the interacting bodies.
elastic / elastically 弹性的 / 弹性地 系统总动能守恒 / Total kinetic energy is conserved.
inelastic / inelastically 非弹性的 / 非弹性地 系统总动能不守恒 / Total kinetic energy is not conserved.
stick together / move together 粘在一起 / 一起运动 碰后共同速度：完全非弹性分支 / A shared final velocity identifies the sticking branch.
stationary / at rest 静止 / 静止状态 相应物体碰前速度为零 / Set that body's initial velocity to zero.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

模型判断 / Model selection

Collide → 碰撞情境 → 检查系统与外冲量 → 判断碰撞类别。 / Identify collision, check external impulse, then classify kinetic-energy behaviour.

题目条件 / Condition 对应分支 / Branch 总动量 / Total momentum 总动能 / Total kinetic energy
elastic / 弹性 弹性碰撞 / elastic collision 所选方向外冲量可忽略时守恒 / conserved if external impulse is negligible \(K_f=K_i\)
inelastic / 非弹性 非弹性碰撞 / inelastic collision 同一外冲量条件 / same condition \(K_f\ne K_i\)；普通耗散碰撞中减少 / decreases in a dissipative collision
stick / move together / 粘合 完全非弹性碰撞 / perfectly inelastic collision 同一外冲量条件 / same condition 两物体共享末速度；通常有动能转移 / common final velocity with kinetic-energy transfer

只给 collide 不能确定弹性；碰后分开也不能确定弹性。 / Neither the word collision nor separation afterwards proves that kinetic energy is conserved.

Conditions / 适用条件

选“两个碰撞物体”为系统，取所需方向。该方向上的外冲量可忽略，才可令总动量守恒；水平碰撞中，重力可能仍存在，但它不提供水平冲量。 / Apply momentum conservation along a direction with negligible external impulse.

对“球撞固定墙”，球本身的动量不守恒；分析球的反弹用冲量，或把墙和地球纳入更大的系统。 / A ball alone is not a momentum-conserving system in a wall collision.

Formula / 公式

一维、带符号速度： / Signed velocities in one dimension:

\[m_1u_1+m_2u_2=m_1v_1+m_2v_2.\]
\[K_i=\frac12m_1u_1^2+\frac12m_2u_2^2,\qquad K_f=\frac12m_1v_1^2+\frac12m_2v_2^2.\]

弹性分支： 联立动量守恒与 \(K_i=K_f\)。 / Use both total momentum and total kinetic-energy conservation.

粘合分支： \(v_1=v_2=V\)，因此

\[V=\frac{m_1u_1+m_2u_2}{m_1+m_2}.\]

只知非弹性： 通常不能仅凭一条动量方程求两个未知末速度；须使用题目补充的速度、能量变化或“共同运动”条件。 / An unspecified inelastic collision generally needs an additional condition.

能量变化 / Energy account

普通耗散碰撞的动能减少量 \(E_{\rm transferred}=K_i-K_f\)，可进入内能、形变或声音。系统及环境的总能量仍守恒。 / Reduced kinetic energy is transferred to other forms; total energy of the complete system is conserved.

数值图解 / Numerical illustration

图中共同初始条件 / Common initial state: \(m_1=2\,\mathrm{kg}\)，\(u_1=3\,\mathrm{m\,s^{-1}}\)；\(m_2=1\,\mathrm{kg}\)，\(u_2=0\)；外冲量可忽略。三种结果的总动量都为 \(6\,\mathrm{kg\,m\,s^{-1}}\)，但总动能不同。 / Equal total momentum does not imply equal kinetic energy.

解题流程 / Method

  1. 圈出碰撞前后、两物体、质量和速度方向。 / Identify both bodies and signed velocities immediately before and after impact.
  2. 明确系统与外冲量条件，再写动量方程。 / State the system and conservation condition.
  3. 从 elastic 或 move together 选择补充方程，求未知量。 / Choose the extra equation from the collision condition.
  4. 比较总动能，说明转移；需要单个物体的平均力时转到冲量模型。 / Compare total kinetic energy and use impulse for a single body's average force.

复述检查 / Retrieval check

“两球碰后仍然分开，所以碰撞是弹性的”是否正确？ / Does separation prove elasticity?

复述答案 / Retrieval answer

不正确。图中中间分支碰后分开，但总动能由9 J变为6.75 J。弹性须检查系统总动能是否守恒。 / No. The separated example loses kinetic energy; elasticity concerns total kinetic energy.
