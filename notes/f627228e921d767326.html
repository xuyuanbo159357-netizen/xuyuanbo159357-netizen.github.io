Concept / 概念

Extension / 伸长量；Spring constant / 弹簧常量；Elastic deformation / 弹性形变；Elastic limit / 弹性极限；Limit of proportionality / 比例极限；Hooke's law / 胡克定律

Definition / 定义

Extension / 伸长量

EN: Extension is the increase in length from the original unstretched length.

中: 伸长量是相对于原始未拉伸长度的长度增加量。

Spring constant / 弹簧常量

EN: The spring constant of a Hookean spring is the force required per unit extension.

中: 遵守胡克定律的弹簧，其弹簧常量是单位伸长量所需的力。

依据 / Evidence: PH01 202506 Q03.1 · MS p6（相关计算或应用）

Elastic deformation / 弹性形变

EN: Elastic deformation is deformation that is fully reversed when the deforming force is removed.

中: 弹性形变在使物体形变的力移除后能够完全恢复。

表达要点 / Wording: returns to original shape or length; force removed

依据 / Evidence: PH01 202101 Q08.1 · MS p12（相关计算或应用）

Elastic limit / 弹性极限

EN: The elastic limit is the maximum force a material can withstand before it begins to undergo plastic deformation.

中: 弹性极限是材料开始发生塑性形变前所能承受的最大力。

表达要点 / Wording: maximum force; before plastic deformation

依据 / Evidence: PH01 202606 Q01.1 · MS p4（定义/陈述评分点）

Limit of proportionality / 比例极限

EN: The limit of proportionality is the point beyond which extension is no longer directly proportional to the applied force.

中: 比例极限是超过后伸长量不再与所施加的力成正比的点。

表达要点 / Wording: last point; Hooke's law; proportional

依据 / Evidence: PH01 202606 Q01.2 · MS p4（定义/陈述评分点）

Statement / 定律陈述

Hooke's law / 胡克定律

EN: The extension of a spring is directly proportional to the applied force, provided the limit of proportionality is not exceeded.

中: 未超过比例极限时，弹簧的伸长量与所施加的力成正比。

表达要点 / Wording: extension; directly proportional; limit of proportionality

Formula / 公式

\[\begin{gathered} \Delta L=L-L_0 \\ F=k\Delta L \\ k=\frac{F}{\Delta L} \end{gathered}\]

Conditions / 适用条件

弹簧常量用于胡克定律比例范围；比例极限和弹性极限分别描述比例关系与可恢复性。 / A constant spring constant describes the Hookean range; proportionality and elasticity are separate limits.

Explanation / 讲解

伸长与比例关系 / Extension and proportionality

在比例极限以内，伸长量与拉力成正比：

\[F=k\Delta L,\qquad[k]=\mathrm{N\,m^{-1}}.\]
\(k\) 是弹簧常量或刚度，\(\Delta L=L-L_0\) 是伸长量，不是总长度。Stiffness is the slope of a force-versus-extension line.

弹性形变指卸载后可恢复原状。弹性极限为超过后会留下永久形变的边界。比例极限为线性关系终止的位置，两者不必相同。A material can be elastic without obeying Hooke’s law over the whole range.

图像与比较 / Graphs and comparison

F–ΔL图在比例范围内是直线，斜率为k。若绘制的是ΔL–F，斜率为1/k。Check which quantity is on each axis.

更大的k表示同样伸长需要更大的力，但材料的杨氏模量还要消除长度与截面积影响。Object stiffness depends on geometry as well as material.

图示：伸长量与原长 / Extension and original length

读图 / Reading： 比较加砝码前后同一指针位置，伸长量是长度变化而不是弹簧总长；逐级加、卸载可检查是否超过弹性极限。

Extension is the change from original length, not the total length. Load and unload in steps to check elastic recovery.

Application / 应用

来源中的补充应用 / Supplementary slide application

原PPT含理想弹簧串并联：并联共同伸长时 \(k_{\rm eq}=k_1+k_2\)；串联相同张力时 \(1/k_{\rm eq}=1/k_1+1/k_2\)。这是对F=kΔL的推导应用，考纲没有另列为必记公式。These results can be derived from force and extension conditions.

D24 方法 1 · 伸长、组合弹簧与比例限制 / Extension and spring combinations

  1. 胡克定律 \(F=k\Delta L\) 只在比例区使用；\(\Delta L\) 是长度变化，不是总长度。\(F\)–\(\Delta L\) 斜率为 \(k\)，反轴图斜率为 \(1/k\)（仅线性区）。 / Read the axes before using a gradient.
  2. 串联同力、伸长相加，\(1/k_{eq}=\sum1/k\)；并联同伸长、力相加，\(k_{eq}=\sum k\)；分支先化简再组合。 / Use the physical constraint of each connection.
  3. 弹性极限是卸载不再完全恢复之前的限度，比例极限是胡克定律停止适用的位置，两者不必相同。 / Distinguish recoverability from linearity.
  4. 非线性图不要把切线“刚度”与整体 \(F/\Delta L\) 混用；按题给定义或所求工作点解释。 / Define the stiffness measure for a nonlinear element.
  5. 由静力求 \(k\) 时载荷包括题设全部悬挂质量；换较软弹簧可增伸长，但需检查测量范围和安全限度。 / Include the actual supported load.
