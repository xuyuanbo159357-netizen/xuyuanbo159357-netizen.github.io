1. 伸长量、胡克定律与刚度 / Extension, Hooke’s law and stiffness

1.1 关键概念与定义 / Key concepts and definitions

Extension / 伸长量

Definition / 定义

EN: Extension is the increase in length from the original unstretched length.

中: 伸长量是相对于原始未拉伸长度的长度增加量。

Formula / 公式

\[\Large\displaystyle \Delta L=L-L_0\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(\Delta L\) 伸长量 / extension \(\mathrm{m}\)
\(L\) 长度 / length \(\mathrm{m}\)
\(L_{0}\) 原长 / original length \(\mathrm{m}\)

物理规律与含义 / Law and meaning

伸长量是受力后长度减原长，不能用最终长度替代伸长量。

Extension is final length minus original length.

伸长量与原长 / Extension and original length

读图 / Reading： 比较加砝码前后同一指针位置，伸长量是长度变化而不是弹簧总长；逐级加、卸载可检查是否超过弹性极限。

Extension is the change from original length, not the total length. Load and unload in steps to check elastic recovery.

Spring constant / 弹簧常量

Definition / 定义

EN: The spring constant of a Hookean spring is the force required per unit extension.

中: 遵守胡克定律的弹簧，其弹簧常量是单位伸长量所需的力。

依据 / Evidence: PH01 202506 Q03.1 · MS p6（相关计算或应用）

Formula / 公式

Conditions / 条件与说明： 适用于线性胡克区；单位为每米牛顿。 / For the linear Hookean region; unit newtons per metre.

\[\Large\displaystyle k=\frac{F}{\Delta L}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(k\) 劲度系数 / spring constant, stiffness \(\mathrm{N\,m^{-1}}\)
\(F\) 力 / force \(\mathrm{N}\)
\(\Delta L\) 伸长量 / extension \(\mathrm{m}\)

物理规律与含义 / Law and meaning

劲度系数是在胡克定律范围内，拉力与伸长量之比。

Spring stiffness is force divided by extension in the Hooke’s law region.

1.2 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle F=k\Delta L\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(F\) 力 / force \(\mathrm{N}\)
\(k\) 劲度系数 / spring constant, stiffness \(\mathrm{N\,m^{-1}}\)
\(\Delta L\) 伸长量 / extension \(\mathrm{m}\)

物理规律与含义 / Law and meaning

胡克定律说明弹性区域内拉力大小与伸长量成正比。

Hooke’s law states that force magnitude is proportional to extension in the linear elastic region.

适用条件 / Conditions

不超过比例限度；正负回复方向另按坐标规定。

Stay within the limit of proportionality. Apply the restoring sign separately when using signed coordinates.

1.3 内容解析与细节 / Explanation and details

伸长与比例关系 / Extension and proportionality

在比例极限以内，伸长量与拉力成正比：

\(k\) 是弹簧常量或刚度，\(\Delta L=L-L_0\) 是伸长量，不是总长度。Stiffness is the slope of a force-versus-extension line.

弹性形变指卸载后可恢复原状。弹性极限为超过后会留下永久形变的边界。比例极限为线性关系终止的位置，两者不必相同。A material can be elastic without obeying Hooke’s law over the whole range.

图像与比较 / Graphs and comparison

F–ΔL图在比例范围内是直线，斜率为k。若绘制的是ΔL–F，斜率为1/k。Check which quantity is on each axis.

更大的k表示同样伸长需要更大的力，但材料的杨氏模量还要消除长度与截面积影响。Object stiffness depends on geometry as well as material.

2. 弹性形变与两个极限 / Elastic deformation and the two limits

2.1 关键概念与定义 / Key concepts and definitions

Elastic deformation / 弹性形变

Definition / 定义

EN: Elastic deformation is deformation that is fully reversed when the deforming force is removed.

中: 弹性形变在使物体形变的力移除后能够完全恢复。

表达要点 / Wording: returns to original shape or length; force removed

依据 / Evidence: PH01 202101 Q08.1 · MS p12（相关计算或应用）

Elastic limit / 弹性极限

Definition / 定义

EN: The elastic limit is the maximum force a material can withstand before it begins to undergo plastic deformation.

中: 弹性极限是材料开始发生塑性形变前所能承受的最大力。

表达要点 / Wording: maximum force; before plastic deformation

依据 / Evidence: PH01 202606 Q01.1 · MS p4（定义/陈述评分点）

Limit of proportionality / 比例极限

Definition / 定义

EN: The limit of proportionality is the point beyond which extension is no longer directly proportional to the applied force.

中: 比例极限是超过后伸长量不再与所施加的力成正比的点。

表达要点 / Wording: last point; Hooke's law; proportional

依据 / Evidence: PH01 202606 Q01.2 · MS p4（定义/陈述评分点）

关联原理 / Related principles： Hooke's law / 胡克定律。定律陈述见本页 Law statement 部分。 / See the Law statement section below.

2.2 内容解析与细节 / Explanation and details

Conditions / 适用条件

弹簧常量用于胡克定律比例范围；比例极限和弹性极限分别描述比例关系与可恢复性。 / A constant spring constant describes the Hookean range; proportionality and elasticity are separate limits.

3. 串并联弹簧 / Springs in series and parallel

3.1 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle k_{\mathrm{eq}}=k_1+k_2\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(k_{\mathrm{eq}}\) 等效劲度系数 / equivalent spring stiffness \(\mathrm{N\,m^{-1}}\)
\(k_{1}\) 状态 1 的劲度系数 / state-1 spring constant, stiffness \(\mathrm{N\,m^{-1}}\)
\(k_{2}\) 状态 2 的劲度系数 / state-2 spring constant, stiffness \(\mathrm{N\,m^{-1}}\)

物理规律与含义 / Law and meaning

并联弹簧伸长相同，拉力相加，因此等效劲度系数相加。

Parallel springs have equal extension and their forces add, so the equivalent stiffness is the sum.

\[\Large\displaystyle \frac{1}{k_{\mathrm{eq}}}=\frac{1}{k_1}+\frac{1}{k_2}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(k_{\mathrm{eq}}\) 等效劲度系数 / equivalent spring stiffness \(\mathrm{N\,m^{-1}}\)
\(k_{1}\) 状态 1 的劲度系数 / state-1 spring constant, stiffness \(\mathrm{N\,m^{-1}}\)
\(k_{2}\) 状态 2 的劲度系数 / state-2 spring constant, stiffness \(\mathrm{N\,m^{-1}}\)

物理规律与含义 / Law and meaning

串联弹簧张力相同，总伸长为各段伸长之和，因此等效劲度系数的倒数相加。

Series springs have equal tension and additive extensions, so their reciprocal stiffnesses add.

3.2 内容解析与细节 / Explanation and details

来源中的补充应用 / Supplementary slide application

原学习资料含理想弹簧串并联：并联共同伸长时 \(k_{\rm eq}=k_1+k_2\)；串联相同张力时 \(1/k_{\rm eq}=1/k_1+1/k_2\)。这是对F=kΔL的推导应用，考纲没有另列为必记公式。These results can be derived from force and extension conditions.

速查、练习与联系 / Reference, practice and connections

Statement / 定律陈述

Hooke's law / 胡克定律

EN: The extension of a spring is directly proportional to the applied force, provided the limit of proportionality is not exceeded.

中: 未超过比例极限时，弹簧的伸长量与所施加的力成正比。

表达要点 / Wording: extension; directly proportional; limit of proportionality

考点精讲：瞬时静止与恢复力 / Instantaneous rest and restoring force

弹簧或物体达到最大压缩时可以瞬时静止，但形变仍存在，因此恢复力不一定为零，加速度也不一定为零。先根据几何画恢复力方向，再结合其他实际力判断合力；不能用“速度为零”代替受力分析。

At maximum compression an object may be instantaneously at rest while the deformation and restoring force remain. Zero speed does not imply zero acceleration. Draw the restoring force from the geometry and combine it with the other real forces.

D24 方法 1 · 伸长、组合弹簧与比例限制 / Extension and spring combinations

  1. 胡克定律 \(F=k\Delta L\) 只在比例区使用；\(\Delta L\) 是长度变化，不是总长度。\(F\)–\(\Delta L\) 斜率为 \(k\)，反轴图斜率为 \(1/k\)（仅线性区）。 / Read the axes before using a gradient.
  2. 串联同力、伸长相加，\(1/k_{eq}=\sum1/k\)；并联同伸长、力相加，\(k_{eq}=\sum k\)；分支先化简再组合。 / Use the physical constraint of each connection.
  3. 弹性极限是卸载不再完全恢复之前的限度，比例极限是胡克定律停止适用的位置，两者不必相同。 / Distinguish recoverability from linearity.
  4. 非线性图不要把切线“刚度”与整体 \(F/\Delta L\) 混用；按题给定义或所求工作点解释。 / Define the stiffness measure for a nonlinear element.
  5. 由静力求 \(k\) 时载荷包括题设全部悬挂质量；换较软弹簧可增伸长，但需检查测量范围和安全限度。 / Include the actual supported load.
