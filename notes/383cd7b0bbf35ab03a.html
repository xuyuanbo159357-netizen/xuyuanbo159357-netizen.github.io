弹簧形变与弹性储能模型 / Spring and extension

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
spring constant / stiffness 弹簧常量 / 劲度 比例范围内F–伸长图的斜率 / Force–extension gradient in the proportional range.
extension / unstretched length 伸长量 / 未伸长原长 伸长量等于末长度减原长 / Extension is final length minus natural length.
Hooke's law 胡克定律 F与伸长量成正比 / Force is proportional to extension.
area / elastic energy 面积 / 弹性储能 检查是否为F–伸长坐标 / Check the actual graph axes.
elastic limit 弹性极限 检查卸载是否能完全恢复 / Check reversibility on unloading.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

比例范围内弹簧有固定 \(k\)；弹性范围说明卸载后可恢复，两者不是同一个条件。 / Proportional behaviour and recoverable deformation are distinct properties.

读图 / Reading: 线性加载图的三角形面积为½FΔL；把全部加载功视作可恢复储能还要求耗散可忽略。 / The triangle area is ½FΔL; full recoverability assumes negligible dissipation.

Formula / 公式

\[x=L-L_0,\qquad F=kx.\]

从未伸长状态开始、线性弹性形变时： / From the unstretched state in the linear elastic range:

\[U_{el}=\frac12Fx=\frac12kx^2.\]

解题流程 / Method

  1. 先求伸长量 \(x\)，统一N、m单位。 / Find extension and use consistent force and length units.
  2. 静止悬挂时由受力平衡求弹簧力，再用 \(F=kx\)。 / Determine spring force from equilibrium before using Hooke's law.
  3. 一般用F为纵轴、x为横轴的面积求做功。若图线是过原点的比例直线，交换坐标轴后的三角形面积数值仍为 \(\frac12Fx\)，同样等于拉伸功；先检查图线条件。 / For a proportional straight line through the origin, either axis order gives the triangular area of half force times extension. The general work relation uses force plotted against extension.
  4. 求伸长变化引起的储能变化，使用 \(\frac12k(x_f^2-x_i^2)\)。 / Compare the two stored energies.

易错判断 / Checks

伸长加倍，在k不变时，弹簧力变2倍、储能变4倍。 切断附加载荷的瞬间，弹簧原有伸长尚未改变，应重新求合力。 / A load change does not instantaneously reset extension.
