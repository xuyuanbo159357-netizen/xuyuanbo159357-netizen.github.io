3.1 测量与数据处理 / Cross-unit data analysis

测量与误差是所有单元的共同基础。需掌握单位换算、有效数字、随机与系统误差、不确定度合成、梯度与截距、图像线性化和实验控制变量。 These skills are shared across units: units, significant figures, errors, combined uncertainty, gradients/intercepts, linearisation and control variables.

考点精讲：科学测量如何获得共同认可 / How scientific measurements gain acceptance

测量值更接近公认值，支持其准确度更高；这不等于散布更小或精密度更高。对科学共同体接受某结果的题型，应说明公开实验方法和结果，使其他科学家能够用相同方法重复实验，并检查结果是否一致。

A value closer to the accepted value supports greater accuracy, not necessarily greater precision. For acceptance by the scientific community, publish the method and result so other scientists can repeat the experiment and compare results.
