知识逐项讲解 / Concept-by-concept guide

Distance travelled / 路程

Definition / 定义

EN: Distance travelled is the total length of the path followed by an object.

中: 路程是物体所走路径的总长度。

依据 / Evidence: PH01 202306 Q06.2 · MS p9（相关计算或应用）

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(s_{\mathrm{path}}\) 路程 / distance travelled \(\mathrm{m}\)

Displacement / 位移

Definition / 定义

EN: Displacement is the change in position from the initial point to the final point, including direction.

中: 位移是从初位置到末位置的位置变化，包含方向。

依据 / Evidence: PH01 202306 Q06.3 · MS p9（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \Delta s=s_f-s_i\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\Delta s\) 位移变化 / change in displacement \(\mathrm{m}\)
\(s_i,s_f\) 初、末位置坐标 / initial and final position coordinates \(\mathrm{m}\)

Speed / 速率

Definition / 定义

EN: Speed is the rate at which distance is travelled.

中: 速率是路程随时间的变化率。

Formula / 公式

\[\Large\displaystyle v_{\mathrm{speed}}=|v|\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(v_{\mathrm{speed}}\) 速率 / speed \(\mathrm{m\,s^{-1}}\)
\(v\) 沿所选直线轴的带符号速度 / signed velocity along the chosen axis \(\mathrm{m\,s^{-1}}\)

Conditions / 条件与说明： 直线运动中速率为带符号速度的绝对值；瞬时速率可由路程—时间图像在该点的切线斜率求得。 / In straight-line motion speed is the absolute value of signed velocity; instantaneous speed is the tangent gradient of a distance–time graph.

Average speed / 平均速率

Definition / 定义

EN: Average speed is the total distance travelled divided by the total time taken.

中: 平均速率是总路程除以总时间。

依据 / Evidence: PH01 202306 Q06.2 · MS p9（相关计算或应用）

Formula / 公式

\[\Large\displaystyle v_{\mathrm{avg,speed}}=\frac{s_{\mathrm{total}}}{\Delta t}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(v_{\mathrm{avg,speed}}\) 平均速率 / average speed \(\mathrm{m\,s^{-1}}\)
\(s_{\mathrm{total}}\) 总路程 / total distance travelled \(\mathrm{m}\)
\(\Delta t\) 总时间 / total elapsed time \(\mathrm{s}\)

Velocity / 速度

Definition / 定义

EN: Velocity is the rate of change of displacement.

中: 速度是位移随时间的变化率。

表达要点 / Wording: displacement; rate of change; direction

Formula / 公式

\[\Large\displaystyle v=\left(\frac{\Delta s}{\Delta t}\right)_{\mathrm{tangent}}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(v\) 瞬时速度 / instantaneous velocity \(\mathrm{m\,s^{-1}}\)
\(\Delta s\) 位移—时间图像切线上两点的纵坐标差 / vertical change between two points on the tangent \(\mathrm{m}\)
\(\Delta t\) 这两点的横坐标差 / corresponding horizontal time interval \(\mathrm{s}\)

Conditions / 条件与说明： 比值取该时刻切线的斜率，不能随意取曲线上两个时刻的割线斜率；后者给出平均速度。 / Use the tangent at the instant; a secant through two points of the motion curve instead gives average velocity.

Average velocity / 平均速度

Definition / 定义

EN: Average velocity is the change in displacement divided by the time interval.

中: 平均速度是位移变化除以对应时间间隔。

依据 / Evidence: PH01 202306 Q06.3 · MS p9（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \bar v=\frac{\Delta s}{\Delta t}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\bar v\) 平均速度 / average velocity \(\mathrm{m\,s^{-1}}\)
\(\Delta s\) 位移变化 / change in displacement \(\mathrm{m}\)
\(\Delta t\) 时间间隔 / time interval \(\mathrm{s}\)

Acceleration / 加速度

Definition / 定义

EN: Acceleration is the rate of change of velocity.

中: 加速度是速度随时间的变化率。

表达要点 / Wording: rate of change; velocity

Formula / 公式

\[\Large\displaystyle \bar a=\frac{v-u}{\Delta t}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\bar a\) 平均加速度 / average acceleration \(\mathrm{m\,s^{-2}}\)
\(u,v\) 初、末速度 / initial and final velocities \(\mathrm{m\,s^{-1}}\)
\(\Delta t\) 时间间隔 / time interval \(\mathrm{s}\)

Conditions / 条件与说明： 匀加速时该比值也等于各时刻的加速度；瞬时加速度取速度—时间图像的切线斜率。 / For constant acceleration this ratio also equals the instantaneous acceleration; otherwise use the tangent gradient of the velocity–time graph.

Formula / 公式

\[\Large\displaystyle v_{\mathrm{avg,speed}}=\frac{\text{total distance}}{\Delta t}\]
\[\Large\displaystyle \bar v=\frac{\Delta s}{\Delta t}\]
\[\Large\displaystyle \bar a=\frac{\Delta v}{\Delta t}\]

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
位移 / displacement \(s,\ x\) \(\mathrm{m}\) 一维正负号表示方向 / A sign gives direction in one dimension.
路程、距离 / distance \(d\) \(\mathrm{m}\) 路程是标量 / Distance travelled is scalar.
速率 / speed \(v\) \(\mathrm{m\,s^{-1}}\) 速度的大小 / Magnitude of velocity.
速度 / velocity \(v,\ \bar v\) \(\mathrm{m\,s^{-1}}\) 矢量；上横线表示平均速度 / Vector; the overbar denotes mean velocity.
初速度 / initial velocity \(u\) \(\mathrm{m\,s^{-1}}\) 运动方程中的初值 / Initial value in motion equations.
加速度 / acceleration \(a,\ \bar a\) \(\mathrm{m\,s^{-2}}\) 上横线表示平均加速度 / The overbar denotes mean acceleration.
时间、时间间隔 / time, time interval \(t,\ \Delta t\) \(\mathrm{s}\)
平均速率 / average speed \(v_{\mathrm{avg,speed}}\) \(\mathrm{m\,s^{-1}}\)

Conditions / 适用条件

用有限时间间隔计算的变化量之比是平均量。瞬时速度由指定时刻的位移–时间图切线斜率确定。 / Ratios over finite intervals give averages; a tangent gives instantaneous velocity.

Explanation / 讲解

物理量辨析 / Quantity distinctions

量 / Quantity 定义 / Definition 单位 / Unit
路程 distance 走过路径的总长度 / total path length m
位移 displacement 起点到终点的位置变化，含方向 / directed change of position m
平均速率 average speed 总路程/总时间 / total distance divided by time m s⁻¹
平均速度 average velocity \(\Delta s/\Delta t\)，保留方向 / displacement divided by interval m s⁻¹
平均加速度 average acceleration \(\Delta v/\Delta t\) / velocity change divided by interval m s⁻²

瞬时量表示某一时刻的量，瞬时速度由位移时间图像的切线斜率给出，瞬时速率为其大小。Instantaneous quantities describe one instant; instantaneous speed is the magnitude of instantaneous velocity.

正负号与方向 / Signs and direction

先选定正方向。沿负方向的速度用负号表示。加速度与速度同向时速率增加，反向时速率减小。Choose a positive axis and compare the signs of \(v\) and \(a\).

负加速度不自动意味着减速；例如 \(v=-4\) m s⁻¹、\(a=-2\) m s⁻² 时速率增加。Negative acceleration gives a direction, not a universal statement about speed.

往返到起点时总位移和平均速度为零，但总路程与平均速率可不为零。A round trip distinguishes distance from displacement.

图示：路程与位移 / Distance and displacement

读图 / Reading： 按图中路线计算路程；位移只看初、末位置及方向。同一对端点可以对应不同路程。

Distance follows the route; displacement depends only on endpoints and direction. Different routes can have the same displacement.

D07 方法 1 · 位移、平均速度与速度变化 / Displacement and changes of velocity

  1. 平均速率 = 总路程/总时间；平均速度 = 总位移/总时间，方向随位移。圆周整圈位移为零，半圈位移大小为直径。 / Use the endpoint displacement, not the arc length.
  2. \(\Delta\mathbf v=\mathbf v_f-\mathbf v_i\)，把初速度反向后相加；同速半圈的速度变化大小为 \(2v\)，不是零。 / Subtract vectors explicitly.
  3. 距离—时间图不可下降，位移—时间图可下降；折返后已走路程仍增加。 / Identify what the vertical axis measures.
