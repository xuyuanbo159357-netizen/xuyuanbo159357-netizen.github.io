辐射吸收与厚度检测模型 / Absorption and thickness

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
absorber / penetrating 吸收物 / 有穿透力的 通过纸、铝、铅等实验比较辐射 / Compare transmission through specified absorbers.
thickness / gauge 厚度 / 测厚装置 透射计数随材料厚度改变 / Transmitted count rate responds to thickness.

核心模型与条件 / Model and conditions

射线通过材料时，一部分被吸收、一部分到达探测器。测厚须在合适厚度范围内仍有可测透射，且厚度变化能明显改变计数。 / Useful monitoring requires measurable and thickness-sensitive transmission.

对应关系 / Interpretation

条件 / Condition 模型判断 / Interpretation
同源、同距离，材料更厚 / same source and geometry, thicker sheet 修正透射计数一般更低 / lower transmitted source count rate
几乎全被吸收 / almost complete absorption 难以区分更厚材料 / little useful transmitted signal
几乎全穿过 / almost complete transmission 厚度灵敏度可能不足 / weak sensitivity to thickness
内部与外部暴露 / internal vs external exposure 危害比较还取决于电离、穿透和停留时间 / compare ionisation, penetration and persistence

解题流程 / Method

  1. 先扣背景，保持几何条件、源及探测条件一致。 / Correct for background and control geometry.
  2. 依据材料厚度与穿透能力选择能被部分吸收的辐射。 / Select radiation with useful partial transmission.
  3. 解释控制方向：在同样条件下，计数偏低可提示材料偏厚。 / Infer thickness from the controlled count rate.
  4. 医学示踪物理题中，讨论可体外探测的辐射和适合检查时长的半衰期。 / In tracer exam questions, relate detection and persistence to the application.

易错判断 / Checks

材料名称不是唯一判断条件，厚度也重要。 α外部穿透弱，不代表进入体内后危害小。 / Penetration and ionisation must be considered together.
