本单元备考重点 / Unit-specific preparation

热学系统 / Thermal systems

先定系统和做功符号；pV面积与热量不同，分子解释要连到动量变化率。 Define the system and signs; connect molecular motion to macroscopic quantities.

核能计算 / Nuclear energy

区分核子数与质子数、每核子结合能与总结合能、质量亏损与反应质量差。 Distinguish nucleon number, binding-energy scales and mass differences.

转动与能源 / Rotation and resources

转动惯量、角动量、转动动能选择不同守恒条件；能源比较需对应题设情境。 Select the rotational constraint and compare the specified energy systems.

按题型落实 / Applying the command

类型 / Type 答题动作 / What to do
计算 / Calculation 明确模型与适用条件→列方程→SI代入→中间量→结果及单位；需要判断时补结论。 State the model, equation, substitution, result and conclusion.
画图 / Drawing 看清draw或sketch；坐标、量名、单位、起点、峰值、渐近线和方向按题意标明，直线用尺。 Label the requested features and use a ruler for straight lines.
陈述 / Statement 按state/name/define区分名称、事实和严格定义，避免只写符号替代名称。 Match the requested level of recall.
解释 / Explanation 条件或原因→物理关系→变化方向→题境结论；不能只给公式或只复述现象。 Develop the causal link.
实验 / Practical 装置、变量、读数、控制、重复、处理、误差改进形成完整路径；改进应针对已识别偏差。 Tie the procedure and improvements to the experiment.
证明与推断 / Show or deduce 从原理出发展示链条；数值show that显示足够位数以验证给定近似值；deduce需推导或结论依据。 Show the reasoning rather than repeat the supplied result.

考官报告回看 / Examiner-report review

本地有14/15场官方报告；缺失场次未编造考生表现数据。 Reports are available for 14 of 15 papers in the collection.

2018年6月 / June

  • 风能损失要指出机制，不能只写效率低于100%。 Identify physical loss mechanisms rather than merely stating inefficiency. 报告第2页 / Report p2

  • 最近接距离用初动能与电势能联系；分清它与真实核半径的差别。 Use energy conservation for closest approach and recognise its limit as a radius estimate. 报告第3页 / Report p3

2019年1月 / January

  • 计算和解释要有清晰结构；本次早期考生人数较少，表现描述应谨慎解读。 Set out arguments clearly and interpret this small early cohort cautiously. 报告第2页 / Report p2

  • 每核子结合能先乘核子数；原子质量单位必须正确换算。 Convert binding energy per nucleon to total binding energy and handle atomic mass units. 报告第3页 / Report p3

2019年6月 / June

  • 陌生情境仍需展示可识别的计算步骤与有效数字。 Keep numerical working recognisable in unfamiliar contexts. 报告第2页 / Report p2

  • 重复值的不确定度用半极差而非全极差；验证核密度后要写结论。 Use half the range for repeated-value uncertainty and conclude density comparisons. 报告第3页 / Report p3

2020年1月 / January

  • 题干数据可能供后面任何小问使用；合力计算须计入氦气自身重量。 Use stem data across subparts and include the gas weight in force balances. 报告第2页 / Report p2

  • 冰箱能量收支不能漏掉食物放热，热泵要明确系统与环境的对应关系。 Include food cooling in the refrigerator balance and identify heat-pump energy flows. 报告第3页 / Report p3

2022年1月 / January

  • “随温度增加”弱于“与绝对温度成正比”，应按物理关系准确表述。 Distinguish an increase from direct proportionality to absolute temperature. 报告第2页 / Report p2

  • 抽水蓄能储存能量而非功率；泵水投入大于发电输出。 Pumped storage stores energy, not power, and pumping requires more energy than generation returns. 报告第3页 / Report p3

2022年6月 / June

  • 气体压强解释需把分子速度、碰撞、动量变化率和力连成因果链。 Link molecular motion, collisions, momentum-change rate and force. 报告第2页 / Report p2

  • 转速改变时不能用恒角速度关系；同储能飞轮比较需同时考虑转动惯量和角速度。 Account for variable angular speed and compare inertia together with speed at fixed stored energy. 报告第3页 / Report p3

2023年1月 / January

  • 符号I在光强题中不是电流；反平方检验可比较Id²。 Interpret symbols in context; test inverse-square behaviour using Id². 报告第2页 / Report p2

  • 备用电源解释要说储存形式；水轮机力矩需由水的动量变化追溯到力。 Specify the stored energy form and connect water momentum change to turbine torque. 报告第3页 / Report p3

2023年6月 / June

  • 布朗运动解释应区分可见烟粒与不可见气体分子，并把观察与推断对应。 Distinguish smoke particles from gas molecules and connect observations to inferences. 报告第2页 / Report p2

  • 保温效果要结合系统为维持输出而升高的工作温度判断。 Evaluate insulation in the actual operating-temperature context. 报告第3页 / Report p3

2024年1月 / January

  • 一般物体内能包括动能和势能；理想气体模型才可忽略分子势能。 Distinguish general internal energy from the ideal-gas kinetic-only model. 报告第2页 / Report p2

  • 改进实验需针对低于公认值这一偏差，不可把准确度与精密度混同。 Address the stated bias when improving an experiment and distinguish accuracy from precision. 报告第3页 / Report p3

2024年6月 / June

  • 平均交流功率用有效值；比较题需比较题目指定的两种水电形式。 Use rms values for mean ac power and compare the specified hydroelectric systems. 报告第2页 / Report p2

  • 两核最近接问题需考虑双方初动能及剩余整体运动，不能默认末动能为零。 Account for both nuclei and any remaining motion at closest approach. 报告第3页 / Report p3

2025年1月 / January

  • deduce后要给是否认同的判断；分子压强解释不能停在碰撞。 Give an explicit deduction and develop pressure explanations beyond collisions. 报告第2页 / Report p2

  • pV图做功注意非零坐标起点；验证等温需分别算出两个pV值。 Account for false origins and compare numerical pV values when testing isothermality. 报告第3页 / Report p3

2025年6月 / June

  • 数据记录器的优势应联系长时间实验等情境；曲线上变化率需准确作切线。 Relate logger advantages to the experiment and draw accurate tangents. 报告第2页 / Report p2

  • 核半径参数用题目数据；质子与中子质量不能无条件视为相同。 Use the supplied nuclear-radius data and distinct proton and neutron masses. 报告第3页 / Report p3

2026年1月 / January

  • 体积须对应所求对象，不可把气体与固体体积混用。 Use the volume of the intended object rather than a neighbouring component. 报告第2页 / Report p2

  • 多材料加热与相变计算分别计入各能量项，避免过早取整。 Include each heating and phase-change contribution and avoid early rounding. 报告第3页 / Report p3

2026年6月 / June

  • kWh转J后再算燃料质量，结合效率区分输入与有效输出。 Convert kWh to joules and distinguish input from useful energy. 报告第2页 / Report p2

  • 气体计算核对K温标、阿伏伽德罗常量、球体积及单粒子质量。 Check kelvin temperature, Avogadro conversion, spherical volume and particle mass. 报告第3页 / Report p3

自测与时间分配 / Practice and timing

每套120分钟、80分，平均1.5分钟/分可作为训练预算；这不是官方逐题用时要求。先完成可得分步骤，标记未完成题，最后核对单位、图线与结论。 A 1.5-minute-per-mark budget is a teaching aid, not an official timing rule.
