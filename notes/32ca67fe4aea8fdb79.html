本卷复盘重点 / Paper-specific review

  • 体积须对应所求对象，不可把气体与固体体积混用。 Use the volume of the intended object rather than a neighbouring component. 报告第2页 / Report p2

  • 多材料加热与相变计算分别计入各能量项，避免过早取整。 Include each heating and phase-change contribution and avoid early rounding. 报告第3页 / Report p3

  • 转动运动 / Rotational Motion：15分，18.75%。 回看 / Review：3.13.1 转动运动学、转动惯量与角动量。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 理想气体 / Ideal Gases：12分，15.00%。 回看 / Review：3.11.3 气体定律与理想气体。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 原子核半径 / Radius Of The Nucleus：12分，15.00%。 回看 / Review：3.12.1 核半径、最接近距离与电子衍射。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.
