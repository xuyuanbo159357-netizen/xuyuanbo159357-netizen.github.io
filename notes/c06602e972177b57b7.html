U1 计算与证明 / Calculations and show-that questions

U1 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 计算题的书写链 / A readable calculation

物理关系 → 带单位或已换算的数据代入 → 运算 → 数值、单位及方向 → 检查。 / Physical relationship → consistent substitution → calculation → value, unit and direction → check.

这是推荐书写方式；是否必须展示某一步，以该题评分标准为准。不能假设只有最终正确数字就一定获得全部方法分。 / This is a presentation recommendation; the question's rubric determines which steps are required.

2. 先确定分量、正方向与研究系统 / Components, signs and system

  • 抛体的水平、竖直分运动分开列式；碰撞沿某一方向守恒时，用该方向的速度分量。 / Treat projectile components separately; use the relevant velocity component in momentum conservation.
  • 2026 June Q07.3 水平动量关系采用约 \(2.41\ \mathrm{m\,s^{-1}}\) 的水平分量，不能把合速度 \(4.5\ \mathrm{m\,s^{-1}}\) 直接代入。 / Use the horizontal component, not the full speed. PH01 2026 June Q07.3 · MS PDF p10 · 原题与答案 / Question and answer
  • 动量守恒要说明研究系统及该方向外力合冲量可忽略；非弹性碰撞损失的是系统动能，不能写成“动量不守恒”。 / Identify the system and negligible external impulse; an inelastic collision does not conserve kinetic energy. PH01 2026 June Q07.2 · MS PDF p9 · 原题与答案 / Question and answer

3. 公式适用对象和几何量 / Use the correct quantity

  • 匀加速度方程要求所取时间段加速度恒定；斜面位移配沿斜面加速度，竖直高度配重力势能。 / Match displacement and acceleration directions; use vertical height in gravitational energy.
  • 力矩写 \(F d_\perp\)；\(d_\perp\) 是支点到力作用线的垂直距离。 / Use the perpendicular distance from the pivot to the force's line of action.
  • 杨氏模量写 \(E=FL/(A\Delta L)\)，区分原长 \(L\) 与伸长量 \(\Delta L\)，面积用半径而非把直径直接平方。 / Distinguish original length from extension and radius from diameter. PH01 2018 June Q10.4 · MS PDF p14 · 原题与答案 / Question and answer
  • \(mg\)、\(mv\)、\(\tfrac12mv^2\) 分别是重力、动量和动能，单位也应能相互区分。 / Check the physical quantity and its dimensions before substituting.

4. 判断题必须比较并下结论 / Compare before concluding

2026 June Q05：下滑方向重力分量约 \(22\ \mathrm N\)，最大静摩擦力为 \(25\ \mathrm N\)；必须写出大小比较，并得出“不下滑”。不能只计算一个力就结束。 / Compare the driving component with maximum static friction and state that the block does not slide. PH01 2026 June Q05 · MS PDF p7 · 原题与答案 / Question and answer

2026 June Q09.3：算出约 \(11\ \mathrm J\) 的需求后，还需比较 \(11>9.6\)，再说明锁定机构不能接合。 / A numerical comparison must support the conclusion about the locking mechanism. PH01 2026 June Q09.3 · MS PDF p14 · 原题与答案 / Question and answer

5. 证明题与后续小问 / Show-that questions and later parts

由已知条件独立算出结果，展示足以支持题给近似值的精度。 通常比题给值多展示至少一位有效数字；这是一种稳妥做法，具体仍以题目和评分要求为准。不能把待证明的数值直接代回作为唯一依据。 / Derive the result independently and show sufficient precision to justify the stated approximation. An extra significant figure is a useful presentation convention, not a universal marking rule.

后续小问依本库约定沿用前问答案；证明题沿用题给证明值。错误跟进分 ECF 只在评分标准允许时存在，不代表任意前值都获分。 / Follow the carry-forward convention below; ECF applies only where permitted. 2018 June Q10.4 明确允许跟进前一步斜率，且不再处罚其有效数字。PH01 2018 June Q10.4 · MS PDF p14 · 原题与答案 / Question and answer

核心纠错 / Common correction

不完整 / Incomplete： “Inelastic means momentum is lost.”

推荐 / Recommended： “Kinetic energy is not conserved in an inelastic collision.” 在外力合冲量可忽略的系统内，动量仍守恒。 / Momentum is conserved for the system if external impulse is negligible. PH01 2026 June Q07.2 · MS PDF p9 · 原题与答案 / Question and answer

同一大题的数据沿用 / Carrying answers into later parts

课堂统一答题规范 / Classroom convention

同一大题内，后续小问用到前面小问的答案数据时，直接使用前问已写出的答案数值，不改用计算器内保留的更精确值。前问若为证明题，后续直接使用题目要求证明的数值。

Within the same question, use the numerical answer reported in the earlier part when it is required in a later part, rather than a more precise calculator value. If the earlier part is a show-that question, use the value stated in that question for later parts.

区分两个阶段：同一小问内部保留中间精度；跨小问沿用已报告的答案或题给证明值。 / Within one part, retain intermediate precision; between parts, carry forward the reported answer or the stated show-that value.

这是本知识库采用的课堂统一约定；原评分标准有时还接受其他跟进路线，不将本约定表述成考局所有题目的唯一评分规则。若题目另给指定数据，以该明确指令为准。 / This is the classroom convention used in this vault. Some mark schemes also accept other follow-through routes; it is not presented as the board's sole permitted method. Follow any explicit value separately specified in the question.
