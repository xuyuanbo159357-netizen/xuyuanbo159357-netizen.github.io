抛体独立分运动模型 / Projectile

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.4 抛体运动 - Projectile motion

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
projectile / fired / launched 抛体 / 发射 / 抛出 先检查阻力条件，再分解运动 / Check drag and resolve the motion.
horizontally 水平地 水平抛出时 uᵧ=0；飞行中某时刻水平则 vᵧ=0 / Distinguish launch direction from a later velocity.
angle to the horizontal 与水平的夹角 uₓ=u cosθ，uᵧ=u sinθ / Resolve the launch velocity.
range / time of flight 水平射程 / 飞行时间 先用竖直运动求时间 / Determine time from vertical motion.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

无空气阻力、均匀重力场中，同一个物体的水平与竖直分运动共享同一时间。 / Horizontal and vertical components describe the same flight time.

Formula / 公式

\[a_x=0,\quad a_y=-g,\quad x=u_xt,\quad y=u_yt-\frac12gt^2,\quad v_y=u_y-gt.\]
\[u_x=u\cos\theta,\quad u_y=u\sin\theta,\quad |v|=\sqrt{v_x^2+v_y^2}.\]

解题流程 / Method

  1. 定发射点为参考位置，按题目高度差写竖直位移。 / Use the actual launch-to-landing height difference.
  2. 由竖直方程求时间，再代入水平关系。 / Solve the vertical motion first, then use the same time horizontally.
  3. 求落地速度时合成 \(v_x\) 与 \(v_y\)；方向由分量及象限判断。 / Recombine signed components for speed and direction.

易错判断 / Checks

最高点只有竖直速度为零；若 \(u_x\ne0\)，总速率不为零。只有起落高度相同，才可用 \(T=2u_y/g\) 的对称简式。 / The top is not a state of rest when horizontal velocity is non-zero; equal-height flight formulas need equal heights.

空阻不可忽略时，仅作U1要求的定性轨迹分析，并重新判断水平速度是否恒定。 / Drag invalidates the ideal constant-horizontal-velocity assumption.

读图 / Reading: 水平速度保持不变，竖直速度在重力作用下改变，两分运动使用同一时间。 / Horizontal velocity stays constant; vertical motion accelerates and shares the same time interval.
