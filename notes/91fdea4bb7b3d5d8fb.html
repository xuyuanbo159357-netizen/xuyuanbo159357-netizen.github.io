U1/07 常用物理模型

点源扩散与反平方模型 / Inverse-square law

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.3.3 放射性 - Radioactivity

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
inverse-square 反平方 强度与距离平方成反比 / Intensity varies inversely with distance squared.
distance / gamma source 距离 / γ源 检查点源近似与吸收条件 / Check point-source and attenuation assumptions.
background count rate 本底计数率 先扣本底再比较距离效应 / Subtract background before comparing distances.
straight-line graph 直线图像 用1/r²作为自变量 / Plot against reciprocal distance squared.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

近似点源各向均匀发射时，相同总输出分布到面积随 \(r^2\) 增大的球面上，单位面积接收到的量随 \(1/r^2\) 减小。 / Geometric spreading reduces intensity as the same output covers a larger sphere.

条件：源可近似为点源，吸收影响可忽略，探测器朝向、有效面积及效率保持一致，比较计数率前扣除背景。 / Keep source and detector conditions controlled and correct background.

读图 / Reading: 改变源到探测器的距离，扣除背景，以校正计数率对1/r²的图检验反平方关系。 / Change distance and plot corrected count rate against 1/r².

Formula / 公式

\[I\propto\frac{1}{r^2},\qquad \frac{I_2}{I_1}=\left(\frac{r_1}{r_2}\right)^2,\]
\[R_s=R_{\rm measured}-R_{\rm background},\qquad R_s r^2=\text{constant}.\]

解题流程 / Method

  1. 把距离统一单位，并确认是源到有效探测位置的距离。 / Use the correct source-to-detector distance.
  2. 总计数先换计数率、扣背景，再用平方比。 / Use corrected source rates in the inverse-square ratio.
  3. 距离加倍时源强度变为四分之一，不是二分之一。 / Double distance gives one-quarter intensity.
  4. \(R_s\)对\(1/r^2\)应为过原点直线；若纵轴用总计数率且背景恒定，截距可表示背景。 / The intercept depends on whether background has already been removed.

易错判断 / Checks

几何扩散造成的减弱不等于材料吸收造成的减弱。 更改距离和加入吸收材料不能在未经区分时套同一个比例。 / Separate spreading from attenuation.
