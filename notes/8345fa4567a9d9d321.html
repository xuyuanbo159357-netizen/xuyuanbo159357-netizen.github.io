Concept / 概念

Nuclide / 核素；Proton number / 质子数；Nucleon number / 核子数；Isotopes / 同位素；Ion / 离子

Definition / 定义

Nuclide / 核素

EN: A nuclide is a type of nucleus characterised by its proton number and nucleon number.

中: 核素是由质子数与核子数表征的一类原子核。

依据 / Evidence: PH01 202506 Q17 · MS p19（相关计算或应用）

Proton number / 质子数

EN: The proton number is the number of protons in a nucleus.

中: 质子数是原子核中的质子个数。

依据 / Evidence: PH01 2018 specimen paper Q09.3 · MS p8（相关计算或应用）

Nucleon number / 核子数

EN: The nucleon number is the total number of protons and neutrons in a nucleus.

中: 核子数是原子核中质子数与中子数的总和。

依据 / Evidence: PH01 202101 Q05.2 · MS p8（相关计算或应用）

Isotopes / 同位素

EN: Isotopes are atoms of the same element with the same number of protons but different numbers of neutrons.

中: 同位素是同一元素的原子，质子数相同而中子数不同。

表达要点 / Wording: same proton number; different neutron number

依据 / Evidence: PH01 2018 specimen paper Q09.1 · MS p8（定义/陈述评分点）

Ion / 离子

EN: An ion is an atom that has gained or lost electrons and therefore has a net electric charge.

中: 离子是因得到或失去电子而带有净电荷的原子。

依据 / Evidence: PH01 202201 Q05.1 · MS p9（相关计算或应用）

Formula / 公式

\[\begin{gathered} {}^A_ZX \\ N=A-Z \\ Q_{\rm atom/ion}=(Z-n_e)e \end{gathered}\]

Conditions / 适用条件

普通离子形成只改变电子数；核方程中的质子数与核子数按核过程另行守恒记账。 / Ordinary ion formation changes electron number; nuclear equations require separate proton and nucleon accounting.

Explanation / 讲解

核素记号 / Nuclide notation

\[{}^{A}_{Z}X\]

\(Z\) 为质子数 proton number，\(A\) 为核子数 nucleon number，\(N=A-Z\) 为中子数 neutron number。质子数决定元素。A is an integer count, not a mass in kilograms.

同位素是同一元素具有相同Z、不同中子数和A的原子。Isotopes have the same proton number but different neutron numbers.

例如 \({}^{14}_{6}\mathrm C\) 有6个质子、8个中子；中性原子有6个电子。核与中性原子具有不同的电荷。The nucleus has charge +6e while the neutral atom has zero net charge.

离子 / Ions

若电子数为 \(n_e\)，原子或离子总电荷为 \((Z-n_e)e\)。失去电子形成正离子，得到电子形成负离子。Ionisation normally leaves the nucleus unchanged.

同位素变化、离子形成和核衰变是不同过程。Isotope identity involves the nucleus; ordinary ion formation changes electrons.

核反应守恒的记号 / Conservation notation

写核方程时两侧核子数总和和电荷数总和须相等。电子的核子数记为0、带电数为-1；正电子为0、+1。Nuclide bookkeeping connects directly to decay equations.

图示：同位素的结构 / Isotope structures

读图 / Reading： 氢的三种同位素质子数都为 1，中子数不同；中性原子的电子数相同。核子数不同不代表元素种类改变。

Hydrogen isotopes share one proton but differ in neutron number; their neutral atoms have the same electron count.

A03 方法 1 · 核素、同位素与离子电子数 / Nuclides, isotopes and ion electrons

同位素具有相同质子数、不同中子数；不得用“不同电子数”定义。同元素离子只是电子数改变。 / Isotopes differ in neutron number, not electron number.

  1. 先写 \(p=Z\)、\(n=A-Z\)；正 \(ke\) 离子有 \(Z-k\) 个电子，负 \(ke\) 离子有 \(Z+k\) 个。 / Read charge and nucleon notation independently.
  2. 核比荷取 \(Ze\)；离子比荷取离子净电荷 \(ke\)，不是无论何种对象都用 \(Ze\)。 / Identify which object the question names.
  3. 从衰变链判断是否同位素，比较最终 \(Z\) 是否相同、\(A\) 是否不同，不能只看元素标签或衰变次数。 / Calculate the net changes.
