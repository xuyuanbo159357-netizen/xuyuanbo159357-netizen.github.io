Concept / 概念

Impulse / 冲量

Definition / 定义

Impulse / 冲量

EN: Impulse is the change in momentum of an object.

中: 冲量是物体动量的变化量。

表达要点 / Wording: change in momentum

依据 / Evidence: PH01 201801 Q11.1 · MS p15（定义/陈述评分点）；PH01 202001 Q09.1 · MS p11（定义/陈述评分点）

Formula / 公式

\[\begin{gathered} J_{\rm net}=\Delta p=m(v-u) \\ F_{\rm resultant,avg}=\frac{\Delta p}{\Delta t} \\ J=F\Delta t\quad\text{(constant force)} \end{gathered}\]

Conditions / 适用条件

只有合力的总冲量等于物体的全部动量变化。若图中给的是接触力，须检查是否还需计入重力等其他力。 / Net impulse gives the total momentum change; check other forces when the graph shows a contact force.

Explanation / 讲解

核心关系 / Core relations

\[F_{\text{avg}}=\frac{\Delta p}{\Delta t},\qquad J=\Delta p=m(v-u).\]

恒定力时 \(J=F\Delta t\)。变力时有符号F–t图下面积是冲量。For a varying force, use the graph area rather than peak force multiplied by time.

单位N s与kg m s⁻¹相同。Force changes momentum, not merely its magnitude.

碰撞与反弹 / Stopping and rebound

从 \(u>0\) 停下时 \(\Delta p=-mu\)。若反弹末速度 \(v<0\)，则动量变化大小为 \(m(|u|+|v|)\)。A rebound can create a larger momentum change than stopping.

同样的动量变化，接触时间越长，平均力越小。缓冲区、包装材料和接球时向后移动手都利用这一关系。A longer stopping interval reduces average impact force.

平均力与峰值力不同；相同面积的F–t曲线可有不同峰值。Different force profiles can give the same impulse.

踢球时冲量改变球的速度，脚受到对应反向冲量。Apply the third law to the same interaction on the two bodies.

图示：冲量是面积 / Impulse as area

读图 / Reading： 力—时间图的面积为该力的冲量；若要求动量变化，所用面积必须对应合力。延长时间可在相同冲量下减小平均力。

Force–time area is that force’s impulse; momentum change requires resultant-force area. Longer duration reduces mean force for a fixed impulse.

D19 方法 1 · 冲量、接触力与连续流 / Impulse, contact forces and continuous flow

  1. 冲量为动量变化 \(\mathbf J=\Delta\mathbf p=\int\mathbf F_{net}dt\)；平均合力 \(\Delta p/\Delta t\)。反弹需计方向，图上ms先换秒。 / Use signed momenta and the correct time unit.
  2. 力板或竖直接触问题要区分接触力与合力；求净冲量可用接触曲线减重力基线，求地面对球力需加回重力。 / Identify exactly which force is plotted or requested.
  3. 安全解释用“相同初末运动状态 → 相同动量变化 → 更长停止时间 → 较小平均合力”；若反弹，动量变化也可能更大，不能无条件说相同。 / State what is held fixed.
  4. 也可用相同动能损失、较长停止距离解释平均阻力；\(F\)–\(t\) 面积和 \(F\)–\(x\) 面积分别对应冲量、功，不可互换。 / Match the graph to the conserved quantity.
  5. 连续流体或沙流 \(F=\dot m(v_{out}-v_{in})\)，先把体积流率经密度转质量流率；电机功率还应计系统摩擦。 / Use the change in velocity, not just the output speed unless the input component is zero.
