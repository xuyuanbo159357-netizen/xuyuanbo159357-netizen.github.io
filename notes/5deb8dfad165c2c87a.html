按物理关系整理公式 / Formulae organised by relationship

关系 1 / Relation 1

\[\Large\displaystyle I=\frac{\Delta Q}{\Delta t}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(I\) 电流 / current \(\mathrm{A}\)
\(\Delta Q\) 通过截面的电荷量 / charge passing the cross-section \(\mathrm{C}\)
\(\Delta t\) 时间间隔 / time interval \(\mathrm{s}\)

物理关系 / Physical relationship： 平均电流描述单位时间通过截面的电荷量。 / Average current is charge passing a cross-section per time.

适用条件 / Conditions： 稳恒电流用 Q/t；载流子关系用于均匀截面 / Q/t is an average for the stated interval; use a uniform cross-section for drift calculations

关系 2 / Relation 2

\[\Large\displaystyle I=nAev_d\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(I\) 电流 / current \(\mathrm{A}\)
\(n\) 载流子数密度 / carrier number density \(\mathrm{m^{-3}}\)
\(A\) 面积 / area \(\mathrm{m^2}\)
\(e\) 元电荷大小 / elementary charge \(\mathrm{C}\)
\(v_d\) 漂移速率 / drift speed \(\mathrm{m\,s^{-1}}\)

物理关系 / Physical relationship： 电流由载流子密度、截面积、电荷和漂移速率共同决定。 / Current depends on carrier density, area, carrier charge and drift speed.

适用条件 / Conditions： 稳恒电流用 Q/t；载流子关系用于均匀截面 / Q/t is an average for the stated interval; use a uniform cross-section for drift calculations
