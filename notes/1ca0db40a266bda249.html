U3/06 真题练习/答题规范

U3 计算与证明 / Calculations and show-that questions

U3 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 先选模型和研究方向 / Select the model and direction

  • 圆周运动：写指向圆心的合力 \(\sum F_r=mv^2/r=m\omega^2r\)；“向心力”是合力的作用，不是在真实受力之外额外加一股力。 / Resolve the actual forces radially rather than adding an extra centripetal force.
  • 简谐运动：\(a=-\omega^2x\)，位移相对平衡位置；不能把位移 \(x\) 当圆周半径而误用向心力。 / Measure displacement from equilibrium and retain the restoring sign.
  • 2026 June Q03.2 明确不接受用圆周向心力关系代替简谐回复力；Q03.3 的力指向平衡位置。 / Use the SHM relation and its direction. PH03 2026 June Q03.2–03.3 · MS PDF p9 · 原题与答案 / Question and answer

2. 轨道、势能与符号 / Orbits and potential energy

用物体到中心的距离 \(r\)，不是距表面高度；圆轨道先列 \(GMm/r^2=mv^2/r\)。 / Use distance from the central body's centre and identify the circular-orbit condition.

\[E_p=-\frac{GMm}{r},\qquad \Delta E_p=E_{p,\mathrm{final}}-E_{p,\mathrm{initial}}.\]

半径减小，势能更负；不能因动能增加就断言总能量增加。2026 June Q04.3 要解释 \(|\Delta E_p|>|\Delta E_k|\)，总能量降低。 / A smaller circular orbit has greater kinetic energy but lower total energy. PH03 2026 June Q04.2 · MS PDF p13 · 原题与答案 / Question and answer；PH03 2026 June Q04.3 · MS PDF p14 · 原题与答案 / Question and answer

3. 证明题：给出独立结果 / Show the independently calculated value

2026 June Q04.1 要证明卫星质量约 \(2000\ \mathrm{kg}\)。用轨道关系和动能数据得到计算值约 \(1562\ \mathrm{kg}\)，评分标准列为 \(1600\ \mathrm{kg}\)，可支持题给粗略值；只写“2000 kg”不能展示证明。 / Derive the mass from the given orbit and kinetic energy; do not merely repeat the target. PH03 2026 June Q04.1 · MS PDF p13 · 原题与答案 / Question and answer

通常展示比题给近似值多至少一位有效数字，有助于体现计算证据；不是所有题统一的扣分规定。 后续 Q04.2 明确接受题给 \(2000\ \mathrm{kg}\)；本库课堂约定在后续小问统一使用该证明值。 / The rubric accepts the stated 2000 kg; the classroom convention uses this value in the next part. PH03 2026 June Q04.2 · MS PDF p13 · 原题与答案 / Question and answer

4. 指数、简谐相位和磁场计算 / Exponentials, SHM phase and magnetic motion

  • 衰变先确定给的是剩余数还是已衰变数。2026 June Q01.4 须用 \(N_0=5.0\times10^6\)、剩余 \(N=1.0\times10^6\)，不能把已衰变的 \(4.0\times10^6\) 当剩余数。 / Identify the quantity represented before using the exponential law. PH03 2026 June Q01.4 · MS PDF p6 · 原题与答案 / Question and answer
  • 简谐运动到达同一位置的最短时间不一定是一个周期；需考虑初始位置及运动方向。使用 \(\omega t\) 时保持角度单位一致。 / Use initial phase and direction, not an automatic period or half-period. PH03 2026 June Q03.4 · MS PDF p10 · 原题与答案 / Question and answer；PH03 2026 June Q03.4 · MS PDF p11 · 原题与答案 / Question and answer
  • 磁偏转 \(r=mv/(|q|B)\)：核对电荷态、单个粒子质量、半径而非直径，以及速度垂直于磁场的条件。 / Check charge state, particle mass, radius and perpendicular motion. PH03 2026 June Q07.4 · MS PDF p20 · 原题与答案 / Question and answer
计算顺序提示 / Calculation sequence

辨认物理量 → 列方程及条件 → 统一单位 → 保留中间精度 → 数值、单位、方向或正负号 → 回答题问。 / Identify quantities → equations and conditions → consistent units → retain digits → final value and sign → answer the question.

同一大题的数据沿用 / Carrying answers into later parts

课堂统一答题规范 / Classroom convention

同一大题内，后续小问用到前面小问的答案数据时，直接使用前问已写出的答案数值，不改用计算器内保留的更精确值。前问若为证明题，后续直接使用题目要求证明的数值。

Within the same question, use the numerical answer reported in the earlier part when it is required in a later part, rather than a more precise calculator value. If the earlier part is a show-that question, use the value stated in that question for later parts.

区分两个阶段：同一小问内部保留中间精度；跨小问沿用已报告的答案或题给证明值。 / Within one part, retain intermediate precision; between parts, carry forward the reported answer or the stated show-that value.

这是本知识库采用的课堂统一约定；原评分标准有时还接受其他跟进路线，不将本约定表述成考局所有题目的唯一评分规则。若题目另给指定数据，以该明确指令为准。 / This is the classroom convention used in this vault. Some mark schemes also accept other follow-through routes; it is not presented as the board's sole permitted method. Follow any explicit value separately specified in the question.
