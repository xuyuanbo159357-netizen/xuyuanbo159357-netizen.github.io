知识逐项讲解 / Concept-by-concept guide

Tensile stress / 拉应力

Definition / 定义

EN: Tensile stress is the tensile force per unit cross-sectional area of a specimen.

中: 拉应力是试样单位截面积上承受的拉力。

表达要点 / Wording: force; cross-sectional area

依据 / Evidence: PH01 201801 Q08.3 · MS p11（相关计算或应用）；PH01 202401 Q01 · MS p4（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \sigma=\frac{F}{A_0}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\sigma\) 拉应力 / tensile stress \(\mathrm{Pa}\)
\(F\) 相应的拉力；断裂或最大应力取对应力值 / corresponding tensile, breaking or maximum force \(\mathrm{N}\)
\(A_0\) 原横截面积 / original cross-sectional area \(\mathrm{m^2}\)

Conditions / 条件与说明： 断裂应力使用断裂时的力；极限拉应力使用最大拉力。 / For breaking stress use the breaking force; for ultimate tensile stress use the maximum tensile force.

Tensile strain / 拉应变

Definition / 定义

EN: Tensile strain is the extension divided by the original unstretched length.

中: 拉应变是伸长量除以原始未拉伸长度。

表达要点 / Wording: extension; original length

依据 / Evidence: PH01 201806 Q04.1 · MS p7（定义/陈述评分点）

Formula / 公式

\[\Large\displaystyle \epsilon=\frac{\Delta L}{L_0}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\epsilon\) 拉应变 / tensile strain 无量纲 / dimensionless
\(\Delta L\) 伸长量 / extension \(\mathrm{m}\)
\(L_0\) 原长 / original length \(\mathrm{m}\)

Formula / 公式

\[\Large\displaystyle \sigma=\frac{F}{A_0}\]
\[\Large\displaystyle \epsilon=\frac{\Delta L}{L_0}\]
\[\Large\displaystyle A_0=\frac{\pi d_0^2}{4}\]

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
拉应力 / tensile stress \(\sigma\) \(\mathrm{Pa}\)
拉应变 / tensile strain \(\epsilon\) \(1\)（无量纲 / dimensionless） 无量纲；不是伸长量 / Dimensionless; not extension.
力 / force \(F\) \(\mathrm{N}\) 矢量；合力常记 ΣF 或 F_resultant / Vector; resultant force is often ΣF or F_resultant.
面积、横截面积 / area, cross-sectional area \(A,\ A_0\) \(\mathrm{m^2}\) A₀ 表初始横截面积；与活度 A 区分 / A₀ is initial area; not activity A.
伸长量 / extension \(\Delta L\) \(\mathrm{m}\) 有些题写 x 或 e；按题设识别 / Some questions use x or e.
原长 / original length \(L_0\) \(\mathrm{m}\)
直径 / diameter \(d,\ d_0\) \(\mathrm{m}\) d₀ 表初始直径 / d₀ is the original diameter.

Conditions / 适用条件

本课程的工程拉应力使用原始截面积，拉应变使用原始未拉伸长度。 / Engineering tensile stress uses original area; tensile strain uses original unstretched length.

Explanation / 讲解

物理量辨析 / Quantity distinctions

\[\Large\displaystyle \sigma=\frac{F}{A},\qquad\epsilon\]
\[\Large\displaystyle \sigma=\frac{\Delta L}{L_0}\]

拉应力为单位原始截面积承受的拉力，单位Pa或N m⁻²。拉应变为伸长量除以原长，没有单位。Tensile stress uses cross-sectional area; tensile strain is dimensionless.

圆线材 \(A=\frac{\pi d^2}{4}\)，直径和原长均须用一致单位。应变不能直接写成伸长量的毫米值。Use a ratio for strain, not an unnormalised extension.

为何使用应力与应变 / Why normalise?

相同材料、不同尺寸的线材有不同F–ΔL曲线；应力–应变关系让材料本身的响应更可比较。Stress and strain separate material properties from specimen geometry.

例如 \(F=100\) N、\(A=2.0\times10^{-6}\) m²，\(\sigma=5.0\times10^7\) Pa；\(\Delta L=1.0\) mm、\(L_0=2.0\) m，\(\epsilon=5.0\times10^{-4}\)。

应力不是总力，应变不是百分比本身；若转成百分比，才另乘100%。Keep force, stress, extension and strain distinct.

图示：应力、应变的几何量 / Geometry of stress and strain

读图 / Reading： A 取原横截面积，L 取原长，ΔL 取伸长量；应力用 F/A，应变用 ΔL/L，不能把长度与伸长量混用。

Use original area A, original length L and extension ΔL; stress is F/A and strain ΔL/L.

D25 方法 1 · 应力、应变与相接细线 / Stress, strain and connected wires

应力 \(\sigma=F/A\)，应变 \(\varepsilon=\Delta L/L_0\)；应变无单位，且 \(\Delta L\) 不等于末长度。 / Define strain using the original length.

  1. 相接轻线若承相同轴向拉力，张力相同，截面积大者应力较小；同材料线性区 \(\sigma/\varepsilon=E\) 相同，但应力、应变本身未必相同。 / Distinguish a common ratio from common values.
  2. 多根相同支承线总载荷先分配，再用每根实际材料面积；安全系数比较工作应力与允许应力，不把破坏应力直接当正常工作上限。 / Apply the factor of safety to matching quantities.
  3. Pa、N m⁻²及J m⁻³等量纲相同，基本单位 \(\mathrm{kg\,m^{-1}\,s^{-2}}\)；面积mm²先转m²。 / Keep dimensions and numerical scale consistent.
