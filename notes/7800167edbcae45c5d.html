本卷复盘重点 / Paper-specific review

  • 陌生情境解释需使用题目数据并给出细节；多步计算要清晰分行。 Use the supplied data in contextual explanations and set out calculations clearly. 报告第2页 / Report p2

  • “某量加倍”的比较应量化；衰变常量、半衰期和活度不能混同。 Quantify doubling arguments and distinguish decay constant, half-life and activity. 报告第3页 / Report p3

  • 简谐运动 / Simple Harmonic Motion：13分，16.25%。 回看 / Review：3.6.2 简谐运动方程、图像与能量。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 电容器 / Capacitors：11分，13.75%。 回看 / Review：3.8.4 电容、介质与储能。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 放射性的指数变化 / Exponential Changes In Radioactivity：9分，11.25%。 回看 / Review：3.9.2 放射性指数衰变。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.
