题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
elastic / returns to 弹性 / 回到原状态 卸载后恢复原形或原长 / Recovery after unloading.
plastic / permanent 塑性 / 永久的 卸载后有永久形变 / Permanent deformation remains.
brittle / ductile 脆性 / 延展性 比较断裂前的塑性形变 / Compare plastic deformation before fracture.
loading / unloading 加载 / 卸载 两条路径可能不同 / Follow the specified loading and unloading paths.
stress–strain 应力–应变 先区分材料性质与试样几何 / Separate material properties from sample geometry.

核心模型与条件 / Model and conditions

用曲线判断比例关系、恢复性和断裂行为。 / Use the graph to distinguish proportionality, reversibility and fracture.

线索 / Cue 物理判断 / Interpretation
过原点直线 / straight line through origin 该段服从比例关系 / proportional response in that region
卸载回到原长 / returns to original length 弹性形变 / elastic deformation
零外力时仍有伸长 / extension remains at zero applied force 存在塑性形变 / permanent deformation
断裂前几乎无塑性形变 / little plastic deformation before fracture 脆性材料 / brittle material

读图 / Reading: 按本图标记：A比例极限，B弹性极限，C屈服，D最大工程应力，E断裂；字母仅适用于本图。 / These source labels denote proportionality limit, elastic limit, yield, maximum engineering stress and fracture; letters are graph-specific.

解题流程 / Method

  1. 读坐标、加载方向及断裂点。 / Identify axes, loading direction and fracture point.
  2. 用卸载路径判断可恢复与永久部分，不只看加载是否为直线。 / Judge reversibility from unloading, not merely straightness during loading.
  3. F–x图加载面积给输入功；卸载面积给可恢复能量；差额表示转入其他形式的能量。 / Compare work input with recoverable energy using the relevant force–extension areas.

易错判断 / Checks

非直线不自动等于塑性；脆性不自动等于强度低。 断裂应力、刚度和延展性分别从不同图像特征判断。 / Non-linearity, strength, stiffness and ductility are distinct characteristics.
