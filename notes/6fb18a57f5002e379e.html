关系 1 / Relation 1

\[\Large\displaystyle A_s=\lambda_d N_n\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(A_s\) 样本活度 / sample activity \(\mathrm{Bq}\)
\(\lambda_d\) 衰变常量 / decay constant \(\mathrm{s^{-1}}\)
\(N_n\) 未衰变核数 / undecayed nuclei \(1\)（无量纲 / dimensionless）

物理关系 / Physical relationship： 活度是大样本每秒衰变数的统计预测，与剩余核数成正比。 / Activity predicts the decay rate of a large sample and is proportional to remaining nuclei.

适用条件 / Conditions： 同一种核素、固定衰变常量；测量还受效率和几何影响 / one nuclide with constant decay constant; detection efficiency and geometry still matter

关系 2 / Relation 2

\[\Large\displaystyle A_s=A_0e^{-\lambda_dt}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(A_s\) 样本活度 / sample activity \(\mathrm{Bq}\)

\(t\) 时间 / time \(\mathrm{s}\)

物理关系 / Physical relationship： 固定衰变常量给出活度的指数预测。 / A constant decay probability gives exponential activity.

适用条件 / Conditions： 同一种核素、固定衰变常量；测量还受效率和几何影响 / one nuclide with constant decay constant; detection efficiency and geometry still matter

3.9.2 放射性指数衰变

采用同一种核素且概率恒定；固定探测效率与几何、扣除背景后，计数率才与活度成正比。

Use a single radionuclide with constant decay probability. Detected count rate is proportional to activity only with fixed detection efficiency/geometry and corrected background.

活度单位 Bq，衰变常量单位 s\(^{-1}\)；质量与摩尔质量使用一致单位。
