知识逐项讲解 / Concept-by-concept guide

Ideal projectile motion / 理想抛体运动

Definition / 定义

EN: Ideal projectile motion is the motion of an object after projection when the only force acting on it is gravity.

中: 理想抛体运动是物体抛出后只受重力作用的运动。

依据 / Evidence: PH01 202501 Q08.1 · MS p11（相关计算或应用）

Formula / 公式

\[\Large\displaystyle a_x=0\]
\[\Large\displaystyle a_y=-g\]
\[\Large\displaystyle u_x=u\cos\theta\]
\[\Large\displaystyle u_y=u\sin\theta\]
\[\Large\displaystyle x=u_xt\]
\[\Large\displaystyle y=u_yt-\frac12gt^2\]
\[\Large\displaystyle v_y=u_y-gt\]

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

Conditions / 适用条件

理想分运动方程要求重力场近似均匀且空气阻力可忽略。起落高度相同时才可使用对称飞行时间的简式。 / The ideal equations assume uniform gravity and negligible drag; equal-height flight formulas require equal launch and landing heights.

Explanation / 讲解

模型与公式 / Model and equations

在均匀重力场、忽略空气阻力的模型中，水平无合力，竖直仅受重力。以向右、向上为正：

\[\Large\displaystyle a_x=0,\quad a_y\]

\[\Large\displaystyle a_x=-g,\quad u_x\]
\[\Large\displaystyle a_x=u\cos\theta,\quad u_y\]
\[\Large\displaystyle a_x=u\sin\theta\]
\[\Large\displaystyle x=u_xt,\qquad y\]
\[\Large\displaystyle x=u_yt-\frac12gt^2,\qquad v_y\]
\[\Large\displaystyle x=u_y-gt\]

The horizontal velocity is constant; the vertical velocity changes under gravity.

水平抛出时 \(u_y=0\)，但竖直加速度不为零。两个分运动彼此独立而时间相同。Horizontal launch does not eliminate vertical acceleration.

有阻力时 / With drag

阻力使水平速率降低，轨迹不再保持理想的对称抛物线，通常射程和最大高度减小。The ideal component equations cease to apply with constant accelerations when drag changes significantly.

图示：抛体分运动独立性 / Independent projectile components

读图 / Reading： 两球从同一高度同时开始下落，竖直初速度相同；忽略阻力时，无论是否有水平速度，落地时间相同。

With equal initial height and vertical velocity, both balls have the same flight time when drag is negligible, regardless of horizontal velocity.

图示：水平抛射轨迹 / Horizontal projection

读图 / Reading： 同一时间内水平位移按匀速累积，竖直位移按自由落体累积；图中 a→b 是高度参考，b→c 才是实际抛物轨迹。

Horizontal motion is uniform while vertical motion is free fall; a–b sets the height reference and b–c is the projectile path.

Application / 应用

解题方法 / Method

先分别列x、y方向已知量；通常用竖直条件求 \(t\)，再代入水平关系求射程。求合速度用 \(v=\sqrt{v_x^2+v_y^2}\)，方向由带符号分量求得。Solve one component for time and use it in the other.

最高点只有 \(v_y=0\)，若 \(v_x\ne0\)，合速度仍不为零。For an angled projectile the speed is not zero at the apex.

同一高度起落时，可由SUVAT推出飞行时间 \(2u_y/g\)；落点高度不同时不能套此式。Equal-height formulas require the stated condition.

依据本库现有真题与评分标准核对。下列步骤按题型使用，先核对题设条件；综合题需结合其他关联知识点。 / Checked against the papers and mark schemes held in this vault; select the approach that fits the stated conditions.

D12 方法 1 · 抛体分量、双根与共同时间 / Projectile components and time roots

  1. 列 \(u_x=u\cos\theta\)、\(u_y=u\sin\theta\)，\(a_x=0\)、\(a_y=-g\)；先在已知条件较多的方向求共同时间，再求另一方向位移。 / Use the same time for independent components.
  2. 最大高度先算相对发射点增量，再加发射高度；最高点竖直速度为零但水平速度一般不为零，因此只是速率最小。 / Distinguish height gained from height above ground.
  3. 给定中间高度可能有上升、下降两个正时间根；根据“下降时、远处横杆、首次到达”等题意选根，不能总把飞行时间写两倍上升时间。 / Equal launch and landing heights are required for that symmetry.
  4. 从气球或飞机释放保留其初速度分量；无水平合力时释放物与载体可保持同水平速度。 / Release does not reset velocity to zero.
  5. 空阻总反向于相对空气的速度，削弱水平速度，降低最高点且通常提前到顶；落地总时间需按题境判断，不能套同一个结论。 / Distinguish time to the top from total flight time.
  6. 抛体在顶点碰撞时先用顶点水平速度作碰撞初速度，再用该方向动量守恒。 / Join the projectile and collision stages explicitly.
