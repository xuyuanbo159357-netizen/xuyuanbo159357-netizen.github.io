Concept / 概念

half-life — 半衰期

Definition / 定义

English: The time for the number of undecayed nuclei, or the activity, to fall to half its initial value.

中文： 未衰变核数或活度降为初值一半所需时间。

定义评分依据 / Definition marking points： PH03 202301-Q05。原答案在题目下展开；此处按评分要点概括。 Summarised from the marking points; originals are folded below each question.

图示讲解 / Diagram explained

图示：指数衰变与半衰期 / Exponential decay

读图 / Reading： 相同半衰期内剩余量乘同一比例，但减少的绝对核数越来越少；曲线斜率大小随时间减小。

Each half-life multiplies the remaining number by the same fraction, but absolute losses and slope magnitude decrease with time.
