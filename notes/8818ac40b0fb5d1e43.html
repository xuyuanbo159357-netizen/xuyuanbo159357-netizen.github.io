3.4.5 分压器与传感电路 / Potential divider

考纲 / Specification： 3.4.5　｜　本单元知识谱系

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
输出电势差 / output potential difference \(V_{\mathrm{out}}\) \(\mathrm{V}\)
电源电势差 / supply potential difference \(V_{\mathrm{s}}\) \(\mathrm{V}\) 分压器语境；变压器中的下标 s 表副线圈 / In a divider; transformer subscript s means secondary.
电阻 / resistance \(R\) \(\mathrm{\Omega}\)

Concept / 概念

  • potential divider — 分压器
  • light-dependent resistor — 光敏电阻

Definition / 定义

↗ potential divider — 分压器

Definition / 定义

English: An arrangement of series resistors used to provide a fraction of a supply potential difference.

中文： 利用串联电阻提供电源电势差一部分的电路。

定义按指定教材与 9630 考纲概括；教材页码见对应小节。 Summarised from the specified textbook and specification; page references are in the linked section.

↗ light-dependent resistor — 光敏电阻

Definition / 定义

English: A resistor whose resistance decreases as the incident light intensity increases.

中文： 入射光强增大时电阻减小的元件。

定义按指定教材与 9630 考纲概括；教材页码见对应小节。 Summarised from the specified textbook and specification; page references are in the linked section.

定义按考纲与指定教材概括；本页未列出可直接对应的定义题评分条目。 Definitions are summarised from the specification and textbook; no directly matched definition-item citation is claimed here.

Formula / 公式与单位

输出取第二个电阻两端时，分压比等于其电阻占总电阻的比例。

\(V_{\mathrm{out}}=V_{\mathrm{s}}R_2/(R_1+R_2)\) for output across \(R_2\).

Conditions / 条件与范围

标准公式假设输出近似无负载；有有限负载时先求其与输出电阻的并联等效电阻。不要求电位差计测量法。

The standard two-resistor formula assumes the output is unloaded, or the voltmeter/load resistance is sufficiently large. With a finite load, replace \(R_2\) by \(R_2\parallel R_{\mathrm{load}}\). A potentiometer used as a measuring instrument is not required.

Explanation / 解释

固定、可变与带负载分压 / Fixed, variable and loaded dividers

两个串联电阻接在稳定输入 \(V_{\rm in}\) 上，输出取自 \(R_2\) 时 \(V_{\rm out}=V_{\rm in}R_2/(R_1+R_2)\)。输出电阻占总电阻的比例越大，输出越大。滑动触点可连续改变这一比例。

For two series resistors, output across \(R_2\) is \(V_{\rm in}R_2/(R_1+R_2)\). Increasing the fraction of total resistance across the output raises the output voltage; a slider varies this fraction continuously.

上述式默认输出端近似不取电流。若负载 \(R_L\) 并在 \(R_2\) 两端，先把它们替换成 \(R_2\parallel R_L\)，再作分压；不能继续使用原来的 \(R_2\)。

The simple expression assumes negligible output current. For a load across \(R_2\), replace it by \(R_2\parallel R_L\) before calculating the output.

传感器位置决定变化方向 / Sensor position and output trend

NTC：温度↑→电阻↓；LDR：照度↑→电阻↓。传感器在下臂且输出取其两端时，温度或照度增加使输出降低；传感器在上臂、输出取固定下臂时，输出升高。

An NTC thermistor loses resistance as temperature rises; an LDR loses resistance as illumination rises. With output across the sensor in the lower arm, output falls; with the sensor in the upper arm and output across the fixed lower resistor, output rises.

按“外界量变化→传感器电阻变化→分压比例变化→输出变化”解释报警、自动照明和恒温控制。可调电阻用于设定触发点。

Explain sensing through the chain: stimulus → sensor resistance → divider ratio → output. A variable resistor sets the switching threshold.

课件范围订正 / Scope correction

本节掌握供电用分压器和滑动分压原理。课件第14页的零电流平衡式属于把电位差计作为测量仪器；该用途不属于本小节考纲要求，不列为必须掌握的方法。

逐项覆盖 / Requirement-by-requirement coverage： 3.4.5

Applications / 应用与实验

分析温度、光照传感器时，先圈出输出电阻，再说明阻值变化和分压比例变化。

Explain temperature and light sensors by identifying the output resistor, its change in resistance and the new resistance ratio.

Common errors / 易错点

不能脱离热敏电阻位置和输出端直接判断输出增减。

Never state “temperature rises so output rises” without locating the thermistor and output terminals.

3.4.5 方法 1 · 传感器阈值与灵敏度 / Sensor thresholds and sensitivity

  1. 标明输出跨在哪一个电阻上，写 \(V_{out}=V_sR_{out}/(R_1+R_2)\)。 / Identify the output arm before applying the divider equation.
  2. 在阈值处用给定输出电压反求阻值比；从温度或照度图读取传感器电阻，再求固定电阻。 / Work backwards from the switching threshold.
  3. 输出端接负载时，先用负载与该臂的并联等效电阻；测量输入电阻应足够大。 / Include loading before taking the voltage ratio.
  4. 灵敏度用 \(\Delta V/\Delta T\) 等明确比值描述。输出范围过小，给定电压分辨率下温度分辨能力变差；不等于误差必然减小。 / Distinguish sensitivity, resolution and accuracy.
  5. 传感器直接跨理想电源时输出电压不随其电阻变化；两端变阻器与三端分压器作用不同。 / Trace the actual connection, not just the component name.

灯泡升温电阻增大、热敏电阻升温电阻减小时，组合电阻的净变化需要相对变化量，不能只凭趋势判断。 / Opposing resistance changes require quantitative comparison.
