知识逐项讲解 / Concept-by-concept guide

Radiation intensity / 辐射强度

Definition / 定义

EN: Radiation intensity is the radiant power incident per unit area.

中: 辐射强度是单位面积接收的辐射功率。

依据 / Evidence: PH01 201906 Q12.3 · MS p13（相关计算或应用）

Formula / 公式

\[\Large\displaystyle I=\frac{P}{A_{\perp}}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(I\) 辐射强度 / radiation intensity \(\mathrm{W\,m^{-2}}\)
\(P\) 穿过表面的辐射功率 / radiation power crossing the surface \(\mathrm{W}\)
\(A_{\perp}\) 垂直传播方向的面积 / area normal to propagation \(\mathrm{m^2}\)

关联原理 / Related principles： Inverse-square law for gamma radiation / γ辐射反平方律。定律陈述见本页 Law statement 部分。 / See the Law statement section below.

Statement / 定律陈述

Inverse-square law for gamma radiation / γ辐射反平方律

EN: For an isotropic point source with negligible absorption, radiation intensity is inversely proportional to the square of the distance from the source.

中: 对于各向均匀发射且吸收可忽略的点源，辐射强度与距源距离的平方成反比。

依据 / Evidence: PH01 202606 Q12.5 · MS p20（相关计算或应用）

Formula / 公式

\[\Large\displaystyle I\propto\frac{1}{r^2}\]
\[\Large\displaystyle \frac{I_2}{I_1}=\left(\frac{r_1}{r_2}\right)^2\]
\[\Large\displaystyle R_{\rm corrected}\propto\frac{1}{r^2}\]

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
辐射强度、光强 / radiation or light intensity \(I\) \(\mathrm{W\,m^{-2}}\) 能量每单位面积每秒；不是电流 I / Not electric current I.
半径、距源距离 / radius, distance from source \(r\) \(\mathrm{m}\) 具体指半径或距源距离，由本题定义 / Follow the specified geometry.
计数率 / count rate \(R\) \(\mathrm{s^{-1}}\) R_measured、R_bg、R_corrected 分别为实测、背景、修正计数率 / Subscripts identify measured, background and corrected rates.

Conditions / 适用条件

反平方模型要求近似点源、各向均匀发射且吸收影响可忽略；计数率比较须固定探测条件并扣除背景。 / The model assumes a point source, isotropic emission and negligible absorption, with fixed detector conditions and background correction.

Explanation / 讲解

关系与条件 / Relation and assumptions

强度是单位面积每秒接收的辐射能量。对近似点源、向各方向均匀发射且衰减可忽略的情境：

\[\Large\displaystyle I\propto\frac{1}{r^2},\qquad\frac{I_2}{I_1}=\left(\frac{r_1}{r_2}\right)^2\]
考纲记号 \(I=I_0/r^2\) 中 \(I_0\) 是比例常数；比较两距离时使用比值更清楚。Do not confuse a proportionality constant with an intensity at an arbitrary reference distance.

距离加倍，强度为1/4；距离增至3倍，强度为1/9。The power spreads over a spherical area proportional to \(r^2\).

危害联系 / Hazard link

增加距离可降低外部源的照射强度；反平方解释的是几何扩散，吸收材料造成的减弱属于另一效应。Spreading and attenuation are different mechanisms.

图示：反平方规律的几何意义 / Inverse-square geometry

读图 / Reading： 距离由 d 变 2d 时，同一立体角内辐射分布到四倍面积，因此单位面积强度降为四分之一；不是总发射功率变小。

Doubling distance spreads the same radiation over four times the area, reducing intensity to one quarter without changing source power.

Application / 应用

实验验证 / Experimental verification

测背景计数率，再在不同r处测γ计数，固定源、探测器方向和计时方法，取合适重复次数与计数时间。Subtract the background and maintain detector geometry.

以校正计数率R对 \(1/r^2\) 作图，若近似直线且模型合适，可支持反平方关系；也可检查 \(Rr^2\) 近似恒定。A graph tests the model across several distances.

r应测到有效源与探测区的合适参考位置。距离过近时源/探测器不再近似点，空气或材料吸收、背景和有限几何会造成偏离。State why the ideal relationship may fail.

A13 方法 1 · 反平方、距离修正与联合变化 / Inverse-square changes and distance offsets

  1. 对点源、近似各向同性且吸收可忽略，净计数或强度 \(C\propto1/r^2\)；\(r\) 从真实发射点到探测区，不只是外壳间距。 / State the geometric assumptions.
  2. 原始率 \(C_{raw}=K/r^2+B\)；位置改变时先减背景、乘距离平方反比、再加背景。源同时衰变时再乘相应半衰比例。 / Separate background, geometry and decay.
  3. 验证可画 \(C\) 对 \(1/r^2\) 应为过原点直线，或 \(1/\sqrt C\) 对 \(r\) 直线；若 \(r=d+d_0\)，后者对外壳距 \(d\) 可有固定截距。对数图斜率应为−2。 / Interpret a nonzero intercept before rejecting the law.
  4. 多距离、长时间计数、重复、固定探测器朝向；混合α/γ源需先阻掉α或超过其射程。 / Make the measurement correspond to the radiation being tested.
  5. 给“再远75 cm”应在原45 cm上相加得120 cm，不能直接用75 cm作新源距。 / Distinguish an additional distance from the final distance.
