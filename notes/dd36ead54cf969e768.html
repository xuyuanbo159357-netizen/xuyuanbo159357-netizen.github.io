U1/06 真题练习/答题规范

U1 通用规范与有效数字 / General conventions and significant figures

U1 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 先读要求，再决定精度 / Choose precision from the question

遵守题目指定的位数或精度；没有明确要求时，结合输入数据精度和运算方式决定。不能把“两位有效数字”当作所有题目的固定要求。 / Follow any stated precision; otherwise consider the data and the calculation. Two significant figures is not a universal rule.

本单元例证 / U1 evidence 评分要求 / Marking requirement
2018 June Q09.2，沿斜面运动的速率 / Speed down a slope \(10.4\ \mathrm{m\,s^{-1}}\)，至少三位有效数字 / At least 3 sf.
2018 June Q10.3，弹簧常量 / Spring constant \(k=(1.08\text{–}1.17)\times10^3\ \mathrm{N\,m^{-1}}\)，只接受二或三位 / 2 or 3 sf only.
2019 January Q09.2，加速度及其不确定度 / Acceleration and uncertainty 加速度接受二或三位；最终百分比不确定度只接受一或两位 / 2 or 3 sf for acceleration; 1 or 2 sf for its percentage uncertainty.

来源 / Sources：PH01 2018 June Q09.2 · MS PDF p12 · 原题与答案 / Question and answer；PH01 2018 June Q10.3 · MS PDF p14 · 原题与答案 / Question and answer；PH01 2019 January Q09.2 · MS PDF p12 · 原题与答案 / Question and answer。上述是各题要求，不能外推为整个单元统一扣分规则。 / These restrictions apply to the cited questions.

2. 过程保留精度，末步取舍 / Retain precision until the final step

  • 中间计算保留计算器精度或足够的保护位，最终结果再四舍五入。 这并不表示测量值没有不确定度。 / Retain calculator precision or guard digits in intermediate results; round at the end. Measurements still have uncertainty.
  • 乘除法通常参考输入数据中最少的有效数字；加减法主要考虑绝对精度、小数位及是否出现相减抵消。不要机械地对每个中间量重新截位。 / For products and quotients, the least precise input in significant figures is a usual guide; sums and differences require attention to absolute precision and decimal places.
  • 若题目指定某一结果、取值或重力加速度，按该题给定值计算。 / Use any value or constant specified in the question.

3. 结果形式和单位 / Numerical form and units

  • 数值求解题通常写整数、小数或科学计数法，并给单位；科学计数法适合很大、很小的量及明确末尾零的有效性，不是“超过两位必须用科学计数法”。 / Give numerical results with units; standard form is useful, rather than compulsory beyond 2 sf.
  • 单位换算写清：\(\mathrm{mm^2\to m^2}\) 乘 \(10^{-6}\)；\(\mathrm{cm^3\to m^3}\) 乘 \(10^{-6}\)。几何面积和体积的换算应对词头的因子取相应次方。 / Apply the prefix factor to the power of the unit.
  • 分数和根式可用于推导、比值或题目要求的精确表达；要求数值时应完成数值计算。 / Fractions and surds remain valid in algebraic or exact answers; evaluate when a numerical value is requested.
  • 矢量答案同时写方向；只写正负号时，必须已定义正方向。 / State a vector's direction, or define the positive direction before using a sign.

4. 不确定度与测量值配套 / Match uncertainty and measured value

2019 January Q09.2 使用 \(a=2s/t^2\)，因此

\[\frac{\Delta a}{a}=\frac{\Delta s}{s}+2\frac{\Delta t}{t}.\]
指数 2 也要乘入时间的相对不确定度；最终 \(5.3\%\) 的精度要求与加速度的精度要求不同。 / The power of 2 multiplies the fractional time uncertainty; the uncertainty and acceleration have different reporting requirements. PH01 2019 January Q09.2 · MS PDF p12 · 原题与答案 / Question and answer

复述练习与答案 / Recall check and answer

问 / Question： “本题所有答案都写两位有效数字”是否可靠？ / Is 2 sf appropriate for every answer?

答 / Answer： 不可靠。2018 June Q09.2 要求至少三位；Q10.3 只接受二或三位。先查题目要求，再决定末步精度。 / No. The cited speed requires at least 3 sf, whereas the spring constant accepts only 2 or 3 sf.

同一大题的数据沿用 / Carrying answers into later parts

课堂统一答题规范 / Classroom convention

同一大题内，后续小问用到前面小问的答案数据时，直接使用前问已写出的答案数值，不改用计算器内保留的更精确值。前问若为证明题，后续直接使用题目要求证明的数值。

Within the same question, use the numerical answer reported in the earlier part when it is required in a later part, rather than a more precise calculator value. If the earlier part is a show-that question, use the value stated in that question for later parts.

区分两个阶段：同一小问内部保留中间精度；跨小问沿用已报告的答案或题给证明值。 / Within one part, retain intermediate precision; between parts, carry forward the reported answer or the stated show-that value.

这是本知识库采用的课堂统一约定；原评分标准有时还接受其他跟进路线，不将本约定表述成考局所有题目的唯一评分规则。若题目另给指定数据，以该明确指令为准。 / This is the classroom convention used in this vault. Some mark schemes also accept other follow-through routes; it is not presented as the board's sole permitted method. Follow any explicit value separately specified in the question.

U1 例证 / Unit-specific example

在 2018 June Q10.4 中，用前问已写出的 \(k\) 代入 \(E=kL/A\)，不另换成更多位数的斜率。该问允许跟进前问结果。 / Use the reported spring constant in the Young-modulus calculation; the cited rubric allows follow-through. PH01 2018 June Q10.4 · MS PDF p14 · 原题与答案 / Question and answer
