1. 半衰期与剩余核数 / Half-life and remaining nuclei

1.1 关键概念与定义 / Key concepts and definitions

Half-life / 半衰期

Definition / 定义

EN: Half-life is the time taken for the number of undecayed nuclei of an isotope in a sample to fall to half its initial value.

中: 半衰期是样品中某核素未衰变原子核数量降到初始值一半所需的时间。

表达要点 / Wording: time; half; undecayed nuclei

依据 / Evidence: PH01 202601 Q08.3 · MS p16（相关计算或应用）

Formula / 公式

\[\Large\displaystyle N=\frac{N_0}{2^{t/T_{1/2}}}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(N\) 未衰变的核数 / number of undecayed nuclei 无量纲 / dimensionless
\(N_{0}\) 初始未衰变核数 / initial number of undecayed nuclei 无量纲 / dimensionless
\(t\) 时间、时间间隔 / time, time interval \(\mathrm{s}\)
\(T_{1/2}\) 半衰期 / half-life \(\mathrm{s}\)

物理规律与含义 / Law and meaning

每经过一个半衰期，未衰变核的预期数量减半。

The expected number of undecayed nuclei halves in each half-life.

适用条件 / Conditions

单一核素、衰变概率不随时间改变。

Use a single isotope with time-independent decay probability.

等时间减半 / Equal half-life intervals

读图 / Reading： 从 N₀ 到 N₀/2、再到 N₀/4 的时间间隔相同；实际计数数据先扣除背景，不是总读数简单减半。

Equal intervals reduce N₀ to N₀/2 then N₀/4; subtract background before applying halving to count-rate data.

1.2 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle N=\frac{N_0}{2^n}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(N\) 未衰变的核数 / number of undecayed nuclei 无量纲 / dimensionless
\(N_{0}\) 初始未衰变核数 / initial number of undecayed nuclei 无量纲 / dimensionless
\(n\) 已经过的半衰期个数 / number of half-lives elapsed 无量纲 / dimensionless

物理规律与含义 / Law and meaning

经过若干个半衰期后，剩余量按二的相应次幂减小。

After a number of half-lives, the remaining amount is reduced by the corresponding power of two.

\[\Large\displaystyle n=\frac{t}{T_{1/2}}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(n\) 已经过的半衰期个数 / number of half-lives elapsed 无量纲 / dimensionless
\(t\) 时间、时间间隔 / time, time interval \(\mathrm{s}\)
\(T_{1/2}\) 半衰期 / half-life \(\mathrm{s}\)

物理规律与含义 / Law and meaning

经历的半衰期个数由总时间除以单个半衰期得到。

The number of half-lives elapsed is elapsed time divided by half-life.

\[\Large\displaystyle N_{\rm decayed}=N_0-N\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(N_{\rm decayed}\) 从初始时刻累计衰变的核数 / cumulative number of decays since the initial instant 无量纲 / dimensionless
\(N_{0}\) 初始未衰变核数 / initial number of undecayed nuclei 无量纲 / dimensionless
\(N\) 未衰变的核数 / number of undecayed nuclei 无量纲 / dimensionless

物理规律与含义 / Law and meaning

已衰变核数等于初始核数减尚未衰变核数。

The number of decayed nuclei is the initial number minus the number remaining.

2. 活度、计数率与图像 / Activity, count rate and graphs

2.1 关键概念与定义 / Key concepts and definitions

Activity / 活度

Definition / 定义

EN: Activity is the number of nuclei decaying per unit time.

中: 活度是单位时间内发生衰变的原子核数目。

表达要点 / Wording: nuclear decays; per unit time

依据 / Evidence: PH01 202506 Q11 · MS p19（相关计算或应用）

Formula / 公式

Conditions / 条件与说明： 1 Bq = 1 s⁻¹，表示每秒一次核衰变；活度不等于探测器计数率。 / One becquerel is one nuclear decay per second; activity is not detector count rate.

\[\Large\displaystyle A=\frac{\Delta N_{\mathrm{decayed}}}{\Delta t}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(A\) 该时间间隔的平均活度 / mean activity over the interval \(\mathrm{Bq}\)
\(\Delta N_{\mathrm{decayed}}\) 该间隔内衰变的核数 / number of decays in the interval 无量纲 / dimensionless
\(\Delta t\) 时间、时间间隔 / time, time interval \(\mathrm{s}\)

物理规律与含义 / Law and meaning

在给定时间间隔内，用衰变次数除以时间估计该间隔的平均活度。

Average activity over an interval is the number of nuclear decays divided by the interval.

Count rate / 计数率

Definition / 定义

EN: Count rate is the number of counts recorded by a detector per unit time.

中: 计数率是探测器单位时间内记录的计数次数。

表达要点 / Wording: recorded counts; per unit time

依据 / Evidence: PH01 202101 Q11.1 · MS p18（相关计算或应用）

Formula / 公式

\[\Large\displaystyle R=\frac{N_{\mathrm{counts}}}{\Delta t}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R\) 计数率 / count rate \(\mathrm{s^{-1}}\)
\(N_{\mathrm{counts}}\) 探测器计数 / detector counts 无量纲 / dimensionless
\(\Delta t\) 时间、时间间隔 / time, time interval \(\mathrm{s}\)

物理规律与含义 / Law and meaning

探测器计数率是记录到的计数除以记录时间，与源活度需通过探测效率联系。

Detected count rate is recorded counts divided by counting time and depends on detection efficiency as well as source activity.

\[\Large\displaystyle R_{\mathrm{source}}=R_{\mathrm{measured}}-R_{\mathrm{background}}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R_{\mathrm{source}}\) 源计数率（扣除背景） / source count rate (background subtracted) \(\mathrm{s^{-1}}\)
\(R_{\mathrm{measured}}\) 包含背景的实测计数率 / measured count rate including background \(\mathrm{s^{-1}}\)
\(R_{\mathrm{background}}\) 背景计数率 / background count rate \(\mathrm{s^{-1}}\)

物理规律与含义 / Law and meaning

源的净计数率由实测计数率扣去背景计数率得到。

Source count rate is obtained by subtracting background count rate from the measured count rate.

适用条件 / Conditions

背景与样品须换算成相同时间单位的计数率。

Express background and sample measurements as rates in the same time unit.

2.2 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle R_{\rm corrected}=R_{\rm measured}-R_{\rm background}\]

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R_{\rm corrected}\) 背景修正后的计数率 / background-corrected count rate \(\mathrm{s^{-1}}\)
\(R_{\rm measured}\) 包含背景的实测计数率 / measured count rate including background \(\mathrm{s^{-1}}\)
\(R_{\rm background}\) 背景计数率 / background count rate \(\mathrm{s^{-1}}\)

物理规律与含义 / Law and meaning

源的净计数率由实测计数率扣去背景计数率得到。

Source count rate is obtained by subtracting background count rate from the measured count rate.

Express background and sample measurements as rates in the same time unit.

2.3 内容解析与细节 / Explanation and details

含义与关系 / Meaning and relationships

半衰期是大量同种核样品中未衰变核的数量减少到原来一半所需的时间。Half-life is the time for the number of undecayed nuclei of an isotope to halve.

同一核素在合适条件下，活度或经过背景修正的计数率也减半。活度为每秒衰变次数，单位Bq；计数率取决于探测效率和几何，不能一概等同于活度。Activity and measured count rate are different quantities.

图像方法 / Graph method

选一个校正值R，找R/2对应时间，取两时刻之差；可选几组不同位置验证半衰期近似相同。Measure several halving intervals on the graph.

若存在背景 \(R_b\)，先用 \(R_{\rm source}=R_{\rm measured}-R_b\)。总计数率趋向背景，不能从未修正曲线直接把总值减半。Subtract the background before finding a halving interval.

考点精讲：半衰期读图先处理背景 / Correct the background before reading half-life

先判断图或数据是否已经扣除背景。未扣背景时，应对源的净计数率作减半处理，再加回背景，才能与仪器的总计数率比较。可在多个起点读出减半时间并取合理平均；不能把总计数率直接减半，也不能把背景扣除两次。

Check whether background has already been removed. Halve the net source count rate, then add background back if a measured total is required. Use several half-value intervals where appropriate. Do not halve an uncorrected total or subtract background twice.

A09 方法 1 · 半衰、背景与质量归一 / Half-lives, background and normalisation

  1. 半衰期是大量不稳定核的未衰变数或相应活度减半所需时间；不是每个核在半衰期后必衰变。 / Use a statistical definition.
  2. U1可用连续减半及比例 \(A/A_0=2^{-t/T}\)；不把U3衰变常数推导列为U1额外记忆。问时间区间可找相邻整数次半衰。 / Choose a method within the unit's requirements.
  3. 原始计数率先减背景，只衰减净源计数，再按要求加回背景；从原始图读半衰目标是 \(B+(C_0-B)/2\)。 / Do not halve the background.
  4. 不同样品质量先归一；纯母核经两次半衰剩 \(N_0/4\)、稳定子核为 \(3N_0/4\)，母/子比是1/3而不是1/4。 / Distinguish remaining fraction from a parent-to-daughter ratio.
  5. 图像要求“准确值”应尽可能取两次或更多半衰测定并平均；放射性供能的功率也随活度同比下降。 / Use repeated graphical determinations when asked.
