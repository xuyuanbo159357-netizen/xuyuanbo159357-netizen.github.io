Concept / 概念

Half-life / 半衰期；Activity / 活度；Count rate / 计数率

Definition / 定义

Half-life / 半衰期

EN: Half-life is the time taken for the number of undecayed nuclei of an isotope in a sample to fall to half its initial value.

中: 半衰期是样品中某核素未衰变原子核数量降到初始值一半所需的时间。

表达要点 / Wording: time; half; undecayed nuclei

依据 / Evidence: PH01 202601 Q08.3 · MS p16（相关计算或应用）

Activity / 活度

EN: Activity is the number of nuclear decays per unit time in a radioactive sample.

中: 活度是放射性样品单位时间内的原子核衰变次数。

表达要点 / Wording: nuclear decays; per unit time

依据 / Evidence: PH01 202506 Q11 · MS p19（相关计算或应用）

Count rate / 计数率

EN: Count rate is the number of counts recorded by a detector per unit time.

中: 计数率是探测器单位时间内记录的计数次数。

表达要点 / Wording: recorded counts; per unit time

依据 / Evidence: PH01 202101 Q11.1 · MS p18（相关计算或应用）

Formula / 公式

\[\begin{gathered} N=\frac{N_0}{2^n} \\ n=\frac{t}{T_{1/2}} \\ N_{\rm decayed}=N_0-N \\ R_{\rm corrected}=R_{\rm measured}-R_{\rm background} \end{gathered}\]

Conditions / 适用条件

用计数率读半衰期前先修正背景，并保持可比的探测几何及探测效率。 / Subtract background and keep detector geometry and efficiency comparable when using count rate for half-life.

Explanation / 讲解

含义与关系 / Meaning and relationships

半衰期是大量同种核样品中未衰变核的数量减少到原来一半所需的时间。Half-life is the time for the number of undecayed nuclei of an isotope to halve.

同一核素在合适条件下，活度或经过背景修正的计数率也减半。活度为每秒衰变次数，单位Bq；计数率取决于探测效率和几何，不能一概等同于活度。Activity and measured count rate are different quantities.

U1整数半衰期运算 / Whole-number calculations

经过n个半衰期（U1核心计算n为整数）：

\[N=\frac{N_0}{2^n},\quad n=\frac{t}{T_{1/2}},\quad N_{\rm decayed}=N_0-N.\]
初始核素的质量或活度在相同条件下也按此比率减少。The material remaining as the original isotope decreases, not the total mass of all daughters simply disappearing.

图像方法 / Graph method

选一个校正值R，找R/2对应时间，取两时刻之差；可选几组不同位置验证半衰期近似相同。Measure several halving intervals on the graph.

若存在背景 \(R_b\)，先用 \(R_{\rm source}=R_{\rm measured}-R_b\)。总计数率趋向背景，不能从未修正曲线直接把总值减半。Subtract the background before finding a halving interval.

范围 / Scope

U1不要求连续指数方程、衰变常量λ、对数拟合或 \(T_{1/2}=\ln2/\lambda\)。教材和PPT如出现这类关系，放入补充范围。The continuous exponential treatment is assigned to A2 by this specification.

A09 方法 1 · 半衰、背景与质量归一 / Half-lives, background and normalisation

  1. 半衰期是大量不稳定核的未衰变数或相应活度减半所需时间；不是每个核在半衰期后必衰变。 / Use a statistical definition.
  2. U1可用连续减半及比例 \(A/A_0=2^{-t/T}\)；不把U3衰变常数推导列为U1额外记忆。问时间区间可找相邻整数次半衰。 / Choose a method within the unit's requirements.
  3. 原始计数率先减背景，只衰减净源计数，再按要求加回背景；从原始图读半衰目标是 \(B+(C_0-B)/2\)。 / Do not halve the background.
  4. 不同样品质量先归一；纯母核经两次半衰剩 \(N_0/4\)、稳定子核为 \(3N_0/4\)，母/子比是1/3而不是1/4。 / Distinguish remaining fraction from a parent-to-daughter ratio.
  5. 图像要求“准确值”应尽可能取两次或更多半衰测定并平均；放射性供能的功率也随活度同比下降。 / Use repeated graphical determinations when asked.
