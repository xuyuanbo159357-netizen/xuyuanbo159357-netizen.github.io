本单元备考重点 / Unit-specific preparation

真实受力与场 / Forces and fields

向心力不是附加力；场强按矢量叠加，电势按标量叠加，明确零点与正负。 Distinguish radial resultants, field vectors and scalar potentials.

守恒与变化 / Conservation and change

轨道能量、电容Q/V约束、RC指数与衰变数量不能混用；先说哪个量守恒。 Identify constraints before applying orbital, capacitor or decay relations.

磁场与交流 / Magnetism and ac

磁通链的值、变化率与感应电动势分开；交流平均功率用有效值。 Separate flux linkage from its rate of change and use rms values for mean power.

按题型落实 / Applying the command

类型 / Type 答题动作 / What to do
计算 / Calculation 明确模型与适用条件→列方程→SI代入→中间量→结果及单位；需要判断时补结论。 State the model, equation, substitution, result and conclusion.
画图 / Drawing 看清draw或sketch；坐标、量名、单位、起点、峰值、渐近线和方向按题意标明，直线用尺。 Label the requested features and use a ruler for straight lines.
陈述 / Statement 按state/name/define区分名称、事实和严格定义，避免只写符号替代名称。 Match the requested level of recall.
解释 / Explanation 条件或原因→物理关系→变化方向→题境结论；不能只给公式或只复述现象。 Develop the causal link.
实验 / Practical 装置、变量、读数、控制、重复、处理、误差改进形成完整路径；改进应针对已识别偏差。 Tie the procedure and improvements to the experiment.
证明与推断 / Show or deduce 从原理出发展示链条；数值show that显示足够位数以验证给定近似值；deduce需推导或结论依据。 Show the reasoning rather than repeat the supplied result.

考官报告回看 / Examiner-report review

本地有14/15场官方报告；缺失场次未编造考生表现数据。 Reports are available for 14 of 15 papers in the collection.

2018年6月 / June

  • 陌生情境解释需使用题目数据并给出细节；多步计算要清晰分行。 Use the supplied data in contextual explanations and set out calculations clearly. 报告第2页 / Report p2

  • “某量加倍”的比较应量化；衰变常量、半衰期和活度不能混同。 Quantify doubling arguments and distinguish decay constant, half-life and activity. 报告第3页 / Report p3

2019年1月 / January

  • 本单元可调用U1—U3基础；证明须先列原理，径向场线用直尺并对称绘制。 Retain earlier-unit principles, state initial equations and draw symmetric radial field lines. 报告第2页 / Report p2

  • 区分具体支路电流与电势差；交流作图先从有效值求峰值。 Identify the branch quantities and convert rms to peak values before plotting. 报告第3页 / Report p3

2019年6月 / June

  • 楞次定律解释须说明阻碍运动的力；不能只背定律名称。 Connect Lenz’s law to the force opposing motion. 报告第2页 / Report p2

  • 磁场方向要区分“向下”与“进入纸面”；介电质问题需说明哪些量不变。 Specify directions unambiguously and identify constraints in dielectric problems. 报告第3页 / Report p3

2020年1月 / January

  • 若未能算出证明题的给定近似值，后续可使用题目提供的数值；解释不能只有方程。 Use the supplied show-that value if the preceding calculation fails; equations need interpretation. 报告第2页 / Report p2

  • RC综合计算先求等效电阻，再还原支路；矢量作图首尾相接。 Find equivalent resistance before branch values and draw vectors head-to-tail. 报告第3页 / Report p3

2022年1月 / January

  • SHM位移从平衡位置量起，不等同于弹性绳伸长。 Measure SHM displacement from equilibrium rather than from the unstretched length. 报告第2页 / Report p2

  • 涉及饮水安全等判断时，计算后要给结论；半衰期比较应定量使用数据。 Conclude contextual calculations and use numerical evidence in half-life comparisons. 报告第3页 / Report p3

2022年6月 / June

  • 定义、实验步骤与describe and explain要求准确完整表达。 Practise precise definitions, practical procedures and developed explanations. 报告第2页 / Report p2

  • 轨道总能量须由动能和势能相加，不能仅对动能改符号而不说明。 Derive orbital total energy by adding kinetic and potential energy. 报告第3页 / Report p3

2023年1月 / January

  • 向心力是已有力的径向合力，不能作为额外力加入受力图。 Centripetal force is the radial resultant, not an additional interaction. 报告第2页 / Report p2

  • 非恒定加速度不能套匀加速度方程；电场能量法须列出每一步。 Use energy methods rather than constant-acceleration equations in nonuniform fields. 报告第3页 / Report p3

2023年6月 / June

  • SHM条件是加速度与位移成正比且反向；图像要标周期和幅值。 State the proportional and opposite SHM relation and label graph scales. 报告第2页 / Report p2

  • 地球同步条件需准确表述；视重、重力与合力要分清。 Specify geostationary conditions and distinguish weight, apparent weight and resultant force. 报告第3页 / Report p3

2024年1月 / January

  • 多步计算要展示可获方法分的中间结果，并在比较后作结论。 Show intermediate results and give the requested comparison or conclusion. 报告第2页 / Report p2

  • 回旋加速器每转经过加速电势差两次，不能漏掉因子2。 Count two accelerating-gap crossings per cyclotron revolution. 报告第3页 / Report p3

2024年6月 / June

  • 空间站受力箭头应标明作用点和方向；两脚支持力需分别考虑。 Place and label forces correctly in the rotating-space-station context. 报告第2页 / Report p2

  • 截断摆可分成两个不同摆长的运动阶段；恒定最大高度对应恒定机械能。 Treat the interrupted pendulum as two lengths and relate height to energy. 报告第3页 / Report p3

2025年1月 / January

  • 摆动的最大速率应用振动关系或能量法，不能直接套圆周速度。 Use oscillation or energy relations for a pendulum’s maximum speed. 报告第2页 / Report p2

  • 椭圆轨道计算需保留势能符号；圆轨道为等势的理由要联系半径不变。 Retain potential-energy signs and explain why constant radius gives an equipotential. 报告第3页 / Report p3

2025年6月 / June

  • 指定某点方向时箭头需穿过该点；力偶计算不能把力和力臂重复加倍。 Pass direction arrows through the named point and avoid double-counting a couple. 报告第2页 / Report p2

  • 斜弯道受力图中重力与接触力的作用点不同，比较题须明确写出比较结论。 Place weight and contact forces appropriately and state comparisons explicitly. 报告第3页 / Report p3

2026年1月 / January

  • 题目留出核符号空格时即使为0也要填写；区分剩余质量和已衰变质量。 Fill zero entries explicitly and distinguish remaining from decayed mass. 报告第2页 / Report p2

  • 场线需径向、对称且来自电荷中心；determine要求展示代入。 Draw radial symmetric field lines from the charge and show substitutions. 报告第3页 / Report p3

2026年6月 / June

  • 衰变常量定义用概率及单位时间，方程法须解释符号；安全题要具体写长柄钳等措施。 Define decay constant precisely and make safety measures specific. 报告第2页 / Report p2

  • SHM解释须说明回复力与位移反向；数值碰巧相同不能证明圆周模型适用。 Justify the restoring direction; a matching number does not validate an inappropriate model. 报告第3页 / Report p3

自测与时间分配 / Practice and timing

每套120分钟、80分，平均1.5分钟/分可作为训练预算；这不是官方逐题用时要求。先完成可得分步骤，标记未完成题，最后核对单位、图线与结论。 A 1.5-minute-per-mark budget is a teaching aid, not an official timing rule.
