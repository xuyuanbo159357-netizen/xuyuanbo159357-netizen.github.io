阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 坐标、单位、关键位置 / Axes, units and key points

定量作图标清物理量、单位和合理刻度，准确使用题目给定点；草图也要保留关键截距、平台、峰值及曲率。 / Use labelled axes and appropriate scales; sketches still need the required physical features.

  • 温度–时间图区分升温段和相变平台；不把相变中吸热误画成温度持续升高。 / Distinguish heating from a phase change.
  • 定量气体图先检查横轴是 \(V\)、\(1/V\) 还是 \(T\)；摄氏温度轴不能机械地强制过原点。 / Identify the plotted variables and temperature scale before interpreting linearity.
  • 每核子结合能图纵轴不是一个原子核的总结合能；解释能量变化时需考虑核子数。 / Do not confuse the ordinate with total nuclear binding energy.

上述为物理解释与推荐画法；具体容差以题目要求为准。 / These are physical and presentation conventions; numerical tolerances are question specific.

2. 太阳能电池 P–V 图的评分例证 / A solar-cell P–V graph example

2026 June Q06.3：功率从零上升，在偏右的位置出现平滑峰顶，再下降至零；峰前梯度为正，峰后为负。额外要点包括：

  • 从 \((0,0)\) 至至少 \((0.5\ \mathrm V,0.035\ \mathrm W)\) 的近似直线段，配适当线性刻度。 / A suitable initial straight section and linear scale.
  • 峰值在 \(0.60\)–\(0.65\ \mathrm V\)。 / Peak at the specified voltage range.
  • 功率降至零的位置在 \(0.70\)–\(0.72\ \mathrm V\)。 / The high-voltage zero lies in the specified range.

这是该题的三个附加特征候选，评分标准取其中两项；不是所有太阳能电池都具有这些数值。 / The rubric credits two of these three numerical features; they are not universal cell parameters. PH04 2026 June Q06.3 · MS PDF p18 · 原题与答案 / Question and answer

3. 受力和转动示意图 / Force and rotation diagrams

画清重力、支持力和摩擦力的作用线，标出转轴或接触点；求转矩使用到作用线的垂直距离。角位移、角速度、角加速度方向约定一致。 / Show force lines, axis and lever arms, with a consistent rotational sign convention.

无摩擦斜面情境中，若重力与支持力都通过质心，则对质心无转动作用，物体可下滑而不能由静止开始转动。不能画一股不存在的摩擦力来解释自发滚动。 / Explain the absence of a torque about the centre using the actual forces. PH04 2026 June Q05.3 · MS PDF p15 · 原题与答案 / Question and answer

4. 能源图像要区分输入输出 / Distinguish input and output quantities

光强、功率、能量、质量流率不是同一量；面积、时间和效率因子各自只在需要的转换步骤使用。若从 \(I\)–\(V\) 数据画 \(P\)–\(V\)，逐点使用 \(P=IV\)，不能直接把原电流轴改标为功率。 / Convert the measured quantity using the correct relationship rather than relabelling an axis.

作图自检 / Drawing check

什么量随什么量变？单位和刻度？平台、峰值及零点？是否符合能量收支？转轴与力臂在哪里？ / Which quantities? Units and scale? Plateau, peak and zeros? Energy consistency? Axis and lever arm?
