U2 计算与证明 / Calculations and show-that questions

U2 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 先识别电路，再列关系 / Identify the circuit before calculating

画出或辨认实际连接 → 标明电流和电势差 → 选择关系 → 换单位代入 → 给数值与单位。 / Identify connections → label currents and voltages → choose relationships → substitute consistently → report the result.

  • 串联支路电流相同；并联支路电势差相同。分压器不能把某个电阻的电势差误当电源电动势。 / Distinguish branch current, component voltage and source emf.
  • 有内阻时 \(V=\mathcal E-Ir\)；求外电路量要使用路端电势差，不能无条件以 \(\mathcal E\) 替代。 / Distinguish terminal potential difference from emf.
  • 电压表测其两个接点间的电势差，电流表测所在支路电流；先看接点，再判断读数。 / Identify the actual meter connections before predicting readings. PH02 2026 June Q08.3 · MS PDF p15 · 原题与答案 / Question and answer

2. 波动和光学模型不能混用 / Select the correct wave or optical model

情境 / Context 列式前检查 / Check before using the equation
双缝干涉 / Double slit \(w=\lambda D/s\)；\(w\) 是相邻条纹间距，\(s\) 为两缝间距。 / Distinguish fringe spacing from slit separation.
衍射光栅 / Grating \(n\lambda=d\sin\theta\)；每单位长度的线数换为间距 \(d\)，角度从中央方向量。 / Convert line density to spacing and use the correct order and angle.
折射与临界角 / Refraction 入射角、折射角相对法线量；临界角对应高折射率向低折射率一侧。 / Measure angles from the normal and identify the direction of incidence.
驻波 / Stationary wave 数清波节、波腹和半波长段；不能把振动点数直接当波长数。 / Count half-wavelength segments correctly.

2026 June Q04 明确不能用双缝关系替代光栅关系。Q10.1 要把所测总宽度除以 9 个间距；Q10.3 才将 \(w\) 代入波长关系。 / The grating and double-slit models are not interchangeable; count the measured spacings before calculating the wavelength. 3. 量子计算中的能量和动量 / Energy and momentum in quantum calculations

  • 光电方程写 \(hf=\phi+E_{k,\max}\)；区分光子能量、逸出功和最大动能，单位一致。 / Distinguish photon energy, work function and maximum kinetic energy.
  • 德布罗意波长使用 \(\lambda=h/p\)；不要把光子的 \(E=hc/\lambda\) 不加判断套到电子动能。 / Use momentum in the de Broglie relation; distinguish photon energy from electron kinetic energy.
  • 代入 SI 常量前将 eV 转为 J。 / Convert eV to joules before using SI constants. PH02 2026 June Q06.1–06.2 · MS PDF p10 · 原题与答案 / Question and answer

4. 证明题与数值检验 / Show-that and checking

写出物理起点、代数步骤和足够精度的计算值，再说明与题给近似值一致。比目标值多展示至少一位有效数字通常有助于证明，但以该题要求为准。 / Show the physical starting point, algebra and sufficient numerical detail; an extra significant figure is a useful convention rather than a universal rule.

不能只把待证明值代回并写“correct”，也不能仅以数量级相同代替题目要求的验证。 / A bare substitution of the target or a matching order of magnitude may not establish the requested result.

计算后自检 / Final calculation check

电压属于哪个元件？电流属于哪一支路？波长还是间距？角从哪里量？eV 是否已换 J？最终单位、方向、位数？ / Which component voltage and branch current? Wavelength or spacing? Angle reference? eV conversion? Final unit, direction and precision?

同一大题的数据沿用 / Carrying answers into later parts

课堂统一答题规范 / Classroom convention

同一大题内，后续小问用到前面小问的答案数据时，直接使用前问已写出的答案数值，不改用计算器内保留的更精确值。前问若为证明题，后续直接使用题目要求证明的数值。

Within the same question, use the numerical answer reported in the earlier part when it is required in a later part, rather than a more precise calculator value. If the earlier part is a show-that question, use the value stated in that question for later parts.

区分两个阶段：同一小问内部保留中间精度；跨小问沿用已报告的答案或题给证明值。 / Within one part, retain intermediate precision; between parts, carry forward the reported answer or the stated show-that value.

这是本知识库采用的课堂统一约定；原评分标准有时还接受其他跟进路线，不将本约定表述成考局所有题目的唯一评分规则。若题目另给指定数据，以该明确指令为准。 / This is the classroom convention used in this vault. Some mark schemes also accept other follow-through routes; it is not presented as the board's sole permitted method. Follow any explicit value separately specified in the question.
