Conditions / 条件与范围

运动学式要求恒角加速度；简单转矩方程要求固定轴且转动惯量恒定；功公式要求恒转矩；扩展物体转动惯量公式需要时会给出。

Uniform angular-acceleration equations require constant \(\alpha\). The simple \(\tau=I\alpha\) equation assumes constant I about the fixed axis; work expression requires constant torque. Moment-of-inertia formulae for extended objects will be given when needed.

Explanation / 解释

转动惯量与角量 / Inertia and angular quantities

关于指定轴，点质量 \(I=mr^2\)，分布物体 \(I=\sum m_ir_i^2\)；\(r_i\) 是到该轴的垂直距离。质量越远离轴，转动惯量越大；同一物体换轴，\(I\) 可改变。需要的复杂形状表达式由题目给出。

Moment of inertia is defined about a specified axis using perpendicular distance. Moving mass farther from the axis raises it; changing the axis changes it. Necessary extended-body formulae are supplied.

角位移 \(\theta\) 用rad，角速度 \(\omega=d\theta/dt\)，角速率为其大小，角加速度 \(\alpha=d\omega/dt\)。同一刚体各点角速度相同，线速度 \(v=r\omega\) 不一定相同。

Distinguish signed angular velocity from angular speed. Points on one rigid rotating body share angular velocity but have different linear speeds at different radii.

匀角加速度与图像 / Constant angular acceleration

固定轴且 \(\alpha\) 恒定：\(\omega=\omega_0+\alpha t\)，\(\theta=\frac{(\omega_0+\omega)t}{2}\)，\(\theta=\omega_0t+\frac12\alpha t^2\)，\(\omega^2=\omega_0^2+2\alpha\theta\)；\(\theta\) 是该时间内的角位移。

Use the four rotational kinematics equations only for constant angular acceleration about the stated axis.

\(\theta\)–\(t\) 斜率为 \(\omega\)，\(\omega\)–\(t\) 斜率为 \(\alpha\)、有符号面积为角位移。负斜率并非总为“减速”：只有角速度和角加速度异号时角速率才减小。转数 \(n\) 对应角位移 \(2\pi n\)。

Graph gradients and signed areas have rotational analogues. Negative angular acceleration does not always mean decreasing speed; compare its sign with angular velocity. Convert revolutions to radians.

图示：角速度图的斜率与面积 / Angular-velocity gradient and area

读图 / Reading： ω–t 斜率为角加速度，带符号面积为角位移；曲线下降表示角加速度为负，不必然表示已经反向转动。

The ω–t gradient is angular acceleration and signed area angular displacement; a falling curve need not mean rotation has reversed.

力矩、角动量与约束 / Torque and angular momentum

力矩 \(\tau=Fr_\perp=Fr\sin\phi\)，\(r_\perp\) 为轴到力作用线的垂直距离；关于固定轴且 \(I\) 不变时 \(\sum\tau=I\alpha\)。要扣除摩擦等反向力矩，不把输入力矩直接视为合力矩。

Torque uses the perpendicular lever arm. For fixed-axis constant-inertia motion, resultant torque is \(I\alpha\); include opposing frictional torque.

角动量 \(L=I\omega\)，只有关于选定轴的合外力矩为零时守恒：\(I_1\omega_1=I_2\omega_2\)。不要求所有外力都为零。收拢质量可提高角速率，但转动动能可由人体或内部机构做功而改变。

Angular momentum is conserved when resultant external torque about the selected axis is zero, even if external forces exist. Reducing inertia increases angular speed, but rotational kinetic energy need not be conserved.

功、功率、飞轮与线性类比 / Energy, power and flywheels

\(E_{k,\rm rot}=I\omega^2/2\)，恒定力矩做功 \(W=\tau\theta\)，瞬时功率 \(P=\tau\omega\)。若转动和平动同时存在，总动能需包括两项，具体滚动约束按题设；飞轮减速可释放储存的转动动能。

Rotational energy is half inertia times angular speed squared. Constant-torque work and instantaneous power use angular displacement and speed. Include translational energy when the body also moves bodily.

线性对应：\(s\leftrightarrow\theta\)，\(v\leftrightarrow\omega\)，\(a\leftrightarrow\alpha\)，\(m\leftrightarrow I\)，\(F\leftrightarrow\tau\)，\(mv\leftrightarrow I\omega\)。角动量守恒和机械能守恒需要分别检查条件。

Use translational–rotational analogies to organise equations, while checking angular-momentum and energy conservation independently.

Applications / 应用与实验

分析飞轮、涡轮或半径变化系统；若同时平移和转动，两种动能均计入。

Model a rotating flywheel, turbine or changing-radius system; include both rotational and translational energies if the situation includes both.

Common errors / 易错点

角动量守恒要求外转矩可忽略；转数须用每周二π弧度换算。

Angular momentum conservation needs negligible external torque, not merely negligible external force. Revolution counts must be converted using \(2\pi\) rad per turn.

3.13.1 方法 1 · 转动方程、反向与力矩账目 / Rotational equations and reversal

  1. 选转动正向，转数转弧度、rpm转 \(\mathrm{rad\,s^{-1}}\)；\(τ_{net}=I\alpha\) 用净力矩，驱动力矩需加回反向摩擦力矩。 / Keep applied and resultant torque separate.
  2. 恒 \(I\)、恒净力矩才有恒 \(\alpha\)，再用角运动方程；\(I\) 随质量位置变化时，恒力矩不保证恒角加速度。 / State the conditions of the constant-acceleration equations.
  3. 从 \(\theta\)–\(t\) 图斜率求 \(\omega\)、\(\omega\)–\(t\) 面积求角位移、\(\tau\)–\(t\) 面积求角动量变化。原点到非线性曲线点的割线斜率不是该点切线斜率。 / Identify the exact gradient requested.
  4. 转向改变时，先分到 \(\omega=0\) 前后两个阶段；总转过角度为两段绝对值之和，而净角位移可相消。 / Separate angular distance from signed displacement.
  5. \(W_{net}=\Delta( I\omega^2/2)\)；若恒摩擦力矩，\(W_f=\tau_f\theta\) 中角度必须用弧度。求驱动功需另加摩擦耗散。 / Include both stored energy and dissipated work.
  6. 皮带不打滑，两轮边缘同线速；共轴部件同角速度；转矩比由半径比或理想功率守恒求，不能把两种连接混为一谈。 / Distinguish belt coupling from a common axle.

对应真题 / Examples： PH04 · 201901 · Q04；PH04 · 202406 · Q19；PH04 · 202601 · Q05；PH04 · 202306 · Q06；PH04 · 202501 · Q05。

3.13.1 方法 2 · 角动量守恒与系统边界 / Angular momentum and system boundaries

  1. 相对同一固定轴、外力矩冲量可忽略时，总角动量守恒；同轴固连体 \(L=I\omega\)，点质量 \(I=mr_\perp^2\)。 / Define the axis and system.
  2. 两盘反向结合先带符号相加 \(I_1\omega_1+I_2\omega_2=(I_1+I_2)\omega_f\)；碰撞后共同角速率，动能通常损失。 / Conserve angular momentum, not kinetic energy, in a sticking event.
  3. 缩臂等改变同一闭合系统质量分布时，\(I\) 减小、\(\omega\) 增大；\(K=L^2/(2I)\) 可增加，能量来自内部做功。 / Angular-momentum conservation does not require constant kinetic energy.
  4. 有物体离开系统时要计其带走的角动量。 不能因为剩余系统 \(I\) 减小，就把离开物体的角动量也强留在剩余系统。纯释放且无切向冲量时，释放瞬间剩余物体角速率不会凭空跳增。 / Include angular momentum carried away by the released body.
  5. 轴改变会改变 \(I\)，必须使用新轴的题给公式或逐点距离；刚度、质量、惯量是不同物理量。 / Recalculate about the specified axis.

教师核对提示 / Teacher check： PH04 202001 Q04.3 的公布评分文字把释放后的运动员角速率判作增大；该结论不能推广为纯释放的守恒定律。保留原评分图，并区分考试给分说明与完整系统账目。 / Retain the published scheme while flagging the system-boundary issue.

对应真题 / Examples： PH04 · 202301 · Q21；PH04 · 202601 · Q18；PH04 · 201806 · Q24；PH04 · 2018 specimen paper · Q02；PH04 · 202001 · Q04。

3.13.1 方法 3 · 滚动、悬挂驱动与实验偏差 / Rolling, hanging loads and experimental bias

  1. 无滑动时 \(v=R\omega\)、\(a=R\alpha\)、\(s=R\theta\)；滚动动能为 \(Mv^2/2+I\omega^2/2\)。整车平动质量已含车轮，另加的是车轮自转能量，不能重复加平动能。 / Avoid double-counting wheel translation.
  2. 斜面上静摩擦提供绕质心力矩；理想无滑动时接触点瞬时静止，静摩擦可不耗散总机械能。无摩擦由静止释放则滑而不自转。 / Torque need not imply dissipative work.
  3. 同坡滚动 \(a=g\sin\theta/[1+I/(MR^2)]\)；比较质量分布要比较 \(I/(MR^2)\)，不能普遍断言不同物体摩擦力矩相同。 / Use coupled translation and rotation, or energy, for comparisons.
  4. 落锤驱动圆盘：\(mg-T=ma\)、\(Tr=I\alpha\)、\(a=r\alpha\)；张力小于 \(mg\)。若忽略实际轴摩擦，会把较小加速度误归于较大 \(I\)。 / Explain the direction of the inferred-inertia bias.
  5. 测滚动固定距离的时间，光电门需测两位置之间的飞行时间，而非一次遮光时长；可用视频和长度标记、垂直拍摄、重复。 / Match the timing method to the interval required.

对应真题 / Examples： PH04 · 202606 · Q05；PH04 · 202101 · Q05；PH04 · 201906 · Q03；PH04 · 202301 · Q02；PH04 · 202506 · Q05。
