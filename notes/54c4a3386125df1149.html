起点 / Given： q、v、B 及速度与磁场夹角 / charge, velocity, field and angle

由哪些量决定 / Dependence： 磁力同时垂直速度和磁场，不对粒子做功；沿磁场运动时磁力为零 / magnetic force is perpendicular to velocity and field, does no work and vanishes for parallel motion

按物理关系整理公式 / Formulae organised by relationship

关系 1 / Relation 1

\[\Large\displaystyle F=|q|vB\sin\theta\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(F\) 力的大小 / force magnitude \(\mathrm{N}\)
\(q\) 带符号粒子电荷 / signed particle charge \(\mathrm{C}\)
\(v\) 速度或速率，按题设 / velocity or speed as specified \(\mathrm{m\,s^{-1}}\)
\(B\) 磁通密度 / magnetic flux density \(\mathrm{T}\)
\(\theta\) 图示夹角 / labelled angle \(\mathrm{rad}\)

物理关系 / Physical relationship： 只有垂直磁场的速度分量贡献磁力。 / Only the velocity component perpendicular to the field contributes to magnetic force.

适用条件 / Conditions： 单个运动电荷；本模型不把导线电流公式直接代给粒子 / use a moving-charge force relation for a particle

关系 2 / Relation 2

\[\Large\displaystyle W_B=0\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(W_B\) 磁力做功 / work by magnetic force \(\mathrm{J}\)

物理关系 / Physical relationship： 纯磁力始终垂直瞬时速度，因此不改变粒子动能。 / Magnetic force is perpendicular to instantaneous velocity and does not change kinetic energy.
