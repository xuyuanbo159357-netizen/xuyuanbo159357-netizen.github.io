本卷复盘重点 / Paper-specific review

  • deduce后要给是否认同的判断；分子压强解释不能停在碰撞。 Give an explicit deduction and develop pressure explanations beyond collisions. 报告第2页 / Report p2

  • pV图做功注意非零坐标起点；验证等温需分别算出两个pV值。 Account for false origins and compare numerical pV values when testing isothermality. 报告第3页 / Report p3

  • 理想气体 / Ideal Gases：17分，21.25%。 回看 / Review：3.11.3 气体定律与理想气体。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 转动运动 / Rotational Motion：13分，16.25%。 回看 / Review：3.13.1 转动运动学、转动惯量与角动量。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 原子核半径 / Radius Of The Nucleus：10分，12.50%。 回看 / Review：3.12.1 核半径、最接近距离与电子衍射。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.
