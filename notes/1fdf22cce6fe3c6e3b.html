本单元备考重点 / Unit-specific preparation

电路因果链 / Circuit reasoning

由电阻变化推总电流、内耗和路端电压，再回到支路；电源不是恒流源。 Trace resistance changes through source and branch quantities.

波动条件 / Wave conditions

相干、相位、驻波、偏振、全反射要说明条件，且联系题目具体光路或振动。 Apply wave conditions to the specific path and motion.

粒子与光子 / Matter and photons

能级差对应光子能量；电子波用德布罗意关系，光电效应用单光子模型。 Separate energy-level, matter-wave and photoelectric models.

按题型落实 / Applying the command

类型 / Type 答题动作 / What to do
计算 / Calculation 明确模型与适用条件→列方程→SI代入→中间量→结果及单位；需要判断时补结论。 State the model, equation, substitution, result and conclusion.
画图 / Drawing 看清draw或sketch；坐标、量名、单位、起点、峰值、渐近线和方向按题意标明，直线用尺。 Label the requested features and use a ruler for straight lines.
陈述 / Statement 按state/name/define区分名称、事实和严格定义，避免只写符号替代名称。 Match the requested level of recall.
解释 / Explanation 条件或原因→物理关系→变化方向→题境结论；不能只给公式或只复述现象。 Develop the causal link.
实验 / Practical 装置、变量、读数、控制、重复、处理、误差改进形成完整路径；改进应针对已识别偏差。 Tie the procedure and improvements to the experiment.
证明与推断 / Show or deduce 从原理出发展示链条；数值show that显示足够位数以验证给定近似值；deduce需推导或结论依据。 Show the reasoning rather than repeat the supplied result.

考官报告回看 / Examiner-report review

本地有5/17场官方报告；缺失场次未编造考生表现数据。 Reports are available for 5 of 17 papers in the collection.

2024年6月 / June

  • 并联电池电动势不相加；等效内阻须按连接关系计算。 Parallel-cell emfs do not add; combine internal resistances correctly. 报告第3页 / Report p3

  • 解释模态色散要联系不同光路；图线若有非零起点，不能直接把图框边缘作零点。 Explain modal dispersion using paths and recognise false origins on graphs. 报告第4页 / Report p4

2025年1月 / January

  • 相干要求固定相位关系；out of phase 不能等同于反相。 Coherence requires a constant phase relationship; out of phase need not mean antiphase. 报告第4页 / Report p4

  • 视差解释须说明表观位置如何改变计时，再推断速率偏差。 Trace parallax through the timing measurement to the inferred speed. 报告第5页 / Report p5

2025年6月 / June

  • 原考试03.2因题目错误取消考查，所有考生统一获1分；本分析将此分单列。 Question 03.2 was discounted and all candidates received one mark. 报告第3页 / Report p3

  • 线状光谱解释要有光子及量子化能级，不能只有笼统的能量变化。 Use photons and quantised energy levels when explaining line spectra. 报告第5页 / Report p5

2026年1月 / January

  • 电子不是光子；电子波长用德布罗意关系，不能直接用光子公式。 Use the de Broglie relation for electrons rather than the photon energy formula. 报告第3页 / Report p3

  • 标注题需在图中标出位置；测多周期减小相对计时不确定度。 Annotate the figure as instructed and distinguish absolute from relative timing uncertainty. 报告第6页 / Report p6

2026年6月 / June

  • 光电效应解释需联系阈频、单光子能量及一对一相互作用。 Connect threshold frequency to photon energy and one-to-one interactions. 报告第4页 / Report p4

  • 有内阻电源不能视为输出固定电流；加支路会改变总电流与路端电压。 An internal-resistance source does not deliver a fixed current when branches change. 报告第5页 / Report p5

自测与时间分配 / Practice and timing

每套120分钟、80分，平均1.5分钟/分可作为训练预算；这不是官方逐题用时要求。先完成可得分步骤，标记未完成题，最后核对单位、图线与结论。 A 1.5-minute-per-mark budget is a teaching aid, not an official timing rule.
