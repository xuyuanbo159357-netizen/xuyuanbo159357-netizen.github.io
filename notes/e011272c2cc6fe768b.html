知识逐项讲解 / Concept-by-concept guide

Error bar / 误差棒

Definition / 定义

EN: An error bar shows the uncertainty range associated with a plotted measurement.

中: 误差棒表示图上测量数据点对应的不确定度范围。

依据 / Evidence: PH01 202306 Q12 · MS p16（相关计算或应用）

Line of best fit / 最佳拟合直线

Definition / 定义

EN: A line of best fit is a straight line that best represents the trend of a set of plotted data.

中: 最佳拟合直线是最能代表一组已绘制数据整体趋势的直线。

依据 / Evidence: PH01 201906 Q11.1 · MS p12（相关计算或应用）

Gradient / 斜率

Definition / 定义

EN: The gradient of a straight-line graph is the change in the vertical-axis quantity divided by the corresponding change in the horizontal-axis quantity.

中: 直线图像的斜率是纵轴量的变化除以对应横轴量的变化。

Formula / 公式

\[\Large\displaystyle m=\frac{\Delta y}{\Delta x}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(m\) 斜率 / gradient \(\mathrm{\text{unit of }y\,/\,\text{unit of }x}\)
\(\Delta y\) 纵轴量的变化 / change in vertical-axis quantity \(\mathrm{\text{unit of }y}\)
\(\Delta x\) 横轴量的变化 / change in horizontal-axis quantity \(\mathrm{\text{unit of }x}\)

Formula / 公式

\[\Large\displaystyle m=\frac{\Delta y}{\Delta x}\]
\[\Large\displaystyle y=mx+c\]
\[\Large\displaystyle \Delta m=\frac{m_{\max}-m_{\min}}{2}\quad\text{(if using the half-range convention)}\]

Explanation / 讲解

数据点与直线 / Points and lines

误差棒的横向、纵向半长度分别表示 \(\Delta x\)、\(\Delta y\)。Error bars show uncertainty in each coordinate. 最佳拟合直线应合理代表数据趋势，不要求穿过每个点的中心。A best-fit line represents the trend rather than joining all point centres.

梯度用直线上相距较远的两个点计算：choose a large triangle on the fitted line.

\[\Large\displaystyle m=\frac{\Delta y}{\Delta x},\qquad y\]

\[\Large\displaystyle m=mx+c\]

梯度单位为纵轴单位除以横轴单位，截距单位为纵轴单位。The gradient and intercept carry different units.

不确定度 / Uncertainty

在误差范围内画最陡和最缓的合理直线，得到 \(m_{\max}\)、\(m_{\min}\)。Draw acceptable steepest and shallowest lines. 按题目约定可报告

\[\Large\displaystyle \Delta m=\frac{m_{\max}-m_{\min}}{2}\]
或采用最佳梯度与极端梯度之间的最大差，并明确说明。Use the specified convention; otherwise state how the range was estimated.

同样读取允许的截距 \(c_{\max}\)、\(c_{\min}\)，估算 \(\Delta c\)。无误差棒时根据数据散布画合理的极端直线，不能假装知道更小的范围。Without error bars, use the observed scatter to justify the extreme lines.

物理含义 / Physical meaning

\(s\) 对 \(t^2\) 图像中梯度为 \(g/2\)；\(F\) 对 \(\Delta L\) 图像中梯度为 \(EA/L\)。把图像梯度转成物理量时，不确定度也按同一比例转化。Convert the gradient and its uncertainty using the same model.

若模型预期截距为零，而测得截距显著偏离零，应检查零点、基准位置或计时延迟。A significant intercept may indicate a systematic offset.

读图 / Reading： 横、纵误差棒分别表示两个坐标量的不确定度；拟合线考虑所有数据与误差范围，不能逐点折线连接。

Horizontal and vertical bars show the corresponding uncertainties; fit the overall trend rather than joining successive points.

图示：斜率不确定度 / Gradient uncertainty

读图 / Reading： 比较合理的最陡、最缓直线与最佳线；允许的直线应与数据的不确定度范围相容，而不是只选最近的两个点。

Compare plausible steepest and shallowest lines with the best fit, respecting uncertainty ranges and using widely separated points.

M06 方法 1 · 拟合、截距与极限斜率 / Fits, intercepts and extreme gradients

  1. 拟合反映整体趋势，斜率从线上相距较远的两点读，不直接连接最靠近的测量点；曲线瞬时变化率画指定点切线。 / Distinguish fitting a trend from taking a local derivative.
  2. 先与 \(y=mx+b\) 对照，识别实际坐标及倍率；非零截距可以来自固定预载或零误差，未必改变斜率。 / Interpret a systematic offset separately from the gradient.
  3. 最陡、最缓允许直线应通过所有相关误差棒；参数不确定度常取允许值半范围，再按关系传播。 / Use lines consistent with the data.
  4. “正比”不仅要求直线，还要求应有的原点；远距离外推需说明数据范围不足，不能把拟合关系无条件推广。 / State the limit of the inference.
