读题到建模 / From wording to a model

flowchart LR
    K["关键词 / Cues"] --> S["对象与阶段 / System and stage"]

    C --> L["物理规律 / Laws"]

单个关键词常提示候选模型；最终规律由题目条件决定。collide提示碰撞，elastic补充动能守恒条件，move together补充共同末速度条件。 / A cue suggests a model; an additional condition determines the usable equations.

3.1 测量与误差 / Measurements and errors

关键词 / Cues 模型 / Model 核心判断 / Key check
best-fit line（最佳拟合直线）；gradient / intercept（斜率 / 截距） PM01 实验图像与不确定度模型 轴名决定斜率意义 / Axes determine gradient meaning.

3.2.1–3.2.5 运动与力 / Motion and forces

关键词 / Cues 模型 / Model 核心判断 / Key check
equilibrium / stationary（平衡 / 静止）；constant velocity（恒定速度） PM02 受力平衡与斜面分解模型 平衡须合力为零 / Equilibrium requires zero resultant force.
pivot / hinge（支点 / 铰链）；held stationary（保持静止） PM03 力矩平衡与支点模型 力与力矩均平衡 / Balance forces and moments.
from rest（从静止开始）；constant / uniform acceleration（恒定 / 均匀加速度） PM04 匀加速度与分段运动模型 所选阶段加速度恒定 / Acceleration must be constant in the interval.
gradient / tangent（斜率 / 切线）；area under（图线下面积） PM05 运动图像与方向变化模型 斜率给变化率，面积须带符号 / Interpret gradients and signed areas.
dropped / released from rest（放下 / 从静止释放）；thrown vertically upwards（竖直向上抛出） PM06 竖直抛落与自由落体模型 仅重力阶段取a=±g / Use gravity-only motion in the specified interval.
projectile / fired / launched（抛体 / 发射 / 抛出）；horizontally（水平地） PM07 抛体独立分运动模型 两分运动共用时间 / Components share the same flight time.
air resistance / drag（空气阻力 / 流体阻力）；terminal speed（终极速率） PM08 阻力与终极速率模型 稳定极限速率时合力为零 / Terminal motion has zero resultant force.
resultant / net force（合力）；connected by a cable（由绳或缆连接） PM09 牛顿定律与连接体模型 各物体受力方程加连接约束 / Combine force equations and constraints.

3.2.6 动量 / Momentum

关键词 / Cues 模型 / Model 核心判断 / Key check
collide / collision（碰撞 / 碰撞过程）；elastic / elastically（弹性的 / 弹性地） PM10 碰撞模型 外冲量条件与动能分类分别检查 / Check external impulse and kinetic energy separately.
explode / explosion（爆炸 / 爆炸过程）；recoil / fragments（反冲 / 碎块） PM11 爆炸与反冲模型 动量可守恒，动能可增加 / Momentum can be conserved as kinetic energy rises.
average force / contact time（平均力 / 接触时间）；rebound / bounce（反弹 / 弹跳） PM12 冲量停止与反弹模型 合冲量等于动量变化 / Net impulse equals momentum change.

3.2.7–3.2.8 功与能量 / Work and energy

关键词 / Cues 模型 / Model 核心判断 / Key check
height / lifted / descends（高度 / 提升 / 下降）；work done / distance（做功 / 距离） PM13 功与能量收支模型 明确系统并列能量收支 / Define the system and energy account.
power / per second（功率 / 每秒）；input / useful output（输入 / 有用输出） PM14 功率效率与恒速行驶模型 区分输入与有用输出 / Distinguish input and useful output.

3.2.9–3.2.10 材料 / Materials

关键词 / Cues 模型 / Model 核心判断 / Key check
density / mass / volume（密度 / 质量 / 体积）；diameter / cylinder / disc（直径 / 圆柱 / 圆盘） PM15 密度质量与几何体积模型 几何体积连接质量与密度 / Geometry links volume, mass and density.
spring constant / stiffness（弹簧常量 / 劲度）；extension / unstretched length（伸长量 / 未伸长原长） PM16 弹簧形变与弹性储能模型 比例关系与可恢复性分别判断 / Distinguish proportionality and recoverability.
elastic / returns to（弹性 / 回到原状态）；plastic / permanent（塑性 / 永久的） PM17 材料弹性塑性与曲线模型 从轴名和卸载路径读性质 / Read axes and unloading behaviour.
wire / cable（细线 / 缆绳）；Young modulus / same material（杨氏模量 / 相同材料） PM18 线材拉伸与杨氏模量模型 E为材料性质，k还取决于几何 / E is a material property; k depends on geometry.

3.3 原子与放射性 / Atoms and radioactivity

关键词 / Cues 模型 / Model 核心判断 / Key check
Rutherford / scattering（卢瑟福 / 散射）；most pass through（多数穿过） PM19 Rutherford散射与核式结构模型 观察必须与结构推断配对 / Pair observations with structural inferences.
nucleon number / proton number（核子数 / 质子数）；isotopes（同位素） PM20 核素离子与比荷模型 先确认对象，再定Q与m / Identify the object before assigning Q and m.
annihilation / particle and antiparticle（湮灭 / 粒子与反粒子）；pair production / photon（成对产生 / 光子） PM21 湮灭与成对产生模型 两份静止能量及动量均须考虑 / Account for both rest energies and momentum.
alpha decay（α衰变）；beta-minus / beta-plus（β⁻ / β⁺衰变） PM22 核衰变方程与守恒模型 平衡核子数、电荷并补中微子 / Balance nucleon number and charge; include neutrinos.
half-life（半衰期）；activity / count rate（活度 / 计数率） PM23 半衰期与背景扣除模型 先扣背景，再逐次减半 / Subtract background before repeated halving.
absorber / penetrating（吸收物 / 有穿透力的）；thickness / gauge（厚度 / 测厚装置） PM24 辐射吸收与厚度检测模型 需有可测的部分透射 / Useful monitoring needs partial transmission.
inverse-square（反平方）；distance / gamma source（距离 / γ源） PM25 点源扩散与反平方模型 扣背景后使用平方距离比 / Apply squared distance ratios to corrected rates.

一题切换多个模型 / Linked stages in one question

2026年6月 Q07：抛体 → 碰撞 → 冲量

  • 7.1： PM07 抛体独立分运动模型——水滴到达昆虫时水平运动，竖直速度为零，先求高度。 / Find height at the top of the trajectory.
  • 7.2–7.3： PM10 碰撞模型——非弹性且碰后一起运动，使用共同末速度的水平动量守恒。 / Use the sticking-collision momentum equation.
  • 7.4： PM12 冲量停止与反弹模型——改选昆虫为对象，用接触时间和它的动量变化求平均力。 / Switch to the insect as the subsystem for average force.
