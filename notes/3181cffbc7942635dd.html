3.9.2 放射性指数衰变 / Exponential changes in radioactivity

考纲 / Specification： 3.9.2　｜　本单元知识谱系

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

Concept / 概念

  • decay constant — 衰变常量
  • activity — 活度
  • half-life — 半衰期

Definition / 定义

↗ decay constant — 衰变常量

Definition / 定义

English: The probability per unit time that an individual nucleus will decay.

中文： 单个原子核在单位时间内发生衰变的概率。

↗ activity — 活度

Definition / 定义

English: The number of nuclear decays per unit time in a radioactive sample.

中文： 放射性样品单位时间发生的核衰变数。

↗ half-life — 半衰期

Definition / 定义

English: The time for the number of undecayed nuclei, or the activity, to fall to half its initial value.

中文： 未衰变核数或活度降为初值一半所需时间。

Formula / 公式与单位

活度单位 Bq，衰变常量单位 s\(^{-1}\)；质量与摩尔质量使用一致单位。

\(dN/dt=-\lambda N\); \(N=N_0e^{-\lambda t}\); \(A=\lambda N=A_0e^{-\lambda t}\); \(T_{1/2}=\ln2/\lambda\); \(N=(m/M)N_A\).

Conditions / 条件与范围

采用同一种核素且概率恒定；固定探测效率与几何、扣除背景后，计数率才与活度成正比。

Use a single radionuclide with constant decay probability. Detected count rate is proportional to activity only with fixed detection efficiency/geometry and corrected background.

Explanation / 解释

随机性、衰变概率与活度 / Randomness and activity

不能预测某一个核何时衰变，但给定核素每个尚未衰变核在单位时间的衰变概率恒定。\(dN/dt=-\lambda N\)，\(N=N_0e^{-\lambda t}\)；负号表示未衰变核数减少。

Individual decay times are unpredictable, while each undecayed nucleus of a given isotope has a constant decay probability per unit time. The negative number gradient describes loss of undecayed nuclei.

活度是每秒衰变数，取正值：\(A=-dN/dt=\lambda N=A_0e^{-\lambda t}\)，单位 Bq。衰变常量单位 \(\mathrm{s^{-1}}\)；“随机”不代表样品没有可预测的统计规律。

Activity is the positive decay rate, not the negative derivative itself. Random individual behaviour still gives predictable statistical behaviour for a large sample.

掷骰子模型：每轮移除出现指定点数的骰子，其余继续投掷；每个剩余骰子的移除概率相同，剩余数量近似指数衰减。

Repeatedly removing a specified die face models constant individual decay probability and an approximately exponential remaining population.

半衰期、核数和图像 / Half-life, nuclei and graphs

\(N=(m/M)N_A\)（质量和摩尔质量单位一致），再用 \(A=\lambda N\)。\(T_{1/2}=\ln2/\lambda\)；经过 \(n\) 个半衰期，剩余比例 \(2^{-n}\)，已衰变比例为 \(1-2^{-n}\)。

Convert sample mass to nuclei using molar mass and Avogadro constant. Distinguish the remaining fraction from the decayed fraction.

测量计数率先扣背景：\(C_{\rm net}=C_{\rm measured}-C_{\rm background}\)。在效率和几何不变时净计数率与活度成正比；作 \(\ln C_{\rm net}\)–\(t\)，斜率 \(-\lambda\)。原曲线可从任意净计数率减半区间求半衰期并多次平均。

Subtract background before logarithmic analysis or halving. With fixed efficiency and geometry, net count rate is proportional to activity. A natural-log gradient gives \(-\lambda\).

Applications / 应用与实验

先扣背景，再使用衰变曲线、对数或比值；掷骰模型用每轮固定概率模拟随机衰变。

Subtract background first, then use decay graphs, logarithms or ratios. A dice model removes a fixed-probability fraction each round and models random decay.

Common errors / 易错点

探测计数不必等于真实衰变数；半衰期与该核素当前数量无关。

Measured detector counts are not necessarily the actual number of decays. Half-life does not depend on the amount of the isotope present.

3.9.2 方法 1 · 衰变数量、质量与功率账目 / Decay counts, mass and power

  1. \(\lambda=\ln2/T_{1/2}\)，先使时间单位一致；\(A=\lambda N\)，\(N=(m/M)N_A\)。活度单位Bq表示每秒衰变，不是探测器每秒计数。 / Distinguish activity from detected count rate.
  2. \(N=N_0e^{-\lambda t}\) 是剩余母核；衰变数 \(N_0-N\)。最初无子核且子核稳定时，\(N_d=N_0(1-e^{-\lambda t})\)。 / Distinguish remaining nuclei from daughter production.
  3. 衰变掉的该同位素质量可用质量的指数变化或 \(\Delta N=\Delta A/\lambda\) 求，不能把它当作整个封闭样品的质量亏损。 / Isotope depletion is not the mass defect of the whole sample.
  4. 每次释放能量 \(E_d\) 时总释放功率 \(P=AE_d\)；真正加热功率还要扣除逃逸粒子、尤其弱相互作用的中微子带走的能量。 / Separate energy release from deposited heat.
  5. 倒推初活度 \(A_0=Ae^{\lambda t}\)；核对结果应较大。混匀示踪测体积先把总活度衰减到取样时，再用总活度/样品活度乘样品体积。 / Compare all activities at the same time.

3.9.2 方法 2 · 随机性、对数图与年代局限 / Randomness, log graphs and dating limits

  • 随机是无法预测某个核何时衰变；大样品总量可作较可靠统计预测。一个核存活一个半衰期，不会增加下一半衰期内的条件衰变概率。 / Survival does not change the decay probability for the next equal interval.
  • \(\ln A=\ln A_0-\lambda t\)：斜率 \(-\lambda\)，截距是对数；若横轴为小时，先换成 \(\mathrm{s^{-1}}\) 再用Bq求核数。 / Convert a logarithmic intercept and its time unit correctly.
  • 骰子模型每轮剩余比例 \(1-p\)，\(N_n=N_0(1-p)^n\)；连续指数等效 \(\lambda=-\ln(1-p)/\Delta t\)，小概率才近似 \(p/\Delta t\)。 / Distinguish the discrete survival law from the approximation.
  • 碳定年需考虑初始比例、碳含量、现代碳污染、木材年龄与器物制作年龄的区别；时间过长则净活度接近背景，过短则变化太小。 / Link each limitation to the measured ratio or activity.
  • 检验指数关系用净计数率、等时间比值或对数直线；不要对“已衰变核数”直接套剩余母核的直线规律。 / Identify exactly what is plotted.
