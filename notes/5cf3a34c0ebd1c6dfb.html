关系 1 / Relation 1

\[\Large\displaystyle P_{\mathrm{in}}=I_{rad}A\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(P_{\mathrm{in}}\) 输入功率 / input power \(\mathrm{W}\)
\(I_{rad}\) 辐射强度 / irradiance \(\mathrm{W\,m^{-2}}\)
\(A\) 面积 / area \(\mathrm{m^2}\)

物理关系 / Physical relationship： 入射辐射功率等于强度乘有效迎光面积。 / Incident radiative power is irradiance times effective illuminated area.

适用条件 / Conditions： 相同电池、相同照明且忽略连接损失时使用简单阵列倍数 / simple scaling assumes identical equally illuminated cells and negligible wiring losses

关系 2 / Relation 2

\[\Large\displaystyle P=VI\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(P\) 功率 / power \(\mathrm{W}\)

物理关系 / Physical relationship： 元件接收的电功率由其端电压和电流决定。 / Electrical power depends on terminal voltage and current.

适用条件 / Conditions： 相同电池、相同照明且忽略连接损失时使用简单阵列倍数 / simple scaling assumes identical equally illuminated cells and negligible wiring losses

关系 3 / Relation 3

\[\Large\displaystyle P_{\mathrm{array}}=N_sN_pP_c\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(P_{\mathrm{array}}\) 理想阵列输出功率 / ideal array power \(\mathrm{W}\)
\(N_s\) 每串电池数量 / cells in each series string \(1\)（无量纲 / dimensionless）
\(N_p\) 并联支路数 / parallel strings \(1\)（无量纲 / dimensionless）
\(P_c\) 单电池功率 / single-cell power \(\mathrm{W}\)

物理关系 / Physical relationship： 相同工作状态下，理想阵列总功率为电池总数乘单电池功率。 / For equally operated identical cells, ideal array power is cell count times cell power.

适用条件 / Conditions： 相同电池、相同照明且忽略连接损失时使用简单阵列倍数 / simple scaling assumes identical equally illuminated cells and negligible wiring losses

3.13.3 太阳辐射、太阳能电池与阵列

反平方规律假设各向同性点源、无显著吸收；地面太阳辐射受大气、天气、纬度、季节、时间与朝向影响，按题给数据计算。

Inverse-square law assumes a point/isotropic source and negligible intervening absorption. At Earth’s surface solar intensity depends on atmosphere, cloud, latitude, season, time and panel orientation; use supplied data.

光强单位 W m\(^{-2}\)；注意 I 可代表光强，也可代表电流，按语境区分。
