基本模型的物理关系 / Physical relationships of the basic model

起点 / Given： 图上两点、误差棒或重复测量值 / two graph points, error bars or repeat readings

由哪些量决定 / Dependence： 增大所测总量可减小相对仪器不确定度；重复测量取均值主要减小随机影响 / a larger measured total reduces relative instrumental uncertainty; averaging mainly reduces random effects

按物理关系整理公式 / Formulae organised by relationship

关系 1 / Relation 1

\[\Large\displaystyle k_g=\frac{\Delta y_g}{\Delta x_g}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(k_g\) 图像斜率 / graph gradient 纵轴单位/横轴单位
\(\Delta y_g\) 纵坐标间隔 / ordinate interval 纵轴的 SI 单位
\(\Delta x_g\) 横坐标间隔 / abscissa interval 横轴的 SI 单位

物理关系 / Physical relationship： 斜率等于纵坐标变化与横坐标变化之比，单位由两轴决定。 / Gradient is the change of ordinate divided by the change of abscissa, with units determined by the axes.

适用条件 / Conditions： 两点不必是原始数据点；极限直线须与误差棒相容 / gradient points need not be measured points; limiting lines must be compatible with error bars

关系 2 / Relation 2

\[\Large\displaystyle \text{percentage uncertainty}=\frac{\Delta X}{|X|}\times100\%\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\Delta X\) 测量不确定度 / measurement uncertainty 与 X 相同
\(X\) 所测物理量 / measured quantity 依物理量确定

物理关系 / Physical relationship： 相同绝对不确定度下，测量值越大，相对不确定度越小。 / A larger measured value gives lower relative uncertainty for a fixed absolute uncertainty.

适用条件 / Conditions： 两点不必是原始数据点；极限直线须与误差棒相容 / gradient points need not be measured points; limiting lines must be compatible with error bars

English cue 中文 应如何判断 / Interpretation

核心模型与条件 / Model and conditions

测量量通过物理关系转成直线关系 \(y=mx+c\)，斜率或截距给待测量。先确认实际纵轴与横轴；相同字母的图像未必代表相同物理量。 / Linearise the physical relation and interpret the actual plotted axes.

重复测量并平均可减小随机误差的影响；固定系统偏差须用校准、零点修正或方法改进处理。 / Averaging reduces random effects; a fixed systematic offset needs correction.

读图 / Reading: 误差棒给出各读数范围，拟合直线代表整体趋势。 / Error bars show measurement ranges; the fitted line represents the trend.

解题流程 / Method

  1. 把理论关系写成图像变量形式，找斜率和截距。 / Rewrite the physical equation using the plotted variables.
  2. 最佳拟合直线上选相距较远的两点求斜率，并写单位。 / Use a large triangle on the fitted line.
  3. 极限斜率线须与误差棒相容；按题目或评分标准给定约定求斜率不确定度。 / Use acceptable limiting lines and the stated uncertainty convention.
  4. 例如 \(s\)–\(t^2\) 图的斜率为 \(g/2\)（从静止自由落体）；\(F\)–\(\Delta L\) 图的斜率为 \(k\)。 / Match the gradient to the specific equation.

易错判断 / Checks

斜率有单位；截距不一定为零。 横纵轴交换后斜率取倒数，待测量的求法也改变。 / A gradient has units; reversing the axes changes its interpretation.
