知识逐项讲解 / Concept-by-concept guide

Terminal speed / 终极速率

Definition / 定义

EN: Terminal speed is the constant speed reached by a falling object when the resultant force on it is zero.

中: 终极速率是下落物体所受合力为零时达到的恒定速率。

表达要点 / Wording: constant speed; zero resultant force

依据 / Evidence: PH01 202506 Q06.4 · MS p10（相关计算或应用）；PH01 202406 Q07.2 · MS p11（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \sum F=0\]
\[\Large\displaystyle a=0\]
\[\Large\displaystyle D=mg\quad\text{(weight-and-drag model)}\]
\[\Large\displaystyle P_{\rm drive}=F_{\rm drive}v\]

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
终极速率 / terminal speed \(v_{\mathrm{terminal}}\) \(\mathrm{m\,s^{-1}}\) 也常写 v_t；题设优先 / Also v_t; follow the question.
阻力 / drag force \(D,\ F_{\mathrm{drag}}\) \(\mathrm{N}\)
重力 / weight \(W,\ F_g\) \(\mathrm{N}\) W 在本语境表示重力；功的单位为 J / Here W means weight, not work.
质量 / mass \(m\) \(\mathrm{kg}\) 与重力不同 / Not weight.
重力加速度、引力场强 / gravitational acceleration, field strength \(g\) \(\mathrm{m\,s^{-2}}\) 等效单位 N kg⁻¹；按所述物理量解释 / N kg⁻¹ is equivalent; interpret the quantity in context.
功率 / power \(P\) \(\mathrm{W}\) 斜体 P 为功率，正体 W 为瓦特 / P is the quantity; upright W is the watt.
力 / force \(F\) \(\mathrm{N}\) 矢量；合力常记 ΣF 或 F_resultant / Vector; resultant force is often ΣF or F_resultant.
速率 / speed \(v\) \(\mathrm{m\,s^{-1}}\) 速度的大小 / Magnitude of velocity.
加速度 / acceleration \(a\) \(\mathrm{m\,s^{-2}}\)

Conditions / 适用条件

若只保留重力与阻力两力，终极速率时阻力与重力相等；存在其他力时应使用完整的合力平衡。 / Weight equals drag in the two-force model; include other forces when present.

Explanation / 讲解

下落物体 / Falling object

释放后速率较小，空气阻力较小，重力大于阻力，因此向下加速。随速率增加，阻力增加，合力和加速度逐渐减小。Increasing drag reduces the downward resultant force.

终极速率时 \(mg=D\)，\(a=0\)，物体继续以恒定速度下落。Terminal motion has nonzero velocity and zero acceleration.

降落伞张开后，迎风面积增大，阻力可能暂时大于重力，使向下运动减速，最终到达较低的终极速率。A larger drag force produces a new, lower terminal speed.

图示：终速时受力平衡 / Force balance at terminal speed

读图 / Reading： 开始下落时阻力小于重力；速率增大使阻力增加，直至阻力等于重力，合力与加速度为零，但速度不为零。

Initially drag is smaller than weight; increasing speed raises drag until forces balance, so acceleration is zero while velocity remains non-zero.

图示：终速图像 / Terminal-speed graph

读图 / Reading： 速度趋于水平线时，曲线斜率趋于零，即加速度趋于零。若打开降落伞，应重新判断新阻力与重力的关系。

As velocity approaches a horizontal asymptote, its gradient and acceleration approach zero. Opening a parachute changes the force balance.

车辆 / Vehicle

最大恒定速率时，驱动力与总阻力平衡。若有效驱动功率给定，沿运动方向 \(P=Fv\)；速度提高时，给定功率能提供的驱动力降低，同时空气阻力增大。At a steady maximum speed, driving and resistive forces balance.

发动机可用功率、车身形状、迎风面积、路面阻力和坡度影响最大速率。说明因素时应连接“力或功率变化”与平衡，而不是只列名词。Explain how a factor changes the balance.

D14 方法 1 · 终速与改变后的新平衡 / Terminal speed and a changed balance

  1. 竖直下落终速时合力为零，阻力与重力（若题给浮力则还需计浮力）平衡；速度不为零，加速度为零，能量仍可向空气转移。 / Zero resultant force does not mean zero motion or zero power.
  2. 同外形、同介质，较重通常终速较大；从静止释放且初始阻力为零时初加速度约为 \(g\)，与质量无关。 / Separate initial acceleration from terminal speed.
  3. 开伞后阻力可先大于重力，物体仍向下但减速，直至较小新终速；不能说一开伞速度立即跳到新终速。 / Describe the transient as well as the final balance.
  4. 车辆恒驱动力时阻力增加到相等；给恒功率时驱动力应为 \(P/v\)。检验阻力平方律在终速取 \(F=mg\)，再检查 \(v^2\) 对重量的正比。 / Use the actual engine constraint.
