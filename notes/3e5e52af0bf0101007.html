U1 答题规范 / Exam answering conventions

返回 U1 真题练习 / Past-paper practice

适用范围 / Scope： OxfordAQA International AS and A-level Physics 9630 · PH01。

测量与误差、力学与材料、原子与放射性 / Measurements and uncertainties; mechanics and materials; atoms and radiation。

本栏目位于本单元“真题练习”下，依据库内已核对的历年评分例证总结，不增加考纲内容。定义的完整知识讲解仍由关联知识笔记承载。 / This section belongs to the unit's past-paper practice and summarises checked historical marking examples within the specification. Full definitions remain in the linked knowledge notes.

本单元优先检查 / Priority checks for this unit

  • 有效数字与图线斜率： 不同题目分别要求至少三位、二或三位，或不确定度一至两位。 / Precision varies between questions.
  • 矢量、守恒与能量： 写清方向、系统和能量名称；用数值比较支持结论。 / Identify directions, systems and energy stores; justify conclusions numerically.
  • 物理定义与辐射论述： 定义保留限定词；辐射选择联系穿透性、电离性及半衰期。 / Retain defining conditions and connect radiation properties to their use.

同一大题的数据沿用 / Carrying answers into later parts

课堂统一答题规范 / Classroom convention

同一大题内，后续小问用到前面小问的答案数据时，直接使用前问已写出的答案数值，不改用计算器内保留的更精确值。前问若为证明题，后续直接使用题目要求证明的数值。

Within the same question, use the numerical answer reported in the earlier part when it is required in a later part, rather than a more precise calculator value. If the earlier part is a show-that question, use the value stated in that question for later parts.

区分两个阶段：同一小问内部保留中间精度；跨小问沿用已报告的答案或题给证明值。 / Within one part, retain intermediate precision; between parts, carry forward the reported answer or the stated show-that value.

这是本知识库采用的课堂统一约定；原评分标准有时还接受其他跟进路线，不将本约定表述成考局所有题目的唯一评分规则。若题目另给指定数据，以该明确指令为准。 / This is the classroom convention used in this vault. Some mark schemes also accept other follow-through routes; it is not presented as the board's sole permitted method. Follow any explicit value separately specified in the question.

如何使用评分例证 / How to use the evidence

  • 物理原则 / Physical principle： 各题都应保持物理量、关系、条件和方向正确。 / Keep quantities, relationships, conditions and directions physically correct.
  • 推荐书写 / Presentation advice： 用于让推理清楚可查，不自动等于独立评分点。 / Makes reasoning visible; not every recommendation is a separate mark.
  • 本题明确要求 / Question-specific requirement： 标注试卷、题号和评分标准 PDF 页；仅用于所引题目。 / Paper, question and MS PDF page identify the exact restriction.
  • 点击“原题与答案”可进入既有题目页，答案仍在题下默认折叠。点击 MS 链接可核对原评分页。 / Open the original practice note for its collapsed answer, or the MS page for the rubric.

自检顺序 / Review order： 题问与指令词 → 模型及条件 → 计算或图示 → 物理解释 → 单位、精度及数据沿用。 / Task → model and conditions → calculation or diagram → explanation → units, precision and carried answers.
