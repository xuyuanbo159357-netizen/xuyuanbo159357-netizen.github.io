U1/06 真题练习/答题规范

U1 实验、数据与评价 / Practical data and evaluation

U1 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 实验方法要能执行 / Make the method reproducible

写明仪器及其测量对象、操作方法、重复方式、控制变量和数据处理关系。笼统写“measure accurately”或“repeat”不能说明改进了什么。 / Name the instruments and quantities, procedure, repeats, controlled variables and processing relationship.

  • 测 \(g\)：明确释放条件、实际下落距离和对应计时区间；\(s=\tfrac12gt^2\) 只适用于所选区间从静止释放且阻力可忽略。 / Specify release conditions and the matching distance and timing interval.
  • 测杨氏模量：原长、伸长、拉力和横截面积各自如何测量应明确；多处测直径可以检查线材粗细变化。 / Explain how original length, extension, force and cross-sectional area are measured.

这些是依据实验物理关系整理的方法框架；本节不新增必做实验范围。 / This is a method-writing framework within the existing practical scope.

2. 拟合与数据提取 / Fit and extract data

2018 June Q10 要求准确落点、合理最佳拟合线、大斜率三角形和图上标记读数；不能只在答案栏给一个斜率。 / The cited graph task requires evidence of the fit and the readings used for the gradient. PH01 2018 June Q10.1–10.4 · MS PDF p14 · 原题与答案 / Question and answer

由图得到的 \(k\) 代入 \(E=kL/A\) 时，写出单位换算，保持足够中间精度。 / Carry the gradient into the physical calculation with consistent units and adequate precision.

3. 不确定度传播 / Propagate uncertainty correctly

加减量合成绝对不确定度；乘除量合成相对或百分比不确定度；幂的绝对值乘相对不确定度。 这是本课程常用的最大不确定度估算方法，并不把随机误差简单等同于极差。 / Combine absolute uncertainties for sums and differences, fractional uncertainties for products and quotients, with powers as multipliers; this is the course's usual worst-case estimate.

2019 January Q09.1–09.2 给出 \(t=0.79\ \mathrm s\)、\(\Delta t=0.02\ \mathrm s\)，对 \(a=2s/t^2\) 使用 \(\%\Delta a=\%\Delta s+2\%\Delta t\)。最终不确定度一至两位有效数字，不能照抄加速度的位数。 / The time uncertainty enters twice; report the uncertainty with its own appropriate precision. PH01 2019 January Q09.1–09.2 · MS PDF p12 · 原题与答案 / Question and answer

4. 评价和改进要对应问题 / Link a limitation to its remedy

2019 January Q09.3–09.4：摩擦使小车所受合力减小；轻微倾斜轨道、补偿拉力或采用直线气垫导轨，是该题接受的相应处理。应说明改进针对的是摩擦，而不是泛写“use better apparatus”。 / Explain the effect of friction and how the proposed change addresses it. PH01 2019 January Q09.3–09.4 · MS PDF p12 · 原题与答案 / Question and answer

  • 随机散布 / Random scatter： 重复测量、合理平均可改善均值估计，但不消除系统偏差。 / Repeats can improve the mean; they do not remove a systematic bias.
  • 系统偏差 / Systematic bias： 检查零点、校准或修正测量方法，并说明偏大还是偏小（若可判断）。 / Address the source of bias and its effect where identifiable.
  • 辐射计数题先确认是否需要扣除背景及统一计数时间；不要对背景已修正的数据再次扣除。 / Check whether background subtraction and a common counting interval are required.
方法评价句式 / Evaluation sentence frame

问题 → 影响 → 改进 → 改进理由。 / Limitation → effect → modification → why it helps.

“Friction reduces the resultant force on the trolley. A slight downward tilt can compensate for this friction.” / 摩擦减小小车合力；适当向下倾斜轨道可补偿摩擦。该做法针对上述小车情境，不能外推为所有实验的通用改进。
