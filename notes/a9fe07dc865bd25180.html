条件词优先检查 / Check condition words first

条件词 / Condition 中文 物理作用 / Role
negligible 可忽略 判断哪一个影响可忽略，不能把所有外力都删掉 / Identify the particular neglected effect.
uniform / constant 均匀 / 恒定 看修饰的是材料、力、加速度还是速率 / Identify the quantity it describes.

isolated / no external force 孤立 / 无外力 结合所选系统或方向判断动量条件 / Check the system and direction for momentum conservation.

moves together 一起运动 检查是否表示碰后同一组合、共享末速度 / Check the shared final velocity condition.

falls freely / negligible air resistance 自由下落 / 空气阻力可忽略 PM06 竖直抛落与自由落体模型 仅重力主导的阶段 / Identify the gravity-only interval.
highest point 最高点 PM06 竖直抛落与自由落体模型 竖直速度为零，加速度仍向下 / Vertical velocity is zero but gravity remains.
projectile / fired / launched 抛体 / 发射 / 抛出 PM07 抛体独立分运动模型 先检查阻力条件，再分解运动 / Check drag and resolve the motion.
horizontally 水平地 PM07 抛体独立分运动模型 水平抛出时 uᵧ=0；飞行中某时刻水平则 vᵧ=0 / Distinguish launch direction from a later velocity.
angle to the horizontal 与水平的夹角 PM07 抛体独立分运动模型 uₓ=u cosθ，uᵧ=u sinθ / Resolve the launch velocity.
range / time of flight 水平射程 / 飞行时间 PM07 抛体独立分运动模型 先用竖直运动求时间 / Determine time from vertical motion.
air resistance / drag 空气阻力 / 流体阻力 PM08 阻力与终极速率模型 阻力与相对流体运动方向相反 / Drag opposes motion relative to the fluid.
terminal speed 终极速率 PM08 阻力与终极速率模型 合力为零且速率稳定 / Resultant force is zero at steady terminal motion.
parachute opens 降落伞打开 PM08 阻力与终极速率模型 阻力突增，先检查加速度方向 / Increased drag can reverse the acceleration.
maximum speed / engine power 最大速率 / 发动机功率 PM08 阻力与终极速率模型 稳定行驶时驱动力与阻力平衡 / Balance driving and resistive forces at steady speed.
resultant / net force 合力 PM09 牛顿定律与连接体模型 F=ma中的F必须是矢量合力 / Use the vector resultant in F=ma.
connected by a cable 由绳或缆连接 PM09 牛顿定律与连接体模型 选单个物体或整体系统 / Choose an individual body or the whole system.
frictionless pulley / negligible extension 无摩擦滑轮 / 伸长可忽略 PM09 牛顿定律与连接体模型 按题设约束判断拉力和加速度关系 / Apply the stated idealisations.
string is cut / immediately after 绳被切断 / 紧接之后 PM09 牛顿定律与连接体模型 重画受力图；速度与弹簧伸长不瞬变 / Redraw forces without making velocity or extension jump.
collide / collision 碰撞 / 碰撞过程 PM10 碰撞模型 先建立相互作用的物体系统 / Identify the interacting bodies.
elastic / elastically 弹性的 / 弹性地 PM10 碰撞模型 系统总动能守恒 / Total kinetic energy is conserved.
inelastic / inelastically 非弹性的 / 非弹性地 PM10 碰撞模型 系统总动能不守恒 / Total kinetic energy is not conserved.
stick together / move together 粘在一起 / 一起运动 PM10 碰撞模型 碰后共同速度：完全非弹性分支 / A shared final velocity identifies the sticking branch.
stationary / at rest 静止 / 静止状态 PM10 碰撞模型 相应物体碰前速度为零 / Set that body's initial velocity to zero.
explode / explosion 爆炸 / 爆炸过程 PM11 爆炸与反冲模型 储存能转为碎块动能 / Stored energy becomes kinetic energy.
recoil / fragments 反冲 / 碎块 PM11 爆炸与反冲模型 不同部分的动量须矢量相加 / Add the momenta of all parts.
initially at rest / highest point 初始静止 / 最高点 PM11 爆炸与反冲模型 检查爆炸前总动量是否为零 / Check the actual total initial momentum.
average force / contact time 平均力 / 接触时间 PM12 冲量停止与反弹模型 用动量变化除以作用时间 / Divide momentum change by interaction time.
rebound / bounce 反弹 / 弹跳 PM12 冲量停止与反弹模型 末速度方向改变，必须带符号 / Use opposite signs for reversed velocities.
stops / comes to rest 停下 / 停止运动 PM12 冲量停止与反弹模型 末速度为零 / Final velocity is zero.
force–time graph 力–时间图像 PM12 冲量停止与反弹模型 有符号面积给该力冲量 / Signed area gives impulse of that force.
crumple zone / packaging 溃缩区 / 缓冲包装 PM12 冲量停止与反弹模型 相同动量变化下，延长时间降低平均力 / Longer time lowers mean force for the same momentum change.
height / lifted / descends 高度 / 提升 / 下降 PM13 功与能量收支模型 检查重力势能变化 / Account for gravitational potential-energy change.
work done / distance 做功 / 距离 PM13 功与能量收支模型 使用力在位移方向的分量 / Use the force component along displacement.
friction / resistive force 摩擦 / 阻力 PM13 功与能量收支模型 机械能可转为内能 / Mechanical energy can be dissipated.
elastic rope / spring 弹性绳 / 弹簧 PM13 功与能量收支模型 伸长阶段加入弹性储能 / Include elastic energy when stretched.
maximum theoretical speed 最大理论速率 PM13 功与能量收支模型 明确忽略哪些能量耗散 / State the idealisations behind the limit.
power / per second 功率 / 每秒 PM14 功率效率与恒速行驶模型 能量转移率 / Rate of energy transfer.
input / useful output 输入 / 有用输出 PM14 功率效率与恒速行驶模型 区分供能与有效机械输出 / Distinguish supplied and useful power.
efficiency 效率 PM14 功率效率与恒速行驶模型 输出与输入的比值 / Useful output divided by input.
constant speed / lifting 恒速 / 提升 PM14 功率效率与恒速行驶模型 用力平衡求驱动或提升力 / Find the force from the motion conditions.
density / mass / volume 密度 / 质量 / 体积 PM15 密度质量与几何体积模型 以m=ρV连接材料与几何 / Connect material properties with geometry.
diameter / cylinder / disc 直径 / 圆柱 / 圆盘 PM15 密度质量与几何体积模型 先求截面积，再乘长度或厚度 / Compute cross-sectional area and volume.
no change in volume 总体积无变化 PM15 密度质量与几何体积模型 混合后的体积可按题设相加 / Add constituent volumes only when justified.
estimate 估算 PM15 密度质量与几何体积模型 先用合理数量级，再做单位核对 / Use a plausible scale and check units.
spring constant / stiffness 弹簧常量 / 劲度 PM16 弹簧形变与弹性储能模型 比例范围内F–伸长图的斜率 / Force–extension gradient in the proportional range.
extension / unstretched length 伸长量 / 未伸长原长 PM16 弹簧形变与弹性储能模型 伸长量等于末长度减原长 / Extension is final length minus natural length.
Hooke's law 胡克定律 PM16 弹簧形变与弹性储能模型 F与伸长量成正比 / Force is proportional to extension.
area / elastic energy 面积 / 弹性储能 PM16 弹簧形变与弹性储能模型 检查是否为F–伸长坐标 / Check the actual graph axes.
elastic limit 弹性极限 PM16 弹簧形变与弹性储能模型 检查卸载是否能完全恢复 / Check reversibility on unloading.
elastic / returns to 弹性 / 回到原状态 PM17 材料弹性塑性与曲线模型 卸载后恢复原形或原长 / Recovery after unloading.
plastic / permanent 塑性 / 永久的 PM17 材料弹性塑性与曲线模型 卸载后有永久形变 / Permanent deformation remains.
brittle / ductile 脆性 / 延展性 PM17 材料弹性塑性与曲线模型 比较断裂前的塑性形变 / Compare plastic deformation before fracture.
loading / unloading 加载 / 卸载 PM17 材料弹性塑性与曲线模型 两条路径可能不同 / Follow the specified loading and unloading paths.
stress–strain 应力–应变 PM17 材料弹性塑性与曲线模型 先区分材料性质与试样几何 / Separate material properties from sample geometry.
wire / cable 细线 / 缆绳 PM18 线材拉伸与杨氏模量模型 受拉的试样 / A sample under tension.
Young modulus / same material 杨氏模量 / 相同材料 PM18 线材拉伸与杨氏模量模型 相同线性材料的E不随试样尺寸改变 / E is a material property in the linear range.
diameter / original length 直径 / 原长 PM18 线材拉伸与杨氏模量模型 面积含直径平方，应变用原长 / Area uses diameter squared; strain uses original length.
tensile stress / strain 拉应力 / 拉应变 PM18 线材拉伸与杨氏模量模型 区分F/A与伸长/原长 / Distinguish force per area from fractional extension.
joined / in series 连接 / 串接 PM18 线材拉伸与杨氏模量模型 按连接点受力判断各段拉力 / Check forces at the join.
Rutherford / scattering 卢瑟福 / 散射 PM19 Rutherford散射与核式结构模型 用实验现象推断原子结构 / Infer structure from observations.
most pass through 多数穿过 PM19 Rutherford散射与核式结构模型 原子大部分空间为空 / Most of the atom is empty space.
large angle / backwards 大角度 / 向后 PM19 Rutherford散射与核式结构模型 少数粒子接近小而密集的原子核 / A small fraction approaches the compact nucleus.
alpha particles / thin foil α粒子 / 薄金属箔 PM19 Rutherford散射与核式结构模型 识别入射粒子、靶和探测装置 / Identify beam, target and detector.
nucleon number / proton number 核子数 / 质子数 PM20 核素离子与比荷模型 读A与Z，求中子数A−Z / Read A and Z.
isotopes 同位素 PM20 核素离子与比荷模型 质子数相同、中子数不同 / Same proton number, different neutron numbers.
ion / nucleus 离子 / 原子核 PM20 核素离子与比荷模型 离子用净电荷，核用Ze / Use the charge of the actual object.
specific charge 比荷 PM20 核素离子与比荷模型 电荷除以质量 / Charge divided by mass.
annihilation / particle and antiparticle 湮灭 / 粒子与反粒子 PM21 湮灭与成对产生模型 粒子与对应反粒子转为光子 / A particle and its antiparticle produce photons.
pair production / photon 成对产生 / 光子 PM21 湮灭与成对产生模型 光子产生粒子与反粒子 / A photon produces a particle–antiparticle pair.
rest energy / minimum energy 静止能量 / 最低能量 PM21 湮灭与成对产生模型 先支付两粒子的静止能量 / Account for both rest energies.
MeV / J 兆电子伏特 / 焦耳 PM21 湮灭与成对产生模型 使用已知静止能量及能量单位换算 / Use given rest energies and convert units.
alpha decay α衰变 PM22 核衰变方程与守恒模型 母核A减4、Z减2 / The parent loses two protons and two neutrons.
beta-minus / beta-plus β⁻ / β⁺衰变 PM22 核衰变方程与守恒模型 A不变，Z分别加1或减1 / A is unchanged; Z changes by +1 or −1.
neutrino / antineutrino 中微子 / 反中微子 PM22 核衰变方程与守恒模型 补全β衰变的能量与动量收支 / Complete energy and momentum accounting.
excited / metastable / gamma 激发态 / 亚稳态 / γ PM22 核衰变方程与守恒模型 核降能级，A和Z不变 / A nuclear energy transition leaves A and Z unchanged.
half-life 半衰期 PM23 半衰期与背景扣除模型 大量未衰变核数量在统计意义上减半 / Statistical halving of a large population.
activity / count rate 活度 / 计数率 PM23 半衰期与背景扣除模型 区别源的衰变率与探测计数率 / Distinguish activity from detected count rate.
background / corrected 本底 / 修正后的 PM23 半衰期与背景扣除模型 先扣本底再分析源的衰变 / Subtract background before analysing decay.
remaining / decayed 剩余 / 已衰变 PM23 半衰期与背景扣除模型 先求未衰变数量，再相减 / Find the remaining amount before the decayed amount.
absorber / penetrating 吸收物 / 有穿透力的 PM24 辐射吸收与厚度检测模型 通过纸、铝、铅等实验比较辐射 / Compare transmission through specified absorbers.
thickness / gauge 厚度 / 测厚装置 PM24 辐射吸收与厚度检测模型 透射计数随材料厚度改变 / Transmitted count rate responds to thickness.
tracer / diagnosis 示踪剂 / 诊断 PM24 辐射吸收与厚度检测模型 联系探测穿透与半衰期选择 / Relate detectability to penetration and half-life.
ionising / hazard 电离的 / 危害 PM24 辐射吸收与厚度检测模型 同时考虑电离能力与暴露位置 / Consider ionisation and the exposure route.
inverse-square 反平方 PM25 点源扩散与反平方模型 强度与距离平方成反比 / Intensity varies inversely with distance squared.
distance / gamma source 距离 / γ源 PM25 点源扩散与反平方模型 检查点源近似与吸收条件 / Check point-source and attenuation assumptions.
background count rate 本底计数率 PM25 点源扩散与反平方模型 先扣本底再比较距离效应 / Subtract background before comparing distances.
straight-line graph 直线图像 PM25 点源扩散与反平方模型 用1/r²作为自变量 / Plot against reciprocal distance squared.

多义词辨析 / Context-sensitive cues

词语 / Cue 情境 / Context 关键区别 / Distinction
elastic 碰撞 / collision 比较碰撞系统总动能 / Compare total kinetic energy.
elastic 材料形变 / deformation 卸载后恢复原状态 / Check recovery on unloading.
constant speed 已知直线或方向不变 / fixed direction 此时可判a=0；只有速率不变还须检查方向 / Check direction before inferring zero acceleration.
highest point 竖直抛体 / vertical throw 瞬时速度为零，重力加速度不为零 / Zero velocity does not imply zero acceleration.

smooth 接触面 / contact surface 排除指定面的摩擦，不自动排除其他阻力 / Apply the condition to the stated contact.
same material 不同尺寸线材 / different wire geometry 线性范围E相同，k和伸长未必相同 / Same E need not mean same stiffness or extension.
