知识逐项讲解 / Concept-by-concept guide

SI base unit / SI基本单位

Definition / 定义

EN: An SI base unit is the unit assigned to one of the SI base quantities.

中: SI基本单位是为一个SI基本物理量规定的单位。

SI derived unit / SI导出单位

Definition / 定义

EN: An SI derived unit is formed by combining SI base units according to the relation defining a derived quantity.

中: SI导出单位按导出量的关系式，由SI基本单位组合得到。

依据 / Evidence: PH01 202306 Q01 · MS p4（相关计算或应用）；PH01 202401 Q01 · MS p4（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \mathrm N=\mathrm{kg\,m\,s^{-2}}\]
\[\Large\displaystyle \mathrm J=\mathrm{kg\,m^2\,s^{-2}}\]
\[\Large\displaystyle \mathrm W=\mathrm{kg\,m^2\,s^{-3}}\]
\[\Large\displaystyle \mathrm{Pa}=\mathrm{kg\,m^{-1}\,s^{-2}}\]

考纲边界 / Scope

六类基本量及单位需要会用。坎德拉 cd、基本量的正式定义和量纲分析不作为本节要求。The candela, formal definitions of base quantities and dimensional analysis are excluded by this specification.

Application / 应用

使用与辨析 / Use and distinctions

物理量符号与单位符号不同，例如力 \(F\) 的单位是 N，质量 \(m\) 的单位是 kg。单位写法区分大小写。Quantity symbols and unit symbols are different, and case matters.

由 \(F=ma\) 可得 N = kg m s⁻²，再由 \(W=Fs\) 得 J = N m。这是导出单位运用。Formal dimensional analysis is not a required U1 technique.

M01 方法 1 · 基本单位与同量纲辨别 / Base units and dimensions

  1. 先写定义或物理公式，再替换为kg、m、s、A等基本单位：\(F=ma\) 得N为 \(\mathrm{kg\,m\,s^{-2}}\)；功为 \(\mathrm{kg\,m^2\,s^{-2}}\)；功率为 \(\mathrm{kg\,m^2\,s^{-3}}\)。 / Derive base units from a physical equation.
  2. 应力 \(F/A\) 为 \(\mathrm{kg\,m^{-1}\,s^{-2}}\)，弹簧劲度 \(F/x\) 为 \(\mathrm{kg\,s^{-2}}\)，冲量为 \(\mathrm{kg\,m\,s^{-1}}\)。 / Keep stress, stiffness and impulse distinct.
  3. 相同量纲不等于同一概念：力矩和功均可写N m，但力矩须说明转动作用；单位符号区分大小写。 / Equal dimensions do not establish identical physical meaning.
