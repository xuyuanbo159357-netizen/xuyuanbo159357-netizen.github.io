Concept / 概念

Plastic deformation / 塑性形变；Brittle behaviour / 脆性行为；Fracture / 断裂；Breaking stress / 断裂应力；Ultimate tensile stress / 极限拉应力

Definition / 定义

Plastic deformation / 塑性形变

EN: Plastic deformation is permanent deformation that remains after the deforming force is removed.

中: 塑性形变是在使物体形变的力移除后仍保留的永久形变。

表达要点 / Wording: permanent; force removed

依据 / Evidence: PH01 202506 Q01.1 · MS p4（定义/陈述评分点）；PH01 201801 Q08.4 · MS p11（定义/陈述评分点）

Brittle behaviour / 脆性行为

EN: A brittle material undergoes little or no plastic deformation before it fractures.

中: 脆性材料在断裂前发生很少或不发生塑性形变。

表达要点 / Wording: little or no plastic deformation; before failure

依据 / Evidence: PH01 202506 Q01.2 · MS p4（定义/陈述评分点）

Fracture / 断裂

EN: Fracture is the breaking of a material into separate parts.

中: 断裂是材料破裂成分离部分的过程。

Breaking stress / 断裂应力

EN: Breaking stress is the tensile force per unit cross-sectional area when the specimen breaks.

中: 断裂应力是试样断裂时拉力与截面积之比。

表达要点 / Wording: force per unit area; when it breaks

依据 / Evidence: PH01 201801 Q08.4 · MS p11（定义/陈述评分点）

Ultimate tensile stress / 极限拉应力

EN: Ultimate tensile stress is the maximum engineering tensile stress reached before fracture.

中: 极限拉应力是断裂前达到的最大工程拉应力。

依据 / Evidence: PH01 201706 Q19 · MS p12（相关计算或应用）

Formula / 公式

\[\begin{gathered} \sigma_{\rm breaking}=\frac{F_{\rm breaking}}{A_0} \\ \sigma_{\rm UTS}=\frac{F_{\max}}{A_0} \end{gathered}\]

Explanation / 讲解

材料性质对照 / Material properties

中文 English 判断依据 / Meaning
弹性 elastic 卸载可恢复 / returns to the original shape
塑性 plastic 卸载后有永久形变 / The material is permanently deformed / does not return to its original length
脆性 brittle 破裂前塑性形变很小 / material undergoes little or no plastic deformation before failure
刚度 stiffness 物体用k（N m⁻¹）比较，材料用E（Pa）比较 / object stiffness k and material modulus E have different units
抗拉强度 tensile strength 能承受的最大拉应力 / maximum tensile stress

曲线关键位置 / Curve features

比例极限：直线段终止。弹性极限：永久形变开始。屈服：应变显著增加而应力变化较小的区域（形状取决于材料）。极限拉应力UTS：工程应力达到最大。断裂：试样最终断开。 Identify proportionality, elasticity, yielding, maximum stress and fracture on the given graph rather than assuming every material has identical points.

延性金属可出现较大塑性形变后断裂；脆性材料可能在仍较小应变时突然断裂。强度高不保证不脆。A strong material may still be brittle.

断裂应力是断裂时的应力；对发生颈缩的延性材料，最大应力与断裂时工程应力可不同。Do not automatically identify UTS with the final fracture stress.

加载与卸载 / Loading and unloading

在弹性范围内可恢复原长；超出弹性极限后卸载留下永久伸长。加载和卸载曲线之间面积可表示未恢复的能量转移。Read the residual extension and energy difference from the graph.

图示：材料曲线比较 / Comparing materials

读图 / Reading： 初始斜率比较刚度，最大应力比较强度，断裂前应变反映延展性；三种判断不是同一件事。

Initial gradient compares stiffness, peak stress compares strength, and strain before fracture indicates ductility.

D26 方法 1 · 弹性、塑性、脆性与曲线证据 / Material behaviour and evidence

  1. 弹性指卸载后恢复，塑性指存在不可恢复形变；脆性指破坏前几乎无塑性形变，不是几乎无弹性形变，也不保证刚度高或强度低。 / Separate elasticity, brittleness and strength.
  2. 单独加载曲线不能证明能否恢复，需卸载证据；非直线也可为弹性，不能把“非胡克”自动判成塑性。 / Linearity is not the definition of elastic behaviour.
  3. 比较图分别看线性区应力/应变比（Young modulus）、最大应力（strength）、塑性范围（ductility/brittleness）、面积（work per volume）。坐标互换时斜率判断反转。 / State which feature supports each property.
  4. 选材料写“曲线显示的性质 → 该用途为何需要它”，例如较小工作伸长、较高允许应力或避免永久形变。 / Make a purpose-specific argument.
