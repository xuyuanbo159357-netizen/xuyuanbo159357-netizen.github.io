U3PM14 圆锥摆与水平分量 / Conical pendulum

所属知识 / Knowledge： 3.6.1 Circular motion / 圆周运动 · 模型目录 / Model index

关键词 → 模型 / Keywords → model

conical pendulum / angle to the vertical / horizontal circle → 圆锥摆与水平分量 / Conical pendulum

关键词只是识别线索；必须同时核对受力方向、几何和约束。 Keywords are cues, not sufficient conditions; check the actual forces and constraints.

建模、方程与适用条件 / Model, equations and conditions

受力与几何 / Forces and geometry

绳长 \(l\)，与竖直方向夹角 \(\theta\)，轨道半径 \(r=l\sin\theta\)。竖直平衡 \(T_s\cos\theta=mg\)；水平径向 \(T_s\sin\theta=mv^2/r\)。张力大小不等于向心力大小。

For a string at angle \(\theta\) to the vertical, radius is \(l\sin\theta\). The vertical tension component balances weight and its horizontal component supplies the radial resultant.

相除得 \(\tan\theta=v^2/(rg)\)；再可得 \(\omega^2=g/(l\cos\theta)\)、周期 \(P=2\pi\sqrt{l\cos\theta/g}\)。此处用 \(P\) 表示周期，避免与绳张力混淆。

Dividing components eliminates tension. Substitute the actual circle radius to obtain angular speed and period.

易错点 / Common errors

若题给角度是绳与水平面的角度，正弦余弦需互换。\(l\) 不是圆周半径；质量约掉不表示重力或张力不存在。

Swap trigonometric components if the stated angle is to the horizontal. String length is not orbit radius, and cancellation of mass does not remove the forces.
