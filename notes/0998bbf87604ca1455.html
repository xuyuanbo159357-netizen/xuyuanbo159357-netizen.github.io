半衰期与背景扣除模型 / Half-life

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
half-life 半衰期 大量未衰变核数量在统计意义上减半 / Statistical halving of a large population.
activity / count rate 活度 / 计数率 区别源的衰变率与探测计数率 / Distinguish activity from detected count rate.
background / corrected 本底 / 修正后的 先扣本底再分析源的衰变 / Subtract background before analysing decay.
remaining / decayed 剩余 / 已衰变 先求未衰变数量，再相减 / Find the remaining amount before the decayed amount.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

每经过一个半衰期，未衰变核数在统计意义上减半。U1的简单数量计算采用整数个半衰期；从图像可比较多个减半时间。 / Use repeated halving for the U1 whole-number-half-life calculations.

读图 / Reading: 原核素剩余量连续减半，相邻减半位置的时间间隔相同；衰变产物的质量并未消失。 / Equal halving intervals characterize decay; daughter material has not disappeared.

Formula / 公式

\[N=\frac{N_0}{2^n},\qquad n=\frac{t}{T_{1/2}}\quad(n\text{ is a whole number}),\qquad N_{\rm decayed}=N_0-N,\]
\[R_s=R_{\rm measured}-R_{\rm background}.\]

保持探测几何和效率一致时，修正后的源计数率 \(R_s\) 与活度成正比，整数半衰期计算可同样逐次减半。 / Corrected count rate follows source activity only under comparable detection conditions.

解题流程 / Method

  1. 总计数若在不同时间间隔测得，先分别换成相同单位的计数率。 / Convert counts over different intervals to comparable rates.
  2. 扣除背景；再找 \(R_s\) 减为一半所需时间。 / Halve the corrected source contribution, not the raw measured rate.
  3. 多次求减半时间可减小读图偶然误差；核对时间单位。 / Compare several halving intervals and check units.
  4. 求已衰变数用初始减剩余，不能把剩余质量自动当成整个样品总质量。 / Decay does not generally remove all daughter material from the sample.

易错判断 / Checks

背景不随该源的半衰期一起减半。 单个核何时衰变不能从半衰期预测。 / A fixed background stays fixed, and individual decay times are unpredictable.
