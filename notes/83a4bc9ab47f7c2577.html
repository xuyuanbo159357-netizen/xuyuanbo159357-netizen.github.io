Concept / 概念

Measurement uncertainty / 测量不确定度；Absolute uncertainty / 绝对不确定度；Fractional uncertainty / 相对不确定度；Percentage uncertainty / 百分比不确定度

Definition / 定义

Measurement uncertainty / 测量不确定度

EN: Measurement uncertainty is an estimate of the range within which the true value of a measured quantity is expected to lie.

中: 测量不确定度估计被测量真值预期所在的数值范围。

Absolute uncertainty / 绝对不确定度

EN: Absolute uncertainty is the estimated uncertainty expressed in the same units as the measured quantity.

中: 绝对不确定度用与被测量相同的单位表示。

依据 / Evidence: PH01 202001 Q08.1 · MS p10（相关计算或应用）

Fractional uncertainty / 相对不确定度

EN: Fractional uncertainty is the absolute uncertainty divided by the magnitude of the measured value.

中: 相对不确定度为绝对不确定度除以测量值的绝对值。

Percentage uncertainty / 百分比不确定度

EN: Percentage uncertainty is fractional uncertainty expressed as a percentage.

中: 百分比不确定度是以百分数表示的相对不确定度。

依据 / Evidence: PH01 202601 Q10.1 · MS p19（相关计算或应用）

Formula / 公式

\[\begin{gathered} x\pm\Delta x \\ u_{\rm frac}=\frac{\Delta x}{|x|} \\ u_{\%}=\frac{\Delta x}{|x|}\times100\% \end{gathered}\]

Explanation / 讲解

物理量辨析 / Quantity distinctions

测量结果写成 \(x\pm\Delta x\)，\(\Delta x\) 是绝对不确定度，单位与 \(x\) 相同。Absolute uncertainty has the same unit as the value.

\[\text{fractional uncertainty}=\frac{\Delta x}{|x|},\qquad \text{percentage uncertainty}=\frac{\Delta x}{|x|}\times100\%.\]

这些数描述合理的数值范围，不等同于“已经知道的真实误差”。Uncertainty estimates a plausible range rather than an exactly known error.

考纲中的合成规则 / Required propagation rules

运算 / Operation 规则 / Rule
\(z=x+y\) 或 \(x-y\) \(\Delta z=\Delta x+\Delta y\)
\(z=xy\) 或 \(x/y\) \(\Delta z/\lvert z\rvert=\Delta x/\lvert x\rvert+\Delta y/\lvert y\rvert\)
\(z=x^n\) \(\Delta z/\lvert z\rvert=\lvert n\rvert\Delta x/\lvert x\rvert\)
乘以精确常数 / exact constant 百分比不确定度不变 / percentage uncertainty unchanged

以上采用本课程的最大估计规则。These are the course’s maximum uncertainty estimates. 如 \(E=FL/(A\Delta L)\)，分别相加各因素的百分比不确定度；若 \(A\propto d^2\)，直径的不确定度贡献乘2。The diameter contribution doubles because area depends on \(d^2\).

Application / 应用

数据与仪器 / Data and instruments

重复读数可用半极差估计不确定度，并说明采用的约定。单次读数的不确定度取决于仪器刻度、读法和题目给定信息；不把“数字仪器”或“模拟仪器”统一套成固定规则。State the convention used; use instrument information given in the question.

例：\(L_2=12.0\pm0.1\) cm，\(L_1=10.0\pm0.1\) cm，则伸长 \(2.0\pm0.2\) cm，相对不确定度10%。Subtraction can make the relative uncertainty large.

三角函数或对数函数的不确定度合成不属于本节要求。Trigonometric and logarithmic uncertainty combinations are excluded.

M05 方法 1 · 读数、差值与不确定度传播 / Readings, differences and propagation

  1. 重复值先识别有依据的异常值，用平均和半范围估不确定度；不能为使结果好看随意删点。 / Justify any excluded anomaly.
  2. 加减量用绝对不确定度相加；乘除用百分或分数不确定度相加，幂次贡献乘幂的绝对值。例如 \(a=2s/t^2\)：\(\%\delta a=\%\delta s+2\%\delta t\)。 / Match the rule to the operation.
  3. 球密度 \(\rho\propto m/d^3\)，直径贡献乘三；压强 \(p=F/l^2\)，长度贡献乘二。 / Identify powers before calculating.
  4. 伸长 \(\Delta L=L-L_0\) 可能含四次端点读数；按仪器分辨率逐项计绝对误差，不能只给一次最小刻度。 / Count how many actual readings form the difference.
  5. 最后由百分不确定度乘报告值求绝对不确定度，单位与原量一致。 / Convert the uncertainty back to the required form.
