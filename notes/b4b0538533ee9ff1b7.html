物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes

Concept / 概念

Resultant force / 合力；Vector component / 矢量分量

Definition / 定义

Resultant force / 合力

EN: The resultant force is the vector sum of all the forces acting on a body.

中: 合力是作用在同一物体上所有力的矢量和。

依据 / Evidence: PH01 202101 Q12 · MS p20（相关计算或应用）

Vector component / 矢量分量

EN: A vector component is the part of a vector resolved along a chosen direction.

中: 矢量分量是矢量沿指定方向分解得到的部分。

依据 / Evidence: PH01 201706 Q03 · MS p4（相关计算或应用）

Formula / 公式

\[\begin{gathered} F_x=F\cos\theta \\ F_y=F\sin\theta \\ R_x=\sum F_x \\ R_y=\sum F_y \\ R=\sqrt{R_x^2+R_y^2} \end{gathered}\]

Explanation / 讲解

图解与计算 / Diagram and calculation

首尾相接法将第二个矢量的起点平移到第一个终点，合矢量从最初起点指向最终终点。平行四边形法适用于共同起点的两个矢量。Translation does not change a vector.

比例图应注明比例、方向、单位，再量出合矢量长度和方向。State the scale and measure both magnitude and direction.

若夹角 \(\theta\) 相对于水平轴，\(F_x=F\cos\theta\)，\(F_y=F\sin\theta\)，分量带正负号。对于别的参考轴，先看角的位置。Components depend on the axis from which the angle is measured.

\[R_x=\sum F_x,\quad R_y=\sum F_y,\quad R=\sqrt{R_x^2+R_y^2}.\]

用分量符号确定方向象限，再求夹角。A calculator’s arctangent alone does not determine the quadrant.

对于互相垂直的3 N和4 N，合力大小5 N；对于同向矢量相加、反向矢量相减。Vector addition is not simply adding magnitudes.

图示：首尾相接法 / Head-to-tail addition

读图 / Reading： 先画 OA，再从 A 画 AB；合矢量从起点 O 指向终点 B。三角形第三边的方向不能随意反转。

Draw OA then AB from its tip; the resultant is OB from the initial to final point.

图示：正交分量 / Perpendicular components

读图 / Reading： 当 θ 从水平轴量起，水平分量为 OP cosθ，竖直分量为 OP sinθ；改变角度基准时正弦、余弦也要相应改变。

With θ measured from horizontal, the horizontal component is OP cosθ and the vertical component OP sinθ; change the reference axis consistently.

D02 方法 1 · 分量、作图与相对速度 / Resolution, vector diagrams and relative velocity

  1. 先画所用角，沿相邻轴分量为 \(F\cos\theta\)、垂直轴为 \(F\sin\theta\)；两绳夹角需先各取半角。分别求有符号分量，再求合量及明确参考轴的方向。 / Define the angle and the axes before resolving.
  2. 三力平衡可画首尾相接闭合三角形；若最大力大于另外两力之和，不可能平衡。求三力合量范围可先合成已知垂直力，再用三角不等式。 / Use vector geometry rather than adding magnitudes.
  3. 比例图题须有比例、足够尺寸、准确箭头和角度；计算仅可核查，不能代替题目要求的作图。 / Follow the required method.
  4. 河流或风中 \(\mathbf v_{ground}=\mathbf v_{relative}+\mathbf v_{medium}\)；垂直过河需用上游分量抵消水流，最小合速需相反方向并选题给最大可用流速。 / Keep the reference frame explicit.
