1. 矢量相加与合力 / Vector addition and resultant force

1.1 关键概念与定义 / Key concepts and definitions

Resultant force / 合力

Definition / 定义

EN: The resultant force is the vector sum of all the forces acting on a body.

中: 合力是作用在同一物体上所有力的矢量和。

依据 / Evidence: PH01 202101 Q12 · MS p20（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \mathbf F_{\mathrm{resultant}}=\sum\mathbf F\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(F_{\mathrm{resultant}}\) 合力 / resultant force \(\mathrm{N}\)
\(F\) 力 / force \(\mathrm{N}\)

物理规律与含义 / Law and meaning

合力是所有真实外力的矢量和，必须同时考虑大小和方向。

The resultant force is the vector sum of the real external forces, including their directions.

1.2 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle R_x=\sum F_x\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R_{x}\) 水平合力分量 / horizontal resultant-force component \(\mathrm{N}\)
\(F_{x}\) 力的分量 / force components \(\mathrm{N}\)

物理规律与含义 / Law and meaning

各力的水平分量按正负号相加，得到合力的水平分量。

Add the signed horizontal force components to obtain the horizontal resultant.

\[\Large\displaystyle R_y=\sum F_y\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R_{y}\) 竖直合力分量 / vertical resultant-force component \(\mathrm{N}\)
\(F_{y}\) 力的分量 / force components \(\mathrm{N}\)

物理规律与含义 / Law and meaning

各力的竖直分量按正负号相加，得到合力的竖直分量。

Add the signed vertical force components to obtain the vertical resultant.

\[\Large\displaystyle R=\sqrt{R_x^2+R_y^2}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(R\) 合力大小 / resultant force magnitude \(\mathrm{N}\)
\(R_{x}\) 水平合力分量 / horizontal resultant-force component \(\mathrm{N}\)
\(R_{y}\) 竖直合力分量 / vertical resultant-force component \(\mathrm{N}\)

物理规律与含义 / Law and meaning

互相垂直的合力分量通过勾股定理给出合力大小。

Perpendicular resultant components give the resultant magnitude through Pythagoras’ theorem.

1.3 内容解析与细节 / Explanation and details

图解与计算 / Diagram and calculation

首尾相接法将第二个矢量的起点平移到第一个终点，合矢量从最初起点指向最终终点。平行四边形法适用于共同起点的两个矢量。Translation does not change a vector.

比例图应注明比例、方向、单位，再量出合矢量长度和方向。State the scale and measure both magnitude and direction.

若夹角 \(\theta\) 相对于水平轴，\(F_x=F\cos\theta\)，\(F_y=F\sin\theta\)，分量带正负号。对于别的参考轴，先看角的位置。Components depend on the axis from which the angle is measured.

用分量符号确定方向象限，再求夹角。A calculator’s arctangent alone does not determine the quadrant.

对于互相垂直的3 N和4 N，合力大小5 N；对于同向矢量相加、反向矢量相减。Vector addition is not simply adding magnitudes.

首尾相接法 / Head-to-tail addition

读图 / Reading： 先画 OA，再从 A 画 AB；合矢量从起点 O 指向终点 B。三角形第三边的方向不能随意反转。

Draw OA then AB from its tip; the resultant is OB from the initial to final point.

2. 正交分量与分解 / Perpendicular components and resolution

2.1 关键概念与定义 / Key concepts and definitions

Vector component / 矢量分量

Definition / 定义

EN: A vector component is the part of a vector resolved along a chosen direction.

中: 矢量分量是矢量沿指定方向分解得到的部分。

依据 / Evidence: PH01 201706 Q03 · MS p4（相关计算或应用）

正交分量 / Perpendicular components

读图 / Reading： 当 θ 从水平轴量起，水平分量为 OP cosθ，竖直分量为 OP sinθ；改变角度基准时正弦、余弦也要相应改变。

With θ measured from horizontal, the horizontal component is OP cosθ and the vertical component OP sinθ; change the reference axis consistently.

2.2 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle F_x=F\cos\theta\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(F_{x}\) 力的分量 / force components \(\mathrm{N}\)
\(F\) 力 / force \(\mathrm{N}\)
\(\theta\) 角、转角 / angle \(\mathrm{rad}\)

物理规律与含义 / Law and meaning

把力投影到水平轴，水平分量等于力的大小乘夹角的余弦。

The horizontal component is the force magnitude multiplied by the cosine of the angle to the horizontal.

适用条件 / Conditions

角度从水平轴量起。

Measure the angle from the horizontal axis.

\[\Large\displaystyle F_y=F\sin\theta\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(F_{y}\) 力的分量 / force components \(\mathrm{N}\)
\(F\) 力 / force \(\mathrm{N}\)
\(\theta\) 角、转角 / angle \(\mathrm{rad}\)

物理规律与含义 / Law and meaning

当夹角从水平轴量起时，竖直分量由正弦投影得到。

With the angle measured from the horizontal axis, the vertical component follows from the sine projection.

3. 相对速度与参考系 / Relative velocity and reference frames

3.1 公式与物理规律 / Formulae and physical laws

\[\Large\displaystyle \mathbf v_{\mathrm{ground}}=\mathbf v_{\mathrm{relative}}+\mathbf v_{\mathrm{medium}}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量或记号 / Quantity or notation SI 单位 / SI unit
\(v_{\mathrm{ground}}\) 物体相对地面的速度 / object velocity relative to the ground \(\mathrm{m\,s^{-1}}\)
\(v_{\mathrm{relative}}\) 物体相对介质的速度 / object velocity relative to the medium \(\mathrm{m\,s^{-1}}\)
\(v_{\mathrm{medium}}\) 介质相对地面的速度 / medium velocity relative to the ground \(\mathrm{m\,s^{-1}}\)

物理规律与含义 / Law and meaning

地面参考系中的速度是物体相对介质的速度与介质相对地面速度的矢量和。

Ground velocity is the vector sum of velocity relative to the medium and the medium’s ground velocity.

D02 方法 1 · 分量、作图与相对速度 / Resolution, vector diagrams and relative velocity

  1. 先画所用角，沿相邻轴分量为 \(F\cos\theta\)、垂直轴为 \(F\sin\theta\)；两绳夹角需先各取半角。分别求有符号分量，再求合量及明确参考轴的方向。 / Define the angle and the axes before resolving.
  2. 三力平衡可画首尾相接闭合三角形；若最大力大于另外两力之和，不可能平衡。求三力合量范围可先合成已知垂直力，再用三角不等式。 / Use vector geometry rather than adding magnitudes.
  3. 比例图题须有比例、足够尺寸、准确箭头和角度；计算仅可核查，不能代替题目要求的作图。 / Follow the required method.
