简明英文样例答案 / Simple English model answer

Use a ruler to measure the distance from the source to the detector. Measure the background count rate with the source removed. Measure the count rate at several distances and subtract the background. Count for a long time at each distance and repeat the readings. Plot corrected count rate C against 1/r². A straight line through the origin supports the inverse-square law.
