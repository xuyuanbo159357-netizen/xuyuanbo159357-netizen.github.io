U4 答题规范 / Exam answering conventions · 返回真题练习 / Past-paper practice

阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 电加热比热容实验 / Electrical measurement of specific heat capacity

说明质量测量、温度初末值或温度–时间图、电压电流及通电时长；电功输入可由 \(VIt\) 或适用的功率计数据求得。 / Identify the mass, temperature change, electrical input and time.

评价散热和容器吸热对结果的影响，提出保温、合适温度范围或热容量修正等对应措施，解释为什么有效；不要只说“avoid human error”。 / Link each limitation to the measured energy balance and a specific remedy.

该段为实验方法书写框架，具体校正关系按题目所给装置与数据使用。 / This is a method-writing framework; use the actual apparatus and data for corrections.

2. 气体定律实验 / Gas-law experiments

写明控制的量、密闭气体状态、压强或体积的实际读数、温度平衡及取点方法。波义耳定律需保持温度和气体量不变；查理定律需保持压强和气体量不变。 / Identify the controlled variables, gas amount, readings and thermal equilibrium.

温度使用 K；评价时可说明未达热平衡、漏气或死体积怎样影响关系。不要只写“temperature constant”而不说明如何实现或检查。 / Explain how conditions are maintained or checked.

3. 反平方实验 / An inverse-square experiment

距离从光源的合适位置量，避免把距外壳的距离当作距发光中心；控制环境光，考虑背景和传感器实际响应。 / Define the source-to-detector distance and account for ambient light and detector response.

按题目建立传感器读数与光强的关系；不能未经说明就把 LDR 电阻 \(R\) 直接当作光强 \(I\)。 / Do not identify LDR resistance with intensity without the appropriate relationship.

4. 滚动计时实验的明确例证 / A rolling-motion timing example

2026 June Q05.2：沿斜面量 38.0 cm；从静止释放；记录通过上下标记或两光电门之间的时间。使用光电门时，本题的 \(t\) 是两位置间的运动时间，不是物体遮挡一个光电门的时间。视频法可用垂直于斜面的拍摄方向减少视差。 / Match the measured distance and timing interval; distinguish transit between gates from interruption of one gate. PH04 2026 June Q05.2 · MS PDF p14 · 原题与答案 / Question and answer

写“metre ruler and stopwatch”只是仪器部分，还必须说明如何释放、何时开始及停止计时。 / An equipment list does not describe the complete method.

5. 评价结果与物理模型 / Evaluate results against the model

  • 滚动题检查是否滑动、是否满足 \(v=\omega r\)，不能把无滑动约束无条件套在无摩擦情境。 / Check the rolling constraint rather than assuming it.
  • 传热题区分是否达到稳态，是否存在侧面散热；气体题辨认是否漏气或温度未平衡。 / Check the assumptions relevant to the apparatus.
  • 不确定度结合测量量和关系传播；极小温差要保留保护位，不能在算热流率前已过度舍入。 / Propagate uncertainty and protect small temperature differences. PH04 2026 June Q01.3 · MS PDF p5 · 原题与答案 / Question and answer；PH04 2026 June Q01.4 · MS PDF p6 · 原题与答案 / Question and answer
  • 对安全、效率或材料的判断，写明证据、限制和结论，不要求所有评价题都作相同结论。 / Support evaluations with evidence and state their limitations.
实验评价句式 / Evaluation frame

测什么 → 怎样测 → 固定什么 → 怎样处理数据 → 误差怎样影响结果 → 有针对性的改进。 / Quantity → measurement → control → processing → effect of error → targeted improvement.
