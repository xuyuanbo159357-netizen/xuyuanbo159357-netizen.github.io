按物理关系整理公式 / Formulae organised by relationship

关系 1 / Relation 1

\[\Large\displaystyle W=Fs\cos\theta\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(W\) 功 / work \(\mathrm{J}\)
\(F\) 力的大小 / force magnitude \(\mathrm{N}\)
\(s\) 带符号位移 / signed displacement \(\mathrm{m}\)
\(\theta\) 图示夹角 / labelled angle \(\mathrm{rad}\)

物理关系 / Physical relationship： 恒力做功取位移方向的力分量。 / Work by a constant force uses its component along displacement.

适用条件 / Conditions： mgh 只用于 g 可视为恒定的高度差；功取力与位移方向夹角 / use mgh only for nearly constant g; work uses the force–displacement angle

关系 2 / Relation 2

\[\Large\displaystyle K=\frac{1}{2}mv^2\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(K\) 动能 / kinetic energy \(\mathrm{J}\)
\(m\) 物体质量 / mass \(\mathrm{kg}\)
\(v\) 速度或速率，按题设 / velocity or speed as specified \(\mathrm{m\,s^{-1}}\)

物理关系 / Physical relationship： 动能随质量成正比、随速率平方变化。 / Kinetic energy is proportional to mass and speed squared.

适用条件 / Conditions： mgh 只用于 g 可视为恒定的高度差；功取力与位移方向夹角 / use mgh only for nearly constant g; work uses the force–displacement angle

关系 3 / Relation 3

\[\Large\displaystyle \Delta U=mg\Delta h\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\Delta U\) 引力势能变化 / change in gravitational potential energy \(\mathrm{J}\)
\(m\) 物体质量 / mass \(\mathrm{kg}\)
\(g\) 重力加速度或场强大小 / gravitational acceleration or field magnitude \(\mathrm{m\,s^{-2}}\)
\(\Delta h\) 高度变化 / change in height \(\mathrm{m}\)

物理关系 / Physical relationship： 近似匀强重力场中，高度增加使势能增加。 / Increasing height raises potential energy in an approximately uniform field.

适用条件 / Conditions： mgh 只用于 g 可视为恒定的高度差；功取力与位移方向夹角 / use mgh only for nearly constant g; work uses the force–displacement angle

\[\Large\displaystyle E_i+E_{\mathrm{in}}=E_f+E_{\mathrm{out}}\]

核心模型与条件 / Model and conditions

选系统并画能量收支：初始机械能、外界输入的功、末态机械能及转为其他形式的能量。 / Set the system and account for input work, final mechanical energy and energy transferred to other forms.

读图 / Reading: 无耗散的模型中重力势能与动能互相转化；使用竖直高度变化。 / Without dissipation, gravitational energy and kinetic energy interchange; use vertical height change.

解题流程 / Method

  1. 明确初末位置、速率与弹簧状态。 / Specify initial and final states.
  2. 近地面用竖直高度差求重力势能变化，不用斜面长度。 / Use vertical height, not path length, for gravitational potential energy.
  3. 恒定阻力耗散 \(Fs\)；变力做功用F–s图下面积。 / Use the actual resistive path length or graph area.
  4. 最低点可能 \(v=0\) 但 \(a\ne0\)；“瞬时停止”不等于平衡。 / A turning point need not be a force-balance point.

易错判断 / Checks

只有相关耗散和外界输入均处理清楚，才能用机械能守恒简式。制动力做功、驱动力做功及合力做功不应混淆；合力做功给动能变化。 / Distinguish work by an individual force from net work, which changes kinetic energy.
