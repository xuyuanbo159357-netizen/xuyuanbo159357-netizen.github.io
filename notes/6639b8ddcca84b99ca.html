功与能量收支模型 / Work and energy

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.7 功、能量与功率 - Work, energy and power · 3.2.8 能量守恒 - Conservation of energy

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
height / lifted / descends 高度 / 提升 / 下降 检查重力势能变化 / Account for gravitational potential-energy change.
work done / distance 做功 / 距离 使用力在位移方向的分量 / Use the force component along displacement.
friction / resistive force 摩擦 / 阻力 机械能可转为内能 / Mechanical energy can be dissipated.
elastic rope / spring 弹性绳 / 弹簧 伸长阶段加入弹性储能 / Include elastic energy when stretched.
maximum theoretical speed 最大理论速率 明确忽略哪些能量耗散 / State the idealisations behind the limit.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

选系统并画能量收支：初始机械能、外界输入的功、末态机械能及转为其他形式的能量。 / Set the system and account for input work, final mechanical energy and energy transferred to other forms.

读图 / Reading: 无耗散的模型中重力势能与动能互相转化；使用竖直高度变化。 / Without dissipation, gravitational energy and kinetic energy interchange; use vertical height change.

Formula / 公式

\[K=\frac12mv^2,\qquad \Delta U_g=mg\Delta h,\qquad W=Fs\cos\theta.\]
\[K_i+U_{g,i}+U_{el,i}+W_{\rm input}=K_f+U_{g,f}+U_{el,f}+E_{\rm dissipated}.\]

此收支中阻力做功的大小已归入 \(E_{\rm dissipated}\)，不得再在 \(W_{\rm input}\) 中重复扣除。 / Do not count the same resistive work twice.

解题流程 / Method

  1. 明确初末位置、速率与弹簧状态。 / Specify initial and final states.
  2. 近地面用竖直高度差求重力势能变化，不用斜面长度。 / Use vertical height, not path length, for gravitational potential energy.
  3. 恒定阻力耗散 \(Fs\)；变力做功用F–s图下面积。 / Use the actual resistive path length or graph area.
  4. 最低点可能 \(v=0\) 但 \(a\ne0\)；“瞬时停止”不等于平衡。 / A turning point need not be a force-balance point.

易错判断 / Checks

只有相关耗散和外界输入均处理清楚，才能用机械能守恒简式。制动力做功、驱动力做功及合力做功不应混淆；合力做功给动能变化。 / Distinguish work by an individual force from net work, which changes kinetic energy.
