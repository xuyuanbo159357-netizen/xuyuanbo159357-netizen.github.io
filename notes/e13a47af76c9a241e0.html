“from rest”（从静止开始） 匀加速度与分段运动模型 / Constant acceleration 08.1、08.2：先划分运动阶段；只有该阶段加速度恒定才用匀加速度方程，from rest 只确定初速度为零。 / Separate stages; SUVAT requires constant acceleration, while from rest only sets the initial velocity.
“horizontal”（水平的）；“projected”（抛射） 抛体独立分运动模型 / Projectile 08.1：先检查阻力和发射方向，再把水平与竖直运动分开；两个方向共享同一飞行时间。 / Check drag and launch direction, then use independent components with a common flight time.
“air resistance”（空气阻力） 阻力与终极速率模型 / Terminal speed 08.4、08.5：分阶段比较驱动力或重力与阻力；稳定终极速率时合力为零，不能对整个过程都取平衡。 / Compare forces by stage; only steady terminal motion has zero resultant.
