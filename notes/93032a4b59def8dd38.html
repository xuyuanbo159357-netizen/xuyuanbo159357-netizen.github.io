阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 坐标决定斜率意义 / The axes determine the gradient

  • \(V\) 对 \(I\) 的欧姆导体直线斜率是 \(R\)；\(I\) 对 \(V\) 的直线斜率是 \(1/R\)。非欧姆元件不能把任一点切线斜率直接当 \(V/I\)。 / For an ohmic straight line, the gradient depends on the axes; for a non-ohmic curve, distinguish tangent gradient from the ratio \(V/I\).
  • \(V\) 对 \(I\) 的电池图像有截距 \(\mathcal E\)、斜率 \(-r\)，报告斜率时不能漏负号。 / Retain the negative gradient in a terminal-voltage graph.
  • 实际例证：2017 June Q07.3 的热敏电阻图斜率为 \(-5\ \Omega\,\mathrm K^{-1}\)，第二分必须有负号。 / The thermistor gradient requires its sign. PH02 2017 June Q07.3 · MS PDF p6 · 原题与答案 / Question and answer

2. 灯泡 I–V 图的具体评分 / A filament-lamp graph example

2026 June Q05.2 要求曲线通过 \((2.0\ \mathrm V,1.0\ \mathrm A)\) 和 \((12\ \mathrm V,2.0\ \mathrm A)\)，平滑过原点；斜率起初近似不变，随后减小，不能出现零或负斜率。点和曲线各自有评分要求。 / Plot the stated coordinates and show the correct smooth shape; the decreasing gradient must remain positive. PH02 2026 June Q05.2 · MS PDF p9 · 原题与答案 / Question and answer

这些坐标及容许形状属于这道题；不要机械复制到其他灯泡数据题。 / These numerical coordinates are specific to the cited question.

3. 超导、波形与光纤图 / Superconductivity, waves and fibre pulses

  • 超导电阻率图：临界温度及以下为零，越过临界温度后出现突变；不能画成普通金属始终连续延伸到零温的直线。 / Represent the transition to zero resistivity correctly. PH02 2026 June Q03.2 · MS PDF p6 · 原题与答案 / Question and answer
  • 标清横轴是时间还是距离：时间轴读周期，位置轴读波长。振幅从平衡位置量，不是峰峰值。 / A time axis gives period; a distance axis gives wavelength. Distinguish amplitude from peak-to-peak value.
  • 驻波画波节位置固定，波腹位移随时间变；相邻波节间距为 \(\lambda/2\)。 / Keep nodes fixed and interpret their spacing correctly.
  • 光纤脉冲要分别考虑宽度、幅度和重复周期。2026 June Q09.5 要求相对原灰线更窄、但底宽不小于 \(1\ \mathrm{\mu s}\)，周期不变且幅度更小。 / Check pulse width, repetition period and amplitude separately. PH02 2026 June Q09.5 · MS PDF p18 · 原题与答案 / Question and answer

4. 电路图与光路图 / Circuit and ray diagrams

电流表串联、电压表并联；开关不同位置下都要检查实际闭合回路。光路画法线、箭头和所需角度；全反射发生在高折射率一侧。 / Use standard meter connections and check switch states; label the normal, ray directions and relevant angles.

测电动势的特定要求：高电阻电压表接在电池两端，并使电流为零或可忽略。 / For the cited emf measurement, use a high-resistance voltmeter with negligible current. PH02 2026 June Q08.2 · MS PDF p14 · 原题与答案 / Question and answer

图像自检 / Graph check

轴、单位、刻度 → 起点和关键点 → 斜率正负与变化 → 曲线或直线 → 图示的物理对象。 / Axes, units and scales → intercepts and key points → gradient sign and trend → line shape → physical meaning.
