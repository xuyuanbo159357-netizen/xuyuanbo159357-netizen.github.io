知识逐项讲解 / Concept-by-concept guide

Radioactive decay / 放射性衰变

Definition / 定义

EN: Radioactive decay is the spontaneous transformation of an unstable nucleus to a more stable state, with the emission of particles or radiation.

中: 放射性衰变是不稳定原子核自发转变到较稳定状态并发射粒子或辐射的过程。

Random radioactive decay / 衰变的随机性

Definition / 定义

EN: Radioactive decay is random because it is impossible to predict which individual nucleus will decay or when it will decay.

中: 衰变具有随机性，因为不能预测哪个特定原子核会衰变，也不能预测它何时衰变。

Spontaneous radioactive decay / 衰变的自发性

Definition / 定义

EN: Radioactive decay is spontaneous because it occurs without an external trigger or input of energy.

中: 衰变具有自发性，因为它不需要外部触发或能量输入。

Alpha particle / α粒子

Definition / 定义

EN: An alpha particle is a helium nucleus containing two protons and two neutrons.

中: α粒子是含两个质子与两个中子的氦核。

依据 / Evidence: PH01 202206 Q08.1 · MS p15（相关计算或应用）

Formula / 公式

\[\Large\displaystyle \alpha:\ {}^A_ZX\to{}^{A-4}_{Z-2}Y+{}^4_2He\]
\[\Large\displaystyle \beta^-:\ {}^A_ZX\to{}^A_{Z+1}Y+e^-+\bar\nu_e\]
\[\Large\displaystyle \beta^+:\ {}^A_ZX\to{}^A_{Z-1}Y+e^++\nu_e\]

物理量与符号 / Quantities and symbols

符号沿用本节公式；若题目另有定义，以题设为准。 / These symbols follow this section; use any notation defined in the question.

物理量 / Quantity 符号 / Symbol SI单位 / SI unit 说明 / Notes
核子数、质量数 / nucleon number, mass number \(A\) \(1\)（无量纲 / dimensionless） 计数；不是以 kg 表示的质量 / A count, not mass in kg.
质子数、原子序数 / proton number, atomic number \(Z\) \(1\)（无量纲 / dimensionless） 计数 / A count.
中子数 / neutron number \(N\) \(1\)（无量纲 / dimensionless） 与未衰变核数等 N 按语境区分 / Context distinguishes this N from other counts.
电荷量 / electric charge \(Q,\ q\) \(\mathrm{C}\) 源电荷常用 Q，单个粒子或检验电荷常用 q / Q often denotes a source; q a particle/test charge.

粒子符号 / Particle notation： \(p\) 为质子，\(n\) 为中子，\(e^-\) 为电子，\(e^+\) 为正电子，\(\nu_e\) 为电子中微子，\(\bar\nu_e\) 为电子反中微子；这些符号表示粒子种类，不是待求物理量，故不配 SI 单位。 / These symbols label particle species, not quantities with SI units.

Explanation / 讲解

随机自发衰变 / Random spontaneous decay

不稳定核可自发转成其他核并发射粒子或辐射。不能预测一个特定核何时衰变，但可描述大量核的统计行为。The decay of an individual nucleus is unpredictable.

必须会写的方程 / Required equations

\[\Large\displaystyle \alpha:\quad{}^A_ZX\to{}^{A-4}_{Z-2}Y+{}^4_2\mathrm{He}\]
\[\Large\displaystyle \beta^-:\quad{}^A_ZX\to{}^A_{Z+1}Y+{}^0_{-1}e+\bar\nu_e\]
\[\Large\displaystyle \beta^+:\quad{}^A_ZX\to{}^A_{Z-1}Y+{}^0_{+1}e+\nu_e\]

α粒子为两个质子和两个中子的氦核。β粒子在核变化过程中产生，不是原来电子壳层中的电子被推出。A beta electron or positron is created in the nuclear process.

衰变 / Mode A变化 Z变化 中子数变化
α -4 -2 -2
β− 0 +1 -1
β+ 0 -1 +1

图示：α 衰变的核变化 / Alpha decay

读图 / Reading： α 粒子为两个质子加两个中子，故母核 A 减 4、Z 减 2；核反应式两侧总核子数和总电荷守恒。

An alpha particle contains two protons and two neutrons, reducing parent A by four and Z by two; total nucleon number and charge are conserved.

Application / 应用

方法 / Method

看两侧A和电荷数总和，确定未知产物。连续衰变逐步更新A、Z，不把元素名称保持不变。Check the complete decay chain step by step.

γ退激发不改变A和Z，具体能级见核激发态笔记。Gamma emission changes nuclear energy rather than nucleon composition.

A07 方法 1 · 核方程与衰变链账目 / Nuclear equations and decay chains

  1. 逐边检查 \(A\) 和电荷数 \(Z\) 守恒：α带走 \((4,2)\)；β⁻为 \((0,-1)\) 使子核 \(Z\) 增1；β⁺为 \((0,+1)\) 使子核 \(Z\) 减1；γ不改 \(A,Z\)。 / Check both conserved totals independently.
  2. β⁻同时有电子反中微子，β⁺同时有电子中微子；两者 \(A=0,Z=0\)，上横线不能漏。 / Pair the correct neutrino with each beta process.
  3. 长链先由 \(\Delta A\) 求α数，再由 \(\Delta Z\) 求β净数；不能把 \(A-Z\) 误当质子数。 / Use nucleon change before charge change.
  4. 子核是否同位素、比荷如何变、反冲如何分配是不同问题：分别用 \(A,Z\)、\(q/m\)、动量守恒处理。 / Keep the bookkeeping tasks separate.
