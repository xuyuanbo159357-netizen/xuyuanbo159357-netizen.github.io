阅读方式 / How to use

本页区分物理原则、推荐书写及具体试题的评分要求；具体容差和扣分范围只用于所引题目。 / Distinguish physical principles, presentation advice and question-specific marking.

1. 定量作图与草图 / Plotting and sketching

  • Plot / 定量作图： 标出物理量、单位和合适线性刻度，准确落点，按数据趋势画最佳拟合线或曲线。 / Label quantities, units and suitable scales; plot accurately and fit the trend.
  • Sketch / 草图： 仍需表达起点、方向、曲率、关键截距及题目给定的数值；通常不要求每一点精确量取。 / Show the relevant shape, intercepts and given numerical features.
  • 只有关系和数据支持时才过原点；不要把每个实验点逐一折线连接。 / Pass through the origin only when justified; do not join experimental points mechanically.

2. 图线和斜率的实际评分例证 / Actual graph-marking example

2018 June Q10.2–10.3 要求：点位在真实位置半个小格以内；拟合线两侧散点合理；避免粗线粗点；斜率三角形斜边超过所画直线长度的一半，且图上标明所读取的数据。 / The cited rubric requires accurate points, a thin fit, a large gradient triangle and annotated readings. 这些数值容差仅指该题。 / Numerical tolerances belong to this question. PH01 2018 June Q10.2–10.3 · MS PDF p14 · 原题与答案 / Question and answer

计算斜率要使用图轴的实际数值与词头，报告斜率单位。\(F\) 对 \(\Delta L\) 的斜率是 \(k\)；若坐标互换，斜率变为 \(1/k\)。 / Use actual axis values and units; reversing the axes changes the physical interpretation.

3. 运动图像 / Motion graphs

  • 先区分位移、距离、速度和速率。速度负值表示运动方向，不表示“速率小于零”。 / Distinguish displacement, distance, velocity and speed; negative velocity indicates direction.
  • \(s\)–\(t\) 图斜率给速度；\(v\)–\(t\) 图斜率给加速度，有符号面积给位移。问路程时，对各段面积取绝对值后相加。 / Interpret gradients and signed areas correctly.
  • 弹跳题先说明正方向。接触地面时速度可以迅速改变符号；不要把碰撞前后两段误画成整段同一恒加速度直线。 / Define the sign convention and represent the short contact interval appropriately.
  • 曲线某点的瞬时量由该点切线斜率求，不以任意两点连线代替。 / Use a tangent for an instantaneous gradient.

以上为图像解读的物理规范和推荐画法；具体给分以题图与评分标准为准。 / These are physical and presentation conventions; consult the individual rubric.

4. 受力图、矢量图与核方程 / Force diagrams, vector diagrams and decay equations

  • 受力图只画研究对象受到的力，力名和方向明确；第三定律作用反作用力作用于不同物体，不是同一物体受力平衡的一对力。 / Draw only forces on the chosen body; third-law partners act on different bodies.
  • 矢量相加使用首尾相接或平行四边形；方向角指明相对哪一方向。 / Use a consistent vector construction and identify the angle reference.
  • 核方程写全粒子符号、核子数和电荷数；分别检查两者守恒。2026 June Q02 将符号和数字分开给分，正电子及中微子不能随意省略。 / Check particle symbols, nucleon numbers and charges. PH01 2026 June Q02 · MS PDF p5 · 原题与答案 / Question and answer
