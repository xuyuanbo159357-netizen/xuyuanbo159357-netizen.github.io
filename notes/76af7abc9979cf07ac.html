运动图像与方向变化模型 / Motion graphs

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.3 直线运动 - Motion along a straight line

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
gradient / tangent 斜率 / 切线 变化率；曲线指定时刻取切线 / A tangent gives an instantaneous rate.
area under 图线下面积 先识别纵轴与横轴 / Identify the axes before interpreting area.
velocity–time 速度–时间 斜率给加速度，面积给位移变化 / Gradient gives acceleration; area gives displacement change.
crosses zero 穿过零值 v–t过零可对应方向改变 / A velocity sign change means reversal.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

图像是运动关系的另一种表达。先读轴名、单位与正方向，再读斜率和面积。 / Read axis quantities, units and sign conventions before using the graph.

读图 / Reading: 位移–时间图的斜率给速度；最高位置处斜率为零，回程速度为负。 / The displacement–time gradient gives velocity; the turning point has zero slope and the return has negative velocity.

Formula / 公式

\[\text{s–t gradient}=v,\quad \text{v–t gradient}=a,\quad \text{signed v–t area}=\Delta s,\quad \text{signed a–t area}=\Delta v.\]

解题流程 / Method

  1. 求平均变化率用两个时刻的变化量；求瞬时变化率取切线。 / Use a secant for an average and a tangent for an instantaneous rate.
  2. 用矩形、三角形或梯形求面积；轴下部分带相反符号。 / Sum geometric areas with their signs.
  3. 求路程时加面积的绝对值；求位移时加有符号面积。 / Distinguish distance from displacement.
  4. 反弹图像分为飞行与接触阶段：飞行可能 \(a=-g\)，接触时不能继续套同一自由落体加速度。 / Separate flight from impact.

易错判断 / Checks

水平 s–t 图线表示位置不变，不一定在原点；水平 v–t 图线表示速度恒定，不一定静止。 / Horizontal lines mean different things on different axes.
