原题关键词 / Original cues 对应物理模型 / Model 关联依据与适用范围 / Link and scope
“component”（分量）；“constant velocity”（恒定速度） 受力平衡与斜面分解模型 / Equilibrium and inclined plane 06.1、06.2、06.3、06.4：根据方向分解真实受力；平衡分支要求合力为零，斜面运动仍须按题设列合力。 / Resolve real forces; use zero resultant only in an equilibrium branch.
“acceleration”（加速度或加速） 匀加速度与分段运动模型 / Constant acceleration 06.2：先划分运动阶段；只有该阶段加速度恒定才用匀加速度方程，from rest 只确定初速度为零。 / Separate stages; SUVAT requires constant acceleration, while from rest only sets the initial velocity.
“velocity-time”（速度-时间）；“graph”（图像）；“variation of”（图中物理量的变化） 运动图像与方向变化模型 / Motion graphs 06.2、06.3：核对运动量和横轴，分别用斜率或面积；速度过零和速率为零需按方向解释。 / Check the axes before interpreting gradient, area or a velocity sign change.
“air resistance”（空气阻力）；“parachute”（降落伞或跳伞者） 阻力与终极速率模型 / Terminal speed 06.1、06.3、06.4：分阶段比较驱动力或重力与阻力；稳定终极速率时合力为零，不能对整个过程都取平衡。 / Compare forces by stage; only steady terminal motion has zero resultant.
