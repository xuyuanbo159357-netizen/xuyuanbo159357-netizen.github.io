Concept / 概念

Young modulus / 杨氏模量；Tensile stress / 拉应力；Tensile strain / 拉应变

Definition / 定义

Young modulus / 杨氏模量

EN: The Young modulus is the ratio of tensile stress to tensile strain in the linear elastic region.

中: 杨氏模量是线性弹性范围内拉应力与拉应变之比。

表达要点 / Wording: tensile stress; tensile strain; linear region

依据 / Evidence: PH01 201801 Q08.3 · MS p11（相关计算或应用）

Tensile stress / 拉应力

EN: Tensile stress is the tensile force per unit cross-sectional area of a specimen.

中: 拉应力是试样单位截面积上承受的拉力。

表达要点 / Wording: force; cross-sectional area

依据 / Evidence: PH01 201801 Q08.3 · MS p11（相关计算或应用）；PH01 202401 Q01 · MS p4（相关计算或应用）

Tensile strain / 拉应变

EN: Tensile strain is the extension divided by the original unstretched length.

中: 拉应变是伸长量除以原始未拉伸长度。

表达要点 / Wording: extension; original length

依据 / Evidence: PH01 201806 Q04.1 · MS p7（定义/陈述评分点）

Formula / 公式

\[\begin{gathered} F=mg \\ A_0=\frac{\pi d_0^2}{4} \\ E=\frac{kL_0}{A_0} \\ \frac{\Delta E}{E}=\frac{\Delta k}{k}+\frac{\Delta L_0}{L_0}+2\frac{\Delta d_0}{d_0} \end{gathered}\]

Conditions / 适用条件

在线性弹性范围内测量，原长取实际受拉的有效段，截面积由代表性的原始直径得到。 / Measure in the linear elastic range using the gauge length and representative original diameter.

Explanation / 讲解

原理 / Principle

\[F=k\Delta L,\qquad E=\frac{kL_0}{A},\qquad A=\frac{\pi d^2}{4}.\]

在比例范围内载荷–伸长梯度 \(k=EA/L_0\)。The graph must use the linear range.

装置与测量 / Apparatus and measurements

用长而均匀的金属线、可靠支架、砝码与挂钩、长度标尺、伸长读数装置及螺旋测微器。可用合适参考线/补偿装置减小支架变化的影响。Measure extension without assuming the support is perfectly rigid.

原长应按线材实际受拉的有效测量段取值。直径在多个位置、不同方向重复测量并取平均，检查测微器零点。Measure the original gauge length and representative diameter.

Application / 应用

步骤 / Procedure

  1. 加适当预载荷拉直线材并定义读数零点 / Use a preload and define the baseline.
  2. 分步增加已知载荷，静止后读取伸长 / Increase load and wait for equilibrium.
  3. 将质量换为力 \(F=mg\)，记录增量和总载荷的约定 / State the load convention.
  4. 画F–ΔL图，选择线性段求k，再求E / Fit the linear range.
  5. 必要时逐步卸载，检验能否恢复 / Unload to test elastic behaviour.

评价 / Evaluation

长线材伸长较大，减小读数的相对误差。读取时防视差，避免温度变化和支架移动。直径的不确定度贡献在面积中乘2。Diameter uncertainty is amplified because area depends on its square.

在简化独立量模型下：\(\Delta E/E=\Delta k/k+\Delta L_0/L_0+2\Delta d/d\)。若已按其他相关测量求不确定度，不应重复计同一误差。State the variables used in the propagation.

避免超载断线，可加防护与砝码接收垫。The thin wire and falling masses require a controlled load range.

P02 方法 1 · 杨氏模量实验与误差方向 / Young-modulus experiments and bias

  1. 测原长，微米尺多位置、多方向测直径并查零误差；逐级加已知质量，测增量伸长，保持比例区并记录卸载以检查恢复。 / Measure geometry and extension independently.
  2. 参照线装置可补偿共同支架移动或温度变化；松夹具会把滑移当伸长，使 \(E=FL/(A\Delta L)\) 偏小。 / Explain the sign of the systematic bias.
  3. \(F\)–\(\Delta L\) 斜率为 \(k\)，\(E=kL/A\)；质量—伸长图斜率需再乘 \(gL/A\)；应力—应变图线性斜率才直接为 \(E\)。 / Use the actual plotted variables.
  4. 细线增加伸长、可减小伸长的百分不确定度，但同时增加直径的百分不确定度；不能脱离仪器分辨率断言总不确定度一定降低。 / Discuss competing uncertainty contributions.
  5. 面积法求塑性区形变功不能继续用线性区 \(F\Delta L/2\)。 / Use the measured curve beyond proportionality.
