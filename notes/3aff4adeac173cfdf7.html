U1/07 常用物理模型

匀加速度与分段运动模型 / Constant acceleration

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.3 直线运动 - Motion along a straight line

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
from rest 从静止开始 只说明 u=0 / This specifies the initial velocity only.
constant / uniform acceleration 恒定 / 均匀加速度 该阶段可用 SUVAT / Use SUVAT within that interval.
deceleration 减速 加速度与速度方向相反 / Acceleration opposes velocity.
then / until / immediately after 随后 / 直到 / 紧接之后 检查是否需要换阶段和初始条件 / Check stage boundaries.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

沿同一方向分析所选时间段内的 \(u,v,a,s,t\)。该段加速度恒定才适用匀加速度方程；“从静止”本身不保证加速度恒定。 / Constant acceleration must be established independently of the initial state.

Formula / 公式

\[v=u+at,\quad s=\frac{u+v}{2}t,\quad s=ut+\frac12at^2,\quad v^2=u^2+2as.\]

解题流程 / Method

  1. 定正方向，把 \(u,v,a,s\) 写成带符号量。 / Set a positive direction and use signed quantities.
  2. 已知恒定合力、质量恒定时，先由 \(a=F_{\rm net}/m\) 求加速度。 / Find acceleration from the resultant force when appropriate.
  3. 选择不含多余未知量的方程。 / Select the equation containing the required variables.
  4. 力或加速度变化时分段：上一段末速度成为下一段初速度，总时间相加。 / Match velocities at boundaries and add stage times.

易错判断 / Checks

若运动中反向，总路程须分段取距离相加；总位移使用符号相加。 / Add distances for path length and signed displacements for net displacement.
