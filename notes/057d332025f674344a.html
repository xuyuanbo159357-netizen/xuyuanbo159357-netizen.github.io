Concept / 概念

decay constant — 衰变常量

Definition / 定义

English: The probability per unit time that an individual nucleus will decay.

中文： 单个原子核在单位时间内发生衰变的概率。

定义评分依据 / Definition marking points： PH03 202606-Q01。原答案在题目下展开；此处按评分要点概括。 Summarised from the marking points; originals are folded below each question.

Formula / 公式与单位

Formula / 公式

\[\Large\displaystyle \lambda=\frac{A}{N}\]
\[\Large\displaystyle \lambda=\frac{\ln 2}{T_{1/2}}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\lambda\) 衰变常量 / decay constant \(\mathrm{s^{-1}}\)
\(A\) 活度 / activity \(\mathrm{Bq}\)
\(N\) 未衰变核数 / number of undecayed nuclei 无量纲 / dimensionless
\(T_{1/2}\) 半衰期 / half-life \(\mathrm{s}\)

图示讲解 / Diagram explained

图示：对数图的斜率 / Logarithmic decay plot

读图 / Reading： lnN–t 图斜率为 −λ、纵截距为 lnN₀；用计数率代替 N 时先扣背景并确认其与活度成正比。

For lnN against t, gradient is −λ and intercept lnN₀; count-rate substitution requires background correction and proportional response.
