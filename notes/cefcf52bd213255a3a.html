本卷复盘重点 / Paper-specific review

  • 若未能算出证明题的给定近似值，后续可使用题目提供的数值；解释不能只有方程。 Use the supplied show-that value if the preceding calculation fails; equations need interpretation. 报告第2页 / Report p2

  • RC综合计算先求等效电阻，再还原支路；矢量作图首尾相接。 Find equivalent resistance before branch values and draw vectors head-to-tail. 报告第3页 / Report p3

  • 圆周运动 / Circular Motion：17分，21.25%。 回看 / Review：3.6.1 圆周运动与向心力。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 电容器的充电和放电 / Capacitor Charge And Discharge：13分，16.25%。 回看 / Review：3.9.1 电容充放电与时间常量。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.

  • 电磁感应 / Electromagnetic Induction：13分，16.25%。 回看 / Review：3.10.4 电磁感应、楞次定律与发电。结合下表原题核对定义、模型条件与评分步骤。 Check definitions, model constraints and credited steps against the linked questions.
