关系 1 / Relation 1

\[\Large\displaystyle v=f\lambda\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(v\) 速度或速率，按题设 / velocity or speed as specified \(\mathrm{m\,s^{-1}}\)
\(f\) 频率 / frequency \(\mathrm{Hz}\)
\(\lambda\) 波长 / wavelength \(\mathrm{m}\)

物理关系 / Physical relationship： 每周期传播一个波长。 / A wave advances one wavelength each period.

关系 2 / Relation 2

\[\Large\displaystyle \Delta\phi=\frac{2\pi\Delta x}{\lambda}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(\Delta\phi\) 相位差 / phase difference \(\mathrm{rad}\)
\(\Delta x\) 传播方向上的距离差 / separation along propagation \(\mathrm{m}\)
\(\lambda\) 波长 / wavelength \(\mathrm{m}\)

物理关系 / Physical relationship： 一波长对应 2π 的相位变化。 / One wavelength corresponds to a phase change of two pi.

适用条件 / Conditions： 均匀介质、同频比较；相位可按整周等价 / uniform medium and same-frequency comparison; phases may differ by whole cycles

关系 3 / Relation 3

\[\Large\displaystyle d=\frac{vt}{2}\]

符号对应表 / Symbols and SI units

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(d\) 反射体单程距离 / one-way reflector distance \(\mathrm{m}\)
\(v\) 速度或速率，按题设 / velocity or speed as specified \(\mathrm{m\,s^{-1}}\)
\(t\) 时间 / time \(\mathrm{s}\)

物理关系 / Physical relationship： 回波时间为往返时间，因此单程距离除以二。 / Round-trip echo time gives half the total path as the one-way distance.

适用条件 / Conditions： 均匀介质、同频比较；相位可按整周等价 / uniform medium and same-frequency comparison; phases may differ by whole cycles

3.5.3

3.5.3 行波、相位与波参数

空间相位关系用于同一行波的不同位置；时间相位关系比较固定位置的周期阶段。

Spatial phase formula applies to points on the same progressive wave; time separation compares equivalent cycles at a fixed point.

相位差可用弧度、角度或周期分数表示。

3.5.4

3.5.4 横波、纵波、偏振与超声

不要求马吕斯定律；所有电磁波在真空中速率相同，电场和磁场的振动为横向。

Malus’s law is not required. All electromagnetic waves have the same speed in vacuum; their electric and magnetic fields oscillate transversely.

往返超声时间对应的深度须除以二。

Echo distance \(d=ct/2\) for a pulse travelling to an interface and back.
