Concept / 概念

Background radiation / 背景辐射；Count rate / 计数率；Corrected count rate / 校正计数率

Definition / 定义

Background radiation / 背景辐射

EN: Background radiation is radiation that does not come from the source being investigated.

中: 背景辐射是不来自正在研究的源的辐射。

表达要点 / Wording: not from the source being investigated

依据 / Evidence: PH01 202206 Q01.1 · MS p4（定义/陈述评分点）

Count rate / 计数率

EN: Count rate is the number of counts recorded by a detector per unit time.

中: 计数率是探测器单位时间内记录的计数次数。

表达要点 / Wording: recorded counts; per unit time

依据 / Evidence: PH01 202101 Q11.1 · MS p18（相关计算或应用）

Corrected count rate / 校正计数率

EN: The corrected count rate is the measured count rate minus the background count rate.

中: 校正计数率是测得的计数率减去背景计数率。

表达要点 / Wording: count rate; minus; background count rate

依据 / Evidence: PH01 202301 Q03.1 · MS p6（定义/陈述评分点）

Formula / 公式

\[\begin{gathered} R_{\rm bg}=\frac{N_{\rm bg}}{t_{\rm bg}} \\ R_{\rm source}=\frac{N_{\rm total}}{t_{\rm total}}-R_{\rm bg} \end{gathered}\]

Conditions / 适用条件

背景与总测量必须统一为同一单位的计数率后再相减。 / Subtract count rates in the same units rather than raw counts taken over different intervals.

Explanation / 讲解

来源 / Origins

背景辐射可来自宇宙射线、岩石土壤中的天然放射性、氡气、建筑材料及体内天然核素等。人造活动和医疗等可提供额外来源。Recognise natural and human-made sources without assuming all background is artificial.

Application / 应用

测量与修正 / Measurement and correction

移走待测源，保持环境和仪器条件，测较长时间的背景，再换算成计数率。Measure the background separately under comparable conditions.

\[R_{\rm bg}=\frac{N_{\rm bg}}{t_{\rm bg}},\qquad R_{\rm source}=\frac{N_{\rm total}}{t_{\rm total}}-R_{\rm bg}.\]

若计数时间不同，不能直接相减原始计数。Convert both to the same rate first.

例：背景120次/60 s=2.0 s⁻¹，测源360次/30 s=12 s⁻¹，源校正计数率为10 s⁻¹。Count rate is not automatically the source’s activity because detection efficiency is limited.

放射性计数随机波动，重复或较长计数通常能减小相对波动影响。源本身随时间明显衰减时，计数间隔也应与变化时间尺度匹配。Balance statistical variation with time resolution.

背景修正连接吸收实验、半衰期读取和反平方验证。The same correction is needed across the radiation experiments.

A14 方法 1 · 背景、计数率与累计时间 / Background, count rates and elapsed time

  1. 背景辐射是来自所研究源之外的辐射；可有自然和人工来源。给定义时不能只列一个例子或限定全为自然。 / Separate the definition from examples.
  2. 测无源背景计数 \(N_b\) 和时长 \(t_b\)，\(B=N_b/t_b\)；样品净率 \(N/t-B\)。不同计数时长不能直接相减总计数。 / Convert both measurements to rates.
  3. 不同计时段的合并率可用 \(\sum N_i/\sum t_i\)；区分总计数、每秒率与每分钟率。题给5分钟背景时先由率差再乘300 s。 / Use a time-weighted combined rate.
  4. 长时间或多次测量降低随机波动；实验前后测背景可检查背景是否变化并求代表值，不能假设所有读数变化都由源引起。 / Explain why a background measurement is needed.
