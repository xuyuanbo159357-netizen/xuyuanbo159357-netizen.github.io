功率效率与恒速行驶模型 / Power and efficiency

常用物理模型总目录 / Model index · 关键词速查 / Keyword lookup

考纲 / Specification: 3.2.7 功、能量与功率 - Work, energy and power

题目关键词与翻译 / Keyword cues and meanings

English cue 中文 应如何判断 / Interpretation
power / per second 功率 / 每秒 能量转移率 / Rate of energy transfer.
input / useful output 输入 / 有用输出 区分供能与有效机械输出 / Distinguish supplied and useful power.
efficiency 效率 输出与输入的比值 / Useful output divided by input.
constant speed / lifting 恒速 / 提升 用力平衡求驱动或提升力 / Find the force from the motion conditions.

关键词用于提示候选模型；须结合对象、方向、阶段和题设条件确认。 / Keywords suggest a model; verify the system, direction, stage and stated conditions.

核心模型与条件 / Model and conditions

把“能量大小”与“能量转移快慢”分开。平均功率用一段时间内的能量变化；瞬时机械功率用力与速度。 / Distinguish energy from its rate of transfer.

Formula / 公式

\[P_{\rm avg}=\frac{\Delta W}{\Delta t},\qquad P=F_{\parallel}v,\qquad \eta=\frac{P_{\rm useful}}{P_{\rm input}}.\]

解题流程 / Method

  1. 判断所给功率是输入还是输出，百分效率先转小数。 / Identify the power type and convert percentage efficiency to a fraction.
  2. 竖直恒速提升、无其他负载时 \(F=mg\)，故 \(P_{\rm useful}=mgv\)。 / Use the appropriate constant-speed force balance.
  3. 水平恒速行驶虽 \(F_{\rm net}=0\)，驱动力仍做正功来补偿阻力耗散；用驱动力求 \(P=Fv\)。 / Zero resultant force does not mean zero engine power.
  4. 小时转秒，MJ转J。 / Convert hours and megajoules to consistent SI units.

易错判断 / Checks

求输入功率通常须除以效率：\(P_{\rm input}=P_{\rm useful}/\eta\)。 / Input power exceeds useful output when efficiency is below one.

真题识别实例 / Recognition in past papers

  • 2026年6月 / June 2026 · Q20：题干线索 input power。恒速提升：先用mgv求有用功率，再除输入功率求效率 / Compare lifting power with the given input.
  • 2026年1月 / January 2026 · Q20：题干线索 27% efficient。由有用功与1小时求输出平均功率，再除0.27 / Find useful average power, then infer input power.
