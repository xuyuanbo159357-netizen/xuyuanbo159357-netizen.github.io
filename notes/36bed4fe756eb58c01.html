知识逐项讲解 / Concept-by-concept guide

Young modulus / 杨氏模量

Definition / 定义

EN: The Young modulus is the ratio of tensile stress to tensile strain in the linear elastic region.

中: 杨氏模量是线性弹性范围内拉应力与拉应变之比。

表达要点 / Wording: tensile stress; tensile strain; linear region

依据 / Evidence: PH01 201801 Q08.3 · MS p11（相关计算或应用）

Formula / 公式

\[\Large\displaystyle E=\frac{\sigma}{\epsilon}\]
\[\Large\displaystyle E=\frac{FL_0}{A_0\Delta L}\]

Symbols and SI units / 符号与 SI 单位

符号 / Symbol 物理量 / Quantity SI 单位 / SI unit
\(E\) 杨氏模量 / Young modulus \(\mathrm{Pa}\)
\(\sigma\) 拉应力 / tensile stress \(\mathrm{Pa}\)
\(\epsilon\) 拉应变 / tensile strain 无量纲 / dimensionless
\(F\) 拉力 / tensile force \(\mathrm{N}\)
\(L_0,\Delta L\) 原长、伸长量 / original length and extension \(\mathrm{m}\)
\(A_0\) 原横截面积 / original cross-sectional area \(\mathrm{m^2}\)

Conditions / 条件与说明： 用于应力与应变成正比的线性区域。 / Use in the linear region where stress is proportional to strain.

Formula / 公式

\[\Large\displaystyle E=\frac{\sigma}{\epsilon}\]
\[\Large\displaystyle E=\frac{FL_0}{A_0\Delta L}\]
\[\Large\displaystyle k=\frac{EA_0}{L_0}\]
\[\Large\displaystyle E=\frac{kL_0}{A_0}\]

Conditions / 适用条件

固定的杨氏模量取自线性弹性范围，不能把任意非线性点的应力应变比当作同一常量。 / Use the linear elastic region; arbitrary ratios beyond it are not the same constant modulus.

Explanation / 讲解

含义与关系 / Meaning and relationships

\[\Large\displaystyle E=\frac{\sigma}{\epsilon}\]
\[\Large\displaystyle E=\frac{FL_0}{A\Delta L},\qquad[E]\]
\[\Large\displaystyle E=\mathrm{Pa}\]

在比例范围内，E等于应力–应变图直线段的梯度。Young modulus is the gradient of the initial linear stress-strain region.

要区别此处E（模量）与能量E（单位J）。同一个字母不代表同一个量。Use the equation and unit to identify the symbol.

与线材刚度的联系 / Link to stiffness

\[\Large\displaystyle F=\frac{EA}{L_0}\Delta L,\qquad k\]
\[\Large\displaystyle F=\frac{EA}{L_0}\]

同一材料E不因换一根长短或粗细不同的线而改变；k随几何尺寸改变。A longer wire is less stiff, and a thicker wire is stiffer, for the same material.

F–ΔL图梯度k换算为 \(E=kL_0/A\)。如果横纵轴是应变–应力，梯度则为1/E。Check the axes before using a gradient.

图示：杨氏模量取线性区斜率 / Young modulus from the linear region

读图 / Reading： 仅用初始线性区应力/应变求杨氏模量；本图横轴用百分数时，先换成无量纲应变，不能直接把百分数当成纯数。

Use the initial linear stress–strain gradient. If strain is plotted as a percentage, convert it to a dimensionless fraction first.

Application / 应用

实验与误差 / Practical connection

Required practical2测载荷–伸长关系、原长和直径。因为 \(A\propto d^2\)，直径误差尤其影响E。Repeated diameter readings and a long specimen can improve the measurement.

超过线性范围时，不能把任意点的σ/ε当成这一固定杨氏模量。Use the specified elastic linear region.

D28 方法 1 · 材料常数、几何刚度与预应变 / Young modulus, geometry and pre-strain

  1. 线性区 \(E=\sigma/\varepsilon=FL_0/(A\Delta L)\)；\(k=EA/L_0\)。同材料截短、增粗改变的是物体刚度，通常不改变材料的杨氏模量。 / Separate a material property from a specimen property.
  2. 比例 \(\Delta L\propto FL_0/(Ed^2)\)；串接线各段同力、各段伸长相加。求直径需从面积再开方并乘二。 / Keep diameter and radius separate.
  3. 有初始预应变，再调节长度时 \(\varepsilon_f=\varepsilon_i+\Delta L_{added}/L_0\)，双头螺纹每转总改变量可为两倍螺距。 / Add the pre-existing strain.
  4. 弓弦或斜绳的推进力既受张力大小也受夹角改变影响，不能由 \(T=kx\) 一条式子断定合力。 / Resolve the changing geometry as well as the tension.
  5. 比较安全绳的刚度需联系停止距离、停止时间及力，同时保留能量和可用伸长范围。 / Explain the physical benefit in the actual use case.
