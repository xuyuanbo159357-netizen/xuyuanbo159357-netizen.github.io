统计口径 / How counts were calculated

  1. 语料范围 / Corpus： 本库2017年6月至2026年6月的17套历年PH01试卷；每道大题只统计一次。2018样卷单独存放在题库，未纳入这张历年词频表。 / Each main question is counted once; the specimen is outside this past-paper corpus.
  2. 出现次数 / Occurrences： 匹配本地PDF已提取的大题文本，包括题干、小问、选项及可提取的图表文字；不是评分标准、教学笔记或重复的知识点分类页。图中仅以像素保存且未进入提取文本的字不计入本次文本次数。 / These are extracted-text counts, with image-only lettering outside the text layer.
  3. 题数与试卷数 / Coverage： 一个词在一题里出现多次，会增加文本次数，但该题只算1道；同一试卷也只算1套。 / Occurrences, question coverage and paper coverage measure different things.
  4. 词形 / Forms： 忽略大小写，统一常见横线和空格，合并词条中列出的单复数、动词词形或明确同义表达。实际匹配到的每个词形及次数在展开项内列出。英文词须完整匹配，elastic不会误计到inelastic中，proton不会误计到antiproton中。 / Full-word boundaries prevent substring inflation.
  5. 组合词重叠 / Overlap： force与resultant force、energy与kinetic energy等分别统计，允许同一原句在不同词条中出现。不要相加不同词条的次数来求语料总词数。 / Single words and phrases are separate, potentially overlapping entries.
  6. 常见词筛选 / Selection： 候选词来自已有概念译名、模型关键词及试题中的物理用语；本表保留至少出现 3次 且涉及 2道不同大题 的词条。 / This table applies an explicit frequency and question-coverage threshold to the curated vocabulary.
  7. 多义词 / Context： 次数按词形匹配，不按释义分别计数；plastic、state、mean、moment等提供语境说明。词频不代表某一释义出现了同样多次。 / A form count is not a separate semantic-sense count.
